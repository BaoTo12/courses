## 2. SNS Filter Policy Execution Results

### Test A: Standard Order
```bash
$ aws sns publish \
    --topic-arn "arn:aws:sns:us-east-1:123456789012:CloudOrderEventsTopic" \
    --message '{"orderId":"ORD-STD-001","customerId":"cust-1@example.com","amount":35.50,"items":["BOOK-01"]}' \
    --message-attributes '{"priority": {"DataType": "String", "StringValue": "STANDARD"}}'
```

Output:
```json
{
    "MessageId": "c4578b91-1779-563f-91cb-3f044ef0a012"
}
```

Queue inspection proves filtering:
```bash
$ aws sqs get-queue-attributes --queue-url "https://sqs.us-east-1.amazonaws.com/123456789012/CloudOrderPriorityQueue" --attribute-names ApproximateNumberOfMessages
{
    "Attributes": {
        "ApproximateNumberOfMessages": "0"
    }
}
```
*Result*: `PriorityQueue` ignored the message completely because `priority` did not match `["HIGH"]`.

### Test B: High-Priority Order
```bash
$ aws sns publish \
    --topic-arn "arn:aws:sns:us-east-1:123456789012:CloudOrderEventsTopic" \
    --message '{"orderId":"ORD-HIGH-999","customerId":"vip@example.com","amount":1299.00,"items":["LAPTOP-PRO"]}' \
    --message-attributes '{"priority": {"DataType": "String", "StringValue": "HIGH"}}'
```

Output:
```json
{
    "MessageId": "8b9e6f32-7201-4ec1-b4d2-f67e8912aa98"
}
```

Checking `PriorityQueue`:
```bash
$ aws sqs get-queue-attributes --queue-url "https://sqs.us-east-1.amazonaws.com/123456789012/CloudOrderPriorityQueue" --attribute-names ApproximateNumberOfMessages
{
    "Attributes": {
        "ApproximateNumberOfMessages": "1"
    }
}
```
*Result*: Matched filter policy and successfully delivered to `PriorityQueue`.
