## 3. Terminal Transcript: Lambda Authorizer Invocations

### 3.1 Invocation with Valid JWT:
```bash
$ aws lambda invoke \
    --function-name cloudorder-token-authorizer-prod \
    --cli-binary-format raw-in-base64-out \
    --payload '{"type":"TOKEN","authorizationToken":"Bearer '"$ACCESS_TOKEN"'","methodArn":"arn:aws:execute-api:us-east-1:123456789012:api-123/prod/POST/orders"}' \
    authorizer-response.json

{
    "StatusCode": 200,
    "ExecutedVersion": "$LATEST"
}

$ cat authorizer-response.json | jq .
{
  "principalId": "09a1b2c3-44dd-55ee-66ff-778899aabbcc",
  "policyDocument": {
    "Version": "2012-10-17",
    "Statement": [
      {
        "Action": "execute-api:Invoke",
        "Effect": "Allow",
        "Resource": "arn:aws:execute-api:us-east-1:123456789012:api-123/prod/POST/orders"
      }
    ]
  },
  "context": {
    "role": "ENGINEER",
    "customerId": "cust-7777"
  }
}
```

### 3.2 Invocation with Tampered JWT:
```bash
$ aws lambda invoke \
    --function-name cloudorder-token-authorizer-prod \
    --cli-binary-format raw-in-base64-out \
    --payload '{"type":"TOKEN","authorizationToken":"Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9.corrupted.signature","methodArn":"arn:aws:execute-api:us-east-1:123456789012:api-123/prod/POST/orders"}' \
    tampered-response.json

{
    "StatusCode": 200,
    "ExecutedVersion": "$LATEST"
}

$ cat tampered-response.json | jq .
{
  "principalId": "anonymous",
  "policyDocument": {
    "Version": "2012-10-17",
    "Statement": [
      {
        "Action": "execute-api:Invoke",
        "Effect": "Deny",
        "Resource": "arn:aws:execute-api:us-east-1:123456789012:api-123/prod/POST/orders"
      }
    ]
  },
  "context": {}
}
```
The authorizer cleanly denied access and prevented unauthorized execution.
