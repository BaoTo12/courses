## 2. Terminal Transcript: CodeDeploy Canary Traffic Shifting

```bash
$ aws deploy get-deployment \
    --deployment-id "d-CANARY12345" \
    --query "deploymentInfo.{Status:status,Config:deploymentConfigName,Creator:creator}" \
    --output json

{
  "Status": "InProgress",
  "Config": "CodeDeployDefault.LambdaCanary10Percent5Minutes",
  "Creator": "codebuild.amazonaws.com"
}
```

### Checking Lambda Function Alias Routing Configuration:
```bash
$ aws lambda get-alias \
    --function-name "CloudOrderServiceFunction" \
    --name "live" \
    --query "{FunctionVersion:FunctionVersion,RoutingConfig:RoutingConfig}" \
    --output json

{
  "FunctionVersion": "1",
  "RoutingConfig": {
    "AdditionalVersionWeights": {
      "2": 0.1
    }
  }
}
```
**Observation**: Version 1 carries 90% of traffic, while Version 2 carries 10% (`0.1` weight).

## 3. Terminal Transcript: Simulated Hook Failure & Rollback Event

### 3.1 Hook Log Output in CloudWatch:
```text
2026-09-27T09:05:12.110Z [CODEDEPLOY-HOOK] Validating Canary for Deployment: d-FAIL9999 (Execution: e-HOOK8888)
2026-09-27T09:05:12.150Z [CODEDEPLOY-HOOK] Exception during canary probe: Database ping timed out on canary port 5432
2026-09-27T09:05:12.185Z [CODEDEPLOY-HOOK] Reported Failed to CodeDeploy
```

### 3.2 CodeDeploy Rollback Execution:
```bash
$ aws deploy get-deployment \
    --deployment-id "d-FAIL9999" \
    --query "deploymentInfo.{Status:status,RollbackInfo:rollbackInfo}" \
    --output json

{
  "Status": "Stopped",
  "RollbackInfo": {
    "rollbackDeploymentId": "d-ROLLBACK7777",
    "rollbackTriggeringDeploymentId": "d-FAIL9999",
    "rollbackMessage": "The deployment failed because a lifecycle event hook execution failed."
  }
}
```

### 3.3 Verifying Restored Alias:
```bash
$ aws lambda get-alias \
    --function-name "CloudOrderServiceFunction" \
    --name "live" \
    --query "{FunctionVersion:FunctionVersion,RoutingConfig:RoutingConfig}" \
    --output json

{
  "FunctionVersion": "1",
  "RoutingConfig": null
}
```
**Result**: Traffic shifting was aborted and 100% of user traffic was restored to Version 1 immediately!
