## 1. Terminal Transcript: Generating & Inspecting Trace Context

### 1.1 Trace Header Injection via Curl
```bash
$ TRACE_ID="1-6789abcd-0123456789abcdef01234567"
$ curl -i -X POST "https://api.cloudorder.com/orders" \
    -H "Content-Type: application/json" \
    -H "X-Amzn-Trace-Id: Root=${TRACE_ID};Sampled=1" \
    -d '{"orderId":"ord-5001","customerId":"cust-101","amount":199.99}'

HTTP/1.1 201 Created
Content-Type: application/json
X-Amzn-Trace-Id: Root=1-6789abcd-0123456789abcdef01234567;Sampled=1
Date: Sun, 27 Sep 2026 09:10:00 GMT

{"orderId":"ord-5001","status":"CREATED"}
```

## 2. Terminal Transcript: Querying X-Ray Summaries by Annotation

```bash
$ aws xray get-trace-summaries \
    --start-time 1790500000 \
    --end-time 1790500900 \
    --filter-expression 'annotation.orderId = "ord-5001"' \
```
