## Narrative Bridge: Engineering Cryptographic Security & Identity

In [Lecture 06.02](./06.02-api-card-kms-secrets-manager-authorizer-events.md), we studied the exact SDK contracts for `KmsClient.generateDataKey()`, `SecretsManagerClient`, and the API Gateway Authorizer IAM policy format. Now, we implement the enterprise security layer for **CloudOrder**:

1. **`KmsEnvelopeEncryptionService` (Client-Side Envelope Encryption)**:
   * Calls AWS KMS `GenerateDataKey` with `DataKeySpec.AES_256`.
   * Encrypts sensitive payment records using local AES-GCM (12-byte random IV, 128-bit authentication tag).
   * **Heap Safety**: Explicitly zeroes out the plaintext byte array from memory (`Arrays.fill(plaintextDek, (byte) 0)`) immediately after cipher execution to prevent memory dump exploitation.
   * Decrypts payloads by sending only the encrypted DEK to AWS KMS.
2. **`SecretsManagerCacheService` (Resilient Secrets Cache)**:
   * Protects applications from rate limits and per-request charges by maintaining an in-memory cache with configurable TTL.
   * Exposes an invalidation hook for automated secret rotation.
3. **`CognitoJwtAuthorizerHandler` (API Gateway Token Authorizer)**:
   * Decodes and validates Cognito-issued JWT tokens.
   * Enforces issuer verification, token use constraints (`token_use: access` or `id`), and expiration windows.
   * Generates AWS IAM execution policies (`Allow`/`Deny`) and passes customer metadata context downstream.

### Critical Mechanical Implementation Details:
* **The Heap Poisoning Vulnerability**: Java `String` objects are immutable and placed into the JVM String Pool, where they linger until garbage collected. Plaintext encryption keys must **never** be converted to `String`. By handling DEKs exclusively as `byte[]` arrays, we can explicitly invoke `Arrays.fill(plaintextDek, (byte) 0)` in a `finally` block, wiping the cryptographic material from physical memory immediately.
* **AES-GCM Authenticated Encryption**: Unlike CBC mode which requires separate HMAC hashing to prevent padding oracle attacks, GCM (Galois/Counter Mode) provides authenticated encryption. Any tampering with the ciphertext, IV, or encrypted DEK triggers a `GeneralSecurityException` during decryption.
