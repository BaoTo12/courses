Stores PDF invoice records securely in private Amazon S3 buckets with SSE-S3 AES-256 encryption, generates time-limited SigV4 download and upload URLs using AWS SDK v2 `S3Presigner`, handles asynchronous `S3Event` notifications with robust URL key decoding, and accelerates order lookups via ElastiCache Redis implementing the Cache-Aside pattern with TTL expiration.

## Narrative Bridge: Engineering the Object Storage & Cache Tier

In [Lecture 05.02](./05.02-api-card-s3-presigner-elasticache-redis.md), we analyzed the exact SDK contracts for `S3Presigner`, `PutObjectRequest`, and Lettuce's non-blocking Redis commands. Now, we will implement the enterprise Java 21 storage and caching subsystem for **CloudOrder**:

1. **`InvoiceStorageService` (S3 Object Manager & Presigner)**:
   * Generates time-limited SigV4 presigned GET URLs so customers download invoices directly from S3 without proxying heavy binary payloads through Lambda (bypassing the 6 MB Lambda payload limit and saving execution memory).
   * Generates presigned PUT URLs with strict `Content-Type` enforcement preventing unauthorized file format uploads.
   * Executes direct server-side uploads enforcing AES-256 server-side encryption.
2. **`OrderCacheService` (ElastiCache Redis Cache-Aside Store)**:
   * Implements Cache-Aside (Lazy-Loading): queries Redis key `order:<id>`, on cache miss queries the database fallback supplier, populates Redis with an explicit TTL, and returns the entity.
   * Tracks real-time cache hits, misses, and hit ratio for CloudWatch observability.
   * Exposes cache eviction on order modification to eliminate stale reads.
3. **`S3InvoiceNotificationHandler` (Asynchronous S3 Event Consumer)**:
   * Consumes `s3:ObjectCreated:*` notifications.
   * Safely URL-decodes object keys (handling S3's conversion of spaces to `+` and percent-encoding).
   * Triggers automated order cache invalidation upon invoice creation.

## 3. S3 Storage Service & S3Presigner Implementation

✍️ `src/main/java/com/cloudarchitect/dvac02/caching/service/InvoiceStorageService.java`

{{file:backend/module-05-s3-caching/src/main/java/com/cloudarchitect/dvac02/caching/service/InvoiceStorageService.java:java}}

### Critical Mechanical Implementation Details:
* **Zero Network Overhead**: Calling `s3Presigner.presignGetObject()` performs zero network calls. It executes purely in-memory HMAC-SHA256 cryptographic signing using local AWS IAM credentials.
* **Lambda Payload Bypass**: A 10 MB invoice PDF would crash standard API Gateway (10 MB limit) and stress Lambda memory. Presigned URLs allow direct S3 transfer at maximum network throughput.

## 4. ElastiCache Redis Cache-Aside Service

✍️ `src/main/java/com/cloudarchitect/dvac02/caching/service/OrderCacheService.java`

{{file:backend/module-05-s3-caching/src/main/java/com/cloudarchitect/dvac02/caching/service/OrderCacheService.java:java}}

### Critical Mechanical Implementation Details:
* **Atomic `SETEX`**: The cache write uses `commands.setex(key, ttlSeconds, json)` to atomically write the value and set the TTL, preventing race conditions where a key is created without an expiration.
* **Cache Corrupt Fallback**: If deserialization fails due to a schema upgrade or corrupt byte stream, the handler silently deletes the bad key (`del(cacheKey)`) and gracefully falls back to the database.

{{file:backend/module-05-s3-caching/src/main/java/com/cloudarchitect/dvac02/caching/handler/S3InvoiceNotificationHandler.java:java}}

### The DVA-C02 URL-Encoding Trap:
> [!WARNING]
> Amazon S3 URL-encodes object keys in notification payloads. A file uploaded as `invoices/2026/09/invoice customer#123.pdf` is transmitted in `S3Event` as `invoices/2026/09/invoice+customer%23123.pdf`.
> If your Lambda handler attempts to fetch `s3Client.getObject(rawKey)`, S3 will return `NoSuchKey` (HTTP 404). Always decode via `URLDecoder.decode(rawKey.replace("+", "%20"), StandardCharsets.UTF_8)`!
