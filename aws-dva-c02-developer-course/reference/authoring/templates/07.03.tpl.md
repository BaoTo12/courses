## Narrative Bridge: Engineering the Deployment Safety Gates

In [Lecture 07.02](./07.02-api-card-buildspec-appspec-codedeploy-hooks.md), we studied the exact schema for `buildspec.yml`, `appspec.yaml`, and CodeDeploy's lifecycle hook protocol. Now, we construct the deployment safety gates for **CloudOrder**:

1. **`buildspec.yml` (CodeBuild Declarative Pipeline)**:
   * Installs Corretto 21.
   * Runs automated unit testing in the `pre_build` phase (`mvn clean compile test`). If any test fails, CodeBuild terminates the pipeline, preventing bad code from ever deploying.
   * Packages deployable artifacts and caches `/root/.m2` to accelerate build times.
2. **`appspec.yaml` (CodeDeploy Traffic Shifting)**:
   * Declares the Lambda target function and binds the `BeforeAllowTraffic` lifecycle hook.
3. **`CanaryValidationHookHandler` (Pre-Traffic Validation Hook)**:
   * Executes synthetic smoke tests against the newly deployed canary version.
   * On success, signals `SUCCEEDED` to CodeDeploy via `putLifecycleEventHookExecutionStatus`.
   * On failure, signals `FAILED`, commanding CodeDeploy to abort immediately and roll back traffic.
4. **`BeanstalkHealthCheckController` (Application Health Probing)**:
   * Evaluates database, cache, and disk subsystems for Elastic Beanstalk Application Load Balancers.

### Critical Mechanical Implementation Details:
* **Fail Fast**: Placing `mvn clean compile test` in `pre_build` ensures that compiling or testing errors immediately exit with a non-zero status code, aborting the build before any artifacts are uploaded to S3.
* **Maven Caching**: Specifying `/root/.m2/**/*` in `cache.paths` cuts recurring CodeBuild execution times from 4 minutes down to 35 seconds.
