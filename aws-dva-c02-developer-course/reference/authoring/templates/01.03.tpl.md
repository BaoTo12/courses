## Narrative Bridge: Implementing the Contract

In [Lecture 01.02](./01.02-api-card-requesthandler.md), we studied the `RequestHandler<APIGatewayProxyRequestEvent, APIGatewayProxyResponseEvent>` contract. Now, we will implement this interface in production Java 21 code for our **CloudOrder** backend.

Our handler must achieve three real-world goals:
1. Accept requests on a greedy route (`/orders/{proxy+}`) so categories like `/orders/electronics` or `/orders/appliances/refrigerators` are dynamically captured without re-deploying API Gateway.
2. Parse query string filters like `?region=us-east-1`.
3. Deserialize incoming JSON bodies safely into an `OrderRequest` POJO, calculate order pricing, and return a validated `OrderResponse` serialized as JSON.

## 1. Project Dependencies Architecture

The backend project is structured around Java 21 LTS and the modular AWS SDK for Java v2.

✍️ `pom.xml`

{{file:backend/module-01-serverless-api/pom.xml:xml}}

### Architectural Decisions in `pom.xml`:
* **BOM Resolution**: `software.amazon.awssdk:bom` manages all SDK v2 module versions synchronously.
* **`url-connection-client`**: Replaces the bulky Apache HTTP client with JVM-native connections, saving ~200ms of cold-start classloading time.
* **`maven-shade-plugin`**: Packages all transitives into an executable Fat JAR to avoid `ClassNotFoundException` in the Lambda isolated classloader.

## 3. The Core Lambda Request Handler

✍️ `src/main/java/com/cloudarchitect/dvac02/api/OrderApiHandler.java`

{{file:backend/module-01-serverless-api/src/main/java/com/cloudarchitect/dvac02/api/OrderApiHandler.java:java}}

### Critical Implementation Details:
1. **Singleton ObjectMapper**: `OBJECT_MAPPER` is instantiated as a `static final` constant outside `handleRequest`. Reusing the Jackson mapper across warm invocations avoids expensive reflection re-initialization.
2. **Greedy Path Extraction**: `input.getPathParameters().get("proxy")` retrieves the full sub-path matched by `{proxy+}` (e.g. `electronics/phones`).
3. **CORS Headers Map**: Returned in all response paths (200, 201, 400, 500) to ensure browsers do not block error responses.
