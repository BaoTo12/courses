## 📇 Card 1: `SnsClient` & `PublishRequest` (AWS SDK for Java v2)

### Maven Dependency
```xml
<dependency>
    <groupId>software.amazon.awssdk</groupId>
    <artifactId>sns</artifactId>
</dependency>
```

### Signature & Factory
```java
package software.amazon.awssdk.services.sns;

public interface SnsClient extends SdkClient {
    static SnsClient create();
    static SnsClientBuilder builder();
    PublishResponse publish(PublishRequest publishRequest);
}
```

### Usage Pattern
```java
SnsClient snsClient = SnsClient.builder()
    .region(Region.US_EAST_1)
    .httpClient(UrlConnectionHttpClient.create())
    .build();

PublishRequest request = PublishRequest.builder()
    .topicArn("arn:aws:sns:us-east-1:123456789012:CloudOrderEventsTopic")
    .message(jsonPayload)
    .messageAttributes(Map.of(
        "priority", MessageAttributeValue.builder()
            .dataType("String")
            .stringValue("HIGH")
            .build(),
        "amount", MessageAttributeValue.builder()
            .dataType("Number")
            .stringValue("149.99") // Numbers are passed as Strings in the SDK builder!
            .build()
    ))
    .build();

PublishResponse response = snsClient.publish(request);
String messageId = response.messageId();
```

> [!WARNING]
> **DVA-C02 Exam Trap**: In `MessageAttributeValue.builder()`, even when `dataType` is `"Number"`, you must pass the value to `.stringValue("149.99")`, NOT an integer or float literal. AWS SDK serializes all attribute values as strings over the wire to preserve numerical precision.

## 📇 Card 2: `SQSEvent` & The SNS Envelope Structure

### Maven Dependency
```xml
<dependency>
    <groupId>com.amazonaws</groupId>
    <artifactId>aws-lambda-java-events</artifactId>
    <version>3.14.0</version>
</dependency>
```

### The SQS Record Contract
```java
package com.amazonaws.services.lambda.runtime.events;

public class SQSEvent {
    public List<SQSMessage> getRecords();
    
    public static class SQSMessage {
        public String getMessageId();            // e.g. "4b81b2e3-6c84-48f8-b3f7-9c98a58e08d9"
        public String getReceiptHandle();        // Used to delete or change visibility
        public String getBody();                 // The raw string payload
        public Map<String, String> getAttributes(); // System attributes: ApproximateReceiveCount, SentTimestamp
        public Map<String, MessageAttribute> getMessageAttributes();
    }
}
```

### The SNS Envelope Trap: `getBody()` is Not Your Domain Object!
When an SNS topic publishes to an SQS queue with `RawMessageDelivery=false` (the default), SQS wraps your payload in an SNS metadata envelope:

```json
{
  "Type": "Notification",
  "MessageId": "8f8303f2-1a4e-5e36-9a40-2bc61a0b1234",
  "TopicArn": "arn:aws:sns:us-east-1:123456789012:CloudOrderEventsTopic",
  "Message": "{\"orderId\":\"ORD-101\",\"amount\":49.99}",
  "Timestamp": "2026-09-27T08:30:00.000Z",
  "MessageAttributes": {
    "priority": { "Type": "String", "Value": "HIGH" }
  }
}
```

> [!IMPORTANT]
> If your Lambda consumer calls `objectMapper.readValue(record.getBody(), OrderEvent.class)`, Jackson will throw `UnrecognizedPropertyException: Unrecognized field "Type"`! Your consumer must either:
> 1. Set `RawMessageDelivery: true` on the `AWS::SNS::Subscription`, OR
> 2. Parse the envelope, inspect whether the JSON contains a `"Message"` field, and unwrap it (as we do in `BillingQueueProcessor`).

## 📇 Card 3: `SQSBatchResponse` & Partial Batch Failure

### Signature & Factory
```java
package com.amazonaws.services.lambda.runtime.events;

public class SQSBatchResponse {
    public static SQSBatchResponseBuilder builder();
    public List<BatchItemFailure> getBatchItemFailures();

    public static class BatchItemFailure {
        public static BatchItemFailureBuilder builder();
        public String getItemIdentifier(); // Must match SQS getMessageId()!
    }
}
```

### Usage Pattern
```java
List<SQSBatchResponse.BatchItemFailure> failures = new ArrayList<>();

for (SQSEvent.SQSMessage message : event.getRecords()) {
    try {
        processOrder(message.getBody());
    } catch (Exception e) {
        // Record the failed message ID
        failures.add(SQSBatchResponse.BatchItemFailure.builder()
            .withItemIdentifier(message.getMessageId())
            .build());
    }
}

return SQSBatchResponse.builder()
    .withBatchItemFailures(failures)
    .build();
```

### Wire-Level JSON Returned to Lambda Runtime
```json
{
  "batchItemFailures": [
    {
      "itemIdentifier": "4b81b2e3-6c84-48f8-b3f7-9c98a58e08d9"
    }
  ]
}
```

> [!CAUTION]
> **Fatal Exam Trap: `itemIdentifier` vs. `ReceiptHandle`**:
> To report a failed message, `itemIdentifier` MUST BE set to `message.getMessageId()`.  
> If you mistakenly pass `message.getReceiptHandle()`, the Lambda runtime will not match the record, will assume all messages succeeded, and will **permanently delete the failed message from SQS**, losing customer data!

## 📇 Card 4: SNS Subscription Filter Policy Grammar

Filter policies evaluate message attributes at the SNS routing plane before delivering to SQS:

| Filter Requirement | Filter Policy JSON Syntax |
|---|---|
| **Exact Match** | `{"priority": ["HIGH"]}` |
| **Or Match (Multiple values)** | `{"priority": ["HIGH", "URGENT"]}` |
| **Numeric Range** | `{"amount": [{"numeric": [">=", 100]}]}` |
| **Prefix Match** | `{"storeId": [{"prefix": "STORE-EAST-"}]}` |
| **Attribute Exists** | `{"discountCode": [{"exists": true}]}` |
| **Anything-But (Negation)** | `{"status": [{"anything-but": "CANCELLED"}]}` |
