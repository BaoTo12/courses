## Narrative Bridge: Observing Live Runtime Behavior

In [Lecture 01.05](./01.05-your-turn-local-test-deploy.md), you successfully deployed the CloudOrder API and triggered it via `curl`.

Now, we shift from deployment to **operational observability**. When you ran that `curl` command, did Lambda experience a cold start? How long did the Java 21 runtime take to initialize? How much of the 1,769 MB RAM did the JVM actually allocate?

We will answer these questions using **Amazon CloudWatch Logs Insights**, querying the live log streams generated by your real AWS deployment.

---

## 1. Inspecting Live Execution Logs

Open the AWS Management Console and navigate to **CloudWatch $\to$ Log groups**:
1. Select `/aws/lambda/cloudorder-api-dev-OrderApiFunction-...`
2. Open the latest log stream.

### The Anatomical Log Line: `REPORT`
Every Lambda invocation outputs an authoritative `REPORT` line upon completion:

```text
REPORT RequestId: 98f12a34-b567-4890-a123-456789abcdef
Duration: 84.12 ms    Billed Duration: 85 ms    Memory Size: 1769 MB    Max Memory Used: 142 MB    Init Duration: 421.30 ms
```

#### Key Fields Analyzed:
* **`Duration`**: Actual execution time spent inside your `handleRequest` Java method.
* **`Billed Duration`**: Rounded up to the nearest millisecond.
* **`Memory Size`**: Configured limit (1,769 MB).
* **`Max Memory Used`**: High-water mark of JVM heap + Metaspace + native buffers.
* **`Init Duration`**: Present **only on cold starts**. Measures microVM boot + JVM classloading + static initializers.

## 2. CloudWatch Logs Insights Query Recipes

Navigate to **CloudWatch $\to$ Logs Insights**, select the Lambda log group, and run these production queries:

### Query 1: Calculate Cold Start Rate & Latency Percentiles (P50, P90, P99)
```sql
filter @type = "REPORT"
| stats
    count(@requestId) as TotalInvocations,
    count(InitDuration) as ColdStarts,
    (count(InitDuration) / count(@requestId)) * 100 as ColdStartPercentage,
    avg(@duration) as AvgDurationMs,
    pct(@duration, 50) as P50_Duration,
    pct(@duration, 90) as P90_Duration,
    pct(@duration, 99) as P99_Duration,
    avg(@initDuration) as AvgColdStartMs
```

### Query 2: Find Slowest Invocations & Memory Consumption
```sql
filter @type = "REPORT"
| sort @duration desc
| limit 20
| fields @timestamp, @requestId, @duration, @maxMemoryUsed, @initDuration
```

### Query 3: Search for Unhandled Exceptions & Error Payloads
```sql
fields @timestamp, @message
| filter @message like /(?i)(exception|error|failed)/
| sort @timestamp desc
| limit 50
```
