## 1. `init` options (25.02, 25.06, 25.08)

| Option | TaskFlow | Default |
|---|---|---|
| `fallbackLng` | `'en'` | `'dev'` |
| `supportedLngs` | `['en', 'vi']` | `false` |
| `nonExplicitSupportedLngs` | `true` | `false` |
| `load` | `'languageOnly'` | `'all'` |
| `ns` / `defaultNS` | `['common']` / `'common'` | `'translation'` |
| `interpolation.escapeValue` | `false` (React escapes) | `true` |
| `detection` | see §2 | — |
| `backend.loadPath` | `` `${BASE_URL}locales/{{lng}}/{{ns}}.json` `` | `/locales/{{lng}}/{{ns}}.json` |

## 3. Instance

| Member | Use |
|---|---|
| `t(key, { count, context, defaultValue, ns, lng, …values })` | translate (25.09) |
| `changeLanguage(lng)` | switch, load the namespaces, fire `languageChanged`, cache via the detector (25.07) |
| `language` / `resolvedLanguage` | the raw value (`vi-VN`) / the supported one in use (`vi`) (25.06) |
| `exists(key)` | a key check (the enum coverage test) |
| `loadNamespaces(ns)` | preload (e.g. on hover over "Dashboard") |
| `on('languageChanged', cb)` | side effects: `<html lang>` |
| `createInstance()` | isolated instances (tests) |

## 4. react-i18next

| API | Use |
|---|---|
| `initReactI18next` | the plugin that connects the instance |
| `useTranslation(ns?, { keyPrefix?, useSuspense? })` | `{ t, i18n, ready }` (25.03) |
| `<Trans i18nKey values components>` | translations with React elements inside (25.03 §5) |
| `<I18nextProvider i18n>` | a non-global instance (micro-frontends, tests with rendering) |

## 5. Key conventions in TaskFlow

| Namespace | Keys |
|---|---|
| `common` | `nav.*`, `language.*`, `status.<TaskStatus>`, `priority.<Priority>`, `auth.*`, `notFound.*`, `errors.<CODE>`, `loading`, `tryAgain` |
| `tasks` | `title`, `count_*`, list, `pager.*`, `details.*`, `comments.*` |
| `dashboard` | `title`, `completion.*`, `byStatus`, `byPriority`, `overdue.*` |

Plural keys: `_one`/`_other` in English, `_other` only in Vietnamese.

## 6. `Intl` (25.10)

`DateTimeFormat`, `RelativeTimeFormat` (`numeric: 'auto'`), `NumberFormat`, `PluralRules`, `ListFormat`. TaskFlow's helpers: `formatDate`, `formatRelativeDay`, `formatDue` in `src/i18n/format.ts`.
