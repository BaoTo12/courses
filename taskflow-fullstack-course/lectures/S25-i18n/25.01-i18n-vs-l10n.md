# Lecture 25.01 · i18n vs l10n: What Must Be Translated

> **Section:** S25 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~25 minutes

---

## 1. Two words, two jobs

| | **Internationalisation (i18n)** | **Localisation (l10n)** |
|---|---|---|
| Who | developers, **once** | translators, **per language** |
| What | make the code *able* to show any language: no hard-coded text, formats through APIs, room for longer words | the actual Vietnamese text, and date and number conventions |
| In TaskFlow | `t('nav.tasks')`, `Intl.DateTimeFormat`, plural keys | `public/locales/vi/*.json` |

The numbers count the letters between the first and last: i-*18*-n, l-*10*-n.

## 2. What must change per language

| Thing | English | Vietnamese | How |
|---|---|---|---|
| UI text | "Log out" | "Đăng xuất" | keys + JSON (25.03) |
| Enum values from the API | `DONE` → "Done" | "Hoàn thành" | keys per value (25.13) |
| Server error codes | `BAD_CREDENTIALS` | "Tên đăng nhập hoặc mật khẩu không đúng." | keys per **code**, not per message (25.13) |
| Plurals | 1 task / 5 task**s** | 1 công việc / 5 công việc (one form) | `_one`/`_other` (25.09) |
| Dates | Oct 3, 2026 | day-month-year | `Intl.DateTimeFormat` (25.10) |
| Relative time | tomorrow | Ngày mai | `Intl.RelativeTimeFormat` |
| Numbers | 1,234.5 | 1.234,5 | `Intl.NumberFormat` |
| Word order | "Page 2 of 5" | "Trang 2/5" | whole sentences with placeholders, never concatenation |
| Direction | LTR | LTR | `dir="rtl"` for Arabic/Hebrew (not needed here) |
| `<html lang>` | `en` | `vi` | screen readers pick the voice (25.07) |

## 3. What must NOT be translated

- **Data** the user typed: task titles, comments.
- **Codes and identifiers**: `TODO`, `BAD_CREDENTIALS`, URLs, API field names. The UI *maps* them to text.
- **Logs** for developers. Keep them in one language, so they can be searched.

## 4. The golden rule

> Translate **whole messages with placeholders**, never pieces glued together.

```ts
'Page ' + page + ' of ' + pages          // ❌ the word order is baked in
t('pager.position', { page, pages })     // ✅ "Page {{page}} of {{pages}}" / "Trang {{page}}/{{pages}}"
```

## ✅ Recap

i18n = the code can do any language. l10n = the content of one language. Translate text, enum labels, error codes, plurals, dates and numbers, as whole sentences. Leave user data and codes alone.
