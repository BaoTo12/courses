# Lecture 25.16 · 🐞 Debug: The App Ignores the `tf_lang` Cookie

> **Section:** S25 · **Type:** 🐞 Debug · **Track:** ★ Core · **Time:** ~20 minutes
> Verified by: `src/i18n/i18n.test.ts` ("the cookie beats the browser language"). With either misconfiguration below, it fails.

---

## 1. The report

> "I pick Tiếng Việt, it works. I reload, and it's English again. My browser is English. The switcher is useless."

## 2. The teammate's config

```ts
detection: {
  order: ['navigator', 'cookie'],       // ①
  lookupCookie: 'tf_lang',
  caches: ['localStorage'],              // ②
},
```

## 3. Investigate

1. DevTools → Cookies: after switching to Vietnamese, **no `tf_lang` cookie**, or an old one. Application → Local Storage: `i18nextLng = vi`. The choice was cached, but not where the detector looks for it.
2. Even with the cookie present (set it by hand: `tf_lang=vi`), a reload is English. `order` asks `navigator` **first**, and it always answers (`en-US`), so the cookie is never consulted.

Two independent bugs:

| # | Bug | Effect |
|---|---|---|
| ① | `navigator` before `cookie` | the browser language always wins; the user's choice is ignored |
| ② | `caches: ['localStorage']` | the choice is saved somewhere the detector never reads (localStorage isn't in `order`), and the server can't see it |

## 4. Fix

```ts
order: ['querystring', 'cookie', 'navigator'],   // explicit choices before the browser default
caches: ['cookie'],                              // save where we read, where the server can read
cookieMinutes: 60 * 24 * 365,                    // and not the 10-minute default
```

## 5. Also check

- **`cookieMinutes`**: with the default of 10, the bug appears only after lunch. That's a nice one to find.
- **`lng: 'en'` in `init`**: an explicit `lng` disables detection entirely.
- **`cookieOptions.path`**: a cookie written with a different path isn't visible on other pages (24.18).

## ✅ Takeaway

`order` must put the **user's explicit choice** before the browser's guess, and `caches` must write where `order` reads.
