# Lecture 30.07 · `service()` → `doGet()` / `doPost()`: Reading `HttpServlet`'s Dispatch

> **Section:** S30 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S30ServletsTest.anUnimplementedMethodIs405` (`POST /hello` → 405)

---

## 1. What `HttpServlet.service` does (simplified from its source)

```java
protected void service(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
  String method = req.getMethod();
  switch (method) {
    case "GET"     -> { /* + If-Modified-Since handling via getLastModified() */ doGet(req, resp); }
    case "HEAD"    -> doHead(req, resp);     // default: runs doGet, discards the body, keeps Content-Length
    case "POST"    -> doPost(req, resp);
    case "PUT"     -> doPut(req, resp);
    case "DELETE"  -> doDelete(req, resp);
    case "OPTIONS" -> doOptions(req, resp);  // default: answers Allow: with the doXxx you overrode
    case "TRACE"   -> doTrace(req, resp);
    default        -> resp.sendError(501, "Method … is not implemented by this servlet for this URI");
  }
}
```

(Open it in your IDE: Ctrl+click `HttpServlet` → download the sources. Reading library source is a skill.)

## 2. The defaults for methods you don't override

```java
protected void doPost(HttpServletRequest req, HttpServletResponse resp) … {
  // HTTP/1.1 → 405 Method Not Allowed; HTTP/1.0 → 400
  sendMethodNotAllowed(req, resp, "http.method_post_not_supported");
}
```

So `HelloServlet` (only `doGet`) answers `POST` with **405** automatically. That's the right default: methods you didn't design for are refused. The test checks it.

## 3. What to override

| Override | When |
|---|---|
| `doGet` | reading: pages, lists, forms |
| `doPost` | form submissions (TaskFlow Admin: create, edit, delete, S37) |
| `doPut`, `doDelete`, `doPatch`* | the JSON API (Part 3). *There's no `doPatch` in Servlet 4.0: override `service` and check for `"PATCH"` (S46). |
| `service` | almost never: you'd bypass the dispatch and the 405 defaults |

**Don't** make `doPost` call `doGet` "to accept both". It invites GET requests with side effects (29.03).

## ✅ Recap

`service` dispatches on the method. Override only the `doXxx` you support, and the rest are 405 for free.
