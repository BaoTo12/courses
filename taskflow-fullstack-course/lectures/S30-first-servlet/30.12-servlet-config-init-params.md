# Lecture 30.12 · `ServletConfig` and Init Parameters

> **Section:** S30 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Used in: `TimeServlet` (30.15), init parameter `format`

---

## 1. Per-servlet configuration

Each servlet declaration gets a **`ServletConfig`**: its name, its init parameters, and the `ServletContext`.

```java
@WebServlet(urlPatterns = "/time",
            initParams = @WebInitParam(name = "format", value = "HH:mm:ss, EEEE d MMMM yyyy"))
public class TimeServlet extends HttpServlet {
  private DateTimeFormatter formatter;

  @Override public void init() throws ServletException {
    String pattern = getInitParameter("format");       // shortcut for getServletConfig().getInitParameter(…)
    formatter = DateTimeFormatter.ofPattern(pattern);
  }
}
```

The same in `web.xml`, where it can be changed without recompiling:

```xml
<servlet>
  <servlet-name>time</servlet-name>
  <servlet-class>com.taskflow.web.TimeServlet</servlet-class>
  <init-param>
    <param-name>format</param-name>
    <param-value>HH:mm</param-value>
  </init-param>
</servlet>
```

## 📇 API card: `ServletConfig`

| Method | Returns |
|---|---|
| `getInitParameter(name)` | `String` or `null` |
| `getInitParameterNames()` | `Enumeration<String>` |
| `getServletName()` | the declared name (the class name by default for annotations) |
| `getServletContext()` | the app's `ServletContext` (30.13) |

`GenericServlet` implements `ServletConfig` itself, so inside your servlet you can call `getInitParameter(…)` directly.

## 2. Read in `init()`, once

- Init parameters don't change while the servlet lives, so parse them **once**, into immutable fields.
- **Validate** them and throw `ServletException` if they're wrong. A bad deployment should fail at deployment (`loadOnStartup`) or on first use, clearly (30.05 §4).

## 3. Not for secrets

Init parameters live in class files or `web.xml`, inside the WAR: everyone with the artifact can read them. Database passwords come from the **environment** (the `docker-compose.yml` variables, 28.01) or a container resource (S36).

## ✅ Recap

`ServletConfig` = settings for **one** servlet. Read and validate them in `init()`. Never put secrets there.
