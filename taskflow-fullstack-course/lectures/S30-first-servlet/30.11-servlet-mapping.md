# Lecture 30.11 · Mapping: `@WebServlet` vs `web.xml`; URL Pattern Types and Precedence

> **Section:** S30 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~35 minutes
> 🔗 Reference: Servlet 4.0 specification, chapter 12 ("Mapping Requests to Servlets")

---

## 1. Two ways to declare the same thing

```java
@WebServlet(name = "hello", urlPatterns = "/hello", loadOnStartup = 1)
public class HelloServlet extends HttpServlet { … }
```

```xml
<servlet>
  <servlet-name>hello</servlet-name>
  <servlet-class>com.taskflow.web.HelloServlet</servlet-class>
  <load-on-startup>1</load-on-startup>
</servlet>
<servlet-mapping>
  <servlet-name>hello</servlet-name>
  <url-pattern>/hello</url-pattern>
</servlet-mapping>
```

| | Annotation | `web.xml` |
|---|---|---|
| Where | next to the code | one central file |
| Change the URL without recompiling | ❌ | ✅ |
| Map a class you don't own (a library's servlet) | ❌ | ✅ |
| TaskFlow | servlets (readable, one place per class) | filters' **order** (S39), error pages, session config |

If both declare the same servlet name, `web.xml` wins (it overrides the annotation). `metadata-complete="true"` on `<web-app>` turns annotation scanning off.

## 2. The four pattern types

| Pattern | Kind | Matches | Example |
|---|---|---|---|
| `/tasks` | **exact** | only `/tasks` | `/tasks` ✅, `/tasks/` ❌, `/tasks/5` ❌ |
| `/tasks/*` | **path prefix** | `/tasks`, `/tasks/`, `/tasks/5/edit`… | pathInfo = the rest |
| `*.do` | **extension** | any path ending in `.do` | `/a/b/save.do` |
| `/` | **default** | anything nothing else matched | Tomcat's `DefaultServlet` (static files) |
| `""` | context root | exactly `/taskflow/` | rarely used |

## 3. Precedence: the most specific wins

For `/taskflow/tasks/view.do`:

```text
1. exact match?                      /tasks/view.do           → no
2. longest path prefix?              /tasks/* (vs /*)         → YES → that servlet (even though *.do also matches)
3. extension?                        *.do                     → only if no prefix matched
4. default servlet                   /
```

Traps:
- **`/*`** is a path prefix matching **everything**, including your JSPs (`/WEB-INF/views/x.jsp` forwards go through mappings too). A servlet on `/*` swallows the `DefaultServlet` and the `JspServlet`. Use `/*` for **filters**, and almost never for servlets.
- Mapping your own servlet to **`/`** replaces the `DefaultServlet`: your CSS stops loading.
- **Two servlets with the same pattern:** Tomcat 9 **refuses to deploy** the app ("The servlets named [a] and [b] are both mapped to the url-pattern [/tasks] which is not permitted"). That's a knowledge-check question.

## ✅ Recap

Annotations for your servlets, `web.xml` for ordering and overrides. Exact → longest prefix → extension → default. Keep servlets off `/*` and `/`.
