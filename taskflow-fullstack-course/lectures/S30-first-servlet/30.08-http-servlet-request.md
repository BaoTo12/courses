## 1. Splitting the URL

Request: `GET http://localhost:8080/taskflow/debug/request-info/a/b?x=1&x=2`, with the servlet mapped to `/debug/request-info/*`:

| Method | Value | Meaning |
|---|---|---|
| `getRequestURL()` | `http://localhost:8080/taskflow/debug/request-info/a/b` | the full URL, without the query |
| `getRequestURI()` | `/taskflow/debug/request-info/a/b` | the path as sent (still URL-encoded) |
| `getContextPath()` | `/taskflow` | which app (`""` for ROOT) |
| `getServletPath()` | `/debug/request-info` | the part that matched the mapping |
| `getPathInfo()` | `/a/b` | what's left after the servlet path (`null` if nothing) |
| `getQueryString()` | `x=1&x=2` | raw, undecoded |
| `getParameter("x")` | `1` | the **first** value, decoded |
| `getParameterValues("x")` | `["1", "2"]` | all values |

Invariant: `requestURI = contextPath + servletPath + pathInfo`.

With an **exact** mapping (`/debug/request-info`), `getPathInfo()` is `null`. Both cases are in the test.

## 📇 API card: what you'll call most

| Method | Returns | Notes |
|---|---|---|
| `getMethod()` | `"GET"`, `"POST"`, … | |
| `getParameter(name)` / `getParameterValues` / `getParameterMap` | `String` / `String[]` / `Map<String, String[]>` | query + urlencoded body merged (29.06); `null` if absent |
| `getHeader(name)` / `getHeaders(name)` / `getHeaderNames()` | `String` / `Enumeration` | case-insensitive names |
| `getCookies()` | `Cookie[]` or **`null`** (no cookies!) | S38 |
| `getSession()` / `getSession(false)` | `HttpSession` / `null` if none | S38 |
| `getRemoteAddr()` | the client IP (or the proxy's) | behind a proxy: `RemoteIpValve` (S49) |
| `getLocale()` / `getLocales()` | from `Accept-Language` | S44 |
| `getContentType()`, `getCharacterEncoding()`, `setCharacterEncoding("UTF-8")` | | set the encoding **before** reading parameters (S39's filter) |
| `getReader()` / `getInputStream()` | the raw body | JSON (Part 3); not both, and not after `getParameter` consumed a form body |
| `setAttribute` / `getAttribute` | `Object` | per-request data for forwards (S31) |
| `getRequestDispatcher(path)` | a dispatcher | forward/include (S31) |

## ✅ Recap
