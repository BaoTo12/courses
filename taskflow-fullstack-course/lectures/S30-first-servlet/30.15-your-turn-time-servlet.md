# Lecture 30.15 · 🎯 Your Turn: A `/time` Servlet with an Init Parameter and a Context Parameter

> **Section:** S30 · **Type:** 🎯 Your Turn · **Track:** ★ Core · **Time:** ~40 minutes

## Requirements

1. `GET /taskflow/time` shows an HTML page with a **greeting** heading and the **current server time**.
2. The time **format** is an **init parameter** named `format` (a `DateTimeFormatter` pattern), declared with the servlet.
3. The greeting is a **context parameter** named `greeting` in `web.xml`, with Vietnamese text: `Xin chào từ TaskFlow!`.
4. The page is correct **UTF-8**: the Vietnamese greeting displays properly in the browser and in `curl`.
5. An invalid `format` pattern must fail **clearly**, once, not with a stack trace on every request.
6. Escape what you write into HTML.
7. Thread-safe: remember there's one instance for all requests.

## Test it

Add a test to `S30ServletsTest` (or your own `TomcatTest` subclass) asserting that the body contains `<h1>Xin chào từ TaskFlow!</h1>`.

## Hints

<details><summary>Where to parse the format</summary>

In `init()`: `DateTimeFormatter` is immutable, so one instance can serve all threads. Wrap `IllegalArgumentException` in a `ServletException`.
</details>

<details><summary>The charset</summary>

`setContentType("text/html;charset=UTF-8")` **before** `getWriter()` (30.09 §3). And `web.xml` itself must be saved as UTF-8 (its XML declaration says so).
</details>
