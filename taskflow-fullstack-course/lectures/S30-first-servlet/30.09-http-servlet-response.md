# Lecture 30.09 · `HttpServletResponse`: Status, Headers, Body, and "Committed"

> **Section:** S30 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~35 minutes
> Verified: `S30ServletsTest` (`Content-Type: text/html;charset=UTF-8` exactly as set; UTF-8 bodies)

## 📇 API card

| Method | Effect |
|---|---|
| `setStatus(int)` | the status code (default **200**) |
| `sendError(int[, msg])` | status + the container's error page (S43); **commits** the response |
| `sendRedirect(url)` | 302 + `Location`; **commits** (S31) |
| `setContentType("text/html;charset=UTF-8")` | the `Content-Type` header, **and** the charset for `getWriter()` |
| `setCharacterEncoding("UTF-8")` | just the charset part |
| `setHeader(name, value)` / `addHeader` / `setIntHeader` / `setDateHeader` | set (replace) or add a header |
| `addCookie(Cookie)` | a `Set-Cookie` header (S38) |
| `getWriter()` | a `PrintWriter` for **text**, encoded with the current charset |
| `getOutputStream()` | a `ServletOutputStream` for **bytes** (files, images, PDFs) |
| `setBufferSize(int)` / `flushBuffer()` / `isCommitted()` / `reset()` | buffer control |

## 1. `getWriter()` vs `getOutputStream()`: pick one

- Text (HTML, JSON): `getWriter()`. It converts characters to bytes with the charset.
- Binary: `getOutputStream()`.
- Calling **both** on one response → `IllegalStateException: getWriter() has already been called for this response`. JSPs use the writer, so a servlet that forwards to a JSP must not have touched the output stream.

## 2. The buffer and "committed"

```text
your println(…) ──► response BUFFER (8 KB by default) ──flush──► socket: status line + headers, then body
```

- While everything is still in the buffer, you can change your mind: set another status, add headers, `reset()`, or redirect.
- The response is **committed** when the first bytes are sent: the buffer filled up, you called `flushBuffer()`, or `sendError`/`sendRedirect` ran. After that, the status and headers are **on the wire**, and `setStatus`, `setHeader` and `sendRedirect` can't change them. `sendRedirect` then throws `IllegalStateException` (30.18).

**The rule:** decide the status, the headers and any redirect **before** writing the body. In MVC (S36), the servlet decides and the JSP writes, so this happens naturally.

## 3. Order matters for the charset

```java
response.setContentType("text/html;charset=UTF-8");   // 1. charset first
PrintWriter out = response.getWriter();                // 2. the writer is created with UTF-8
```

Swapped, the writer is created with the **default** (ISO-8859-1), and Vietnamese turns into `?` (30.17).

## ✅ Recap

Status and headers first, then the body. `getWriter` for text (after the charset), `getOutputStream` for bytes, never both. Once committed, the head of the response is final.
