# Lecture 39.01 · The Problem: Copy-Pasted Headers and Navs Across Ten Pages

> **Section:** S39 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~10 minutes

---

TaskFlow Admin now has **eight** pages: list, details, the task form (create and edit), categories, the dashboard, and three debug pages. Each needs the same `<head>`, stylesheet, brand, navigation, flash message and footer. Some share bigger pieces: the task row appears on the list **and** the dashboard, and the error summary fits every form.

What copy-paste costs:

| Change | With copies | With one shared piece |
|---|---|---|
| add a nav link ("Dashboard") | edit 8 files, miss one | edit `nav.jspf` |
| fix an escaping bug in the task row | fix it twice, or leave an XSS in one copy | fix it once |
| highlight the current section | 8 variations | one rule in one fragment |
| switch the theme | every `<html>` tag | `header.jspf` |

JSP offers three ways to share view code, and this section uses the first two:

| Mechanism | When it's joined | Lecture |
|---|---|---|
| `<%@ include file="…" %>` | **translation** time: the text is pasted into the page | 39.02 |
| `<jsp:include page="…"/>` | **request** time: another JSP runs and its output is inserted | 39.03 |
| tag files (`<tf:taskRow task="${task}"/>`) | a custom tag with declared attributes | 39.07 (＋), S44 |

## ✅ Recap

Every repeated piece of markup is a place where a fix can be missed. Share it once. The question is only *how*, which the next lectures answer.
