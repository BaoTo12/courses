# Lecture 39.04 · Side by Side: Include Directive vs `<jsp:include>`

> **Section:** S39 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes

---

| | `<%@ include file %>` | `<jsp:include page>` |
|---|---|---|
| joined at | translation | request time |
| generated code | the fragment's `out.write(…)` calls **inline** | `JspRuntimeLibrary.include(request, response, "…", out, false)` |
| servlets | one | two (or more) |
| page scope / variables | **shared** | separate |
| request attributes and params | shared | shared, plus `<jsp:param>` |
| taglib prefixes | inherited from the page (declaring again with the same URI is allowed) | must be declared in the included page |
| path decided | when written (a constant) | can be an expression (`page="${…}"`) |
| a fragment change is picked up | the **including** pages are re-translated (via `_jspx_dependants`) | only the included JSP is re-translated |
| per-request cost | none | a dispatch |
| the same fragment twice in one page | pasted twice (39.12's trap with declarations) | two calls, independent |

## TaskFlow's choices

| Piece | Mechanism | Why |
|---|---|---|
| `header.jspf`, `nav.jspf`, `footer.jspf` | directive | the skeleton; uses the page's `pageTitle`, `theme` and `csrfToken` |
| `tasks/task-row.jspf` | directive, inside `<c:forEach>` | needs the loop's `task` and `row` (page scope) |
| `common/flash.jsp` | `<jsp:include>` | a self-contained widget; reads only a request attribute |
| `common/form-errors.jsp` | `<jsp:include>` + `<jsp:param name="title">` | reusable on any form page, with a per-page title |

## ✅ Recap

Directive = paste text, one servlet, shared variables. Action = call another servlet, shared request only. Choose by what the fragment needs to see.
