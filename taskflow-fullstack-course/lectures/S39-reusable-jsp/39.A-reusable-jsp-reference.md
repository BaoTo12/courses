## 1. Include mechanisms

| | `<%@ include file="…" %>` | `<jsp:include page="…"/>` |
|---|---|---|
| joined | translation | request time |
| shares | everything (one method) | the request only |
| data in | the page's variables | request attributes, `<jsp:param>` → `${param.x}` |
| path | constant | may be `${…}` |
| TaskFlow | `header.jspf`, `nav.jspf`, `footer.jspf`, `task-row.jspf` | `flash.jsp`, `form-errors.jsp` |

## 2. Original request data after a forward (39.08)

`requestScope['javax.servlet.forward.request_uri' | '…context_path' | '…servlet_path' | '…path_info' | '…query_string']`. After an include: `javax.servlet.include.*`.

## 3. Cookies (39.09)

`new Cookie(name, value)` · `setPath` · `setMaxAge` (`0` deletes, `-1` session) · `setHttpOnly` · `setSecure` · `response.addCookie` · `${cookie.name.value}`. Always allow-list cookie values before using them in HTML.
