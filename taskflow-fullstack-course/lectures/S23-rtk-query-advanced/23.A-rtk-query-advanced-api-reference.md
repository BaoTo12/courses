## 5. TaskFlow's decisions at the end of S23

| Endpoint | Strategy |
|---|---|
| `getTasks` | items + LIST tags; seeds `getTask(id)` |
| `patchTask` | optimistic on every cached list + detail; undo on error; id invalidation on success |
| `deleteTask` | optimistic removal; undo on error; id + LIST invalidation |
| `updateTask` | pessimistic: writes the PUT answer into `getTask(id)`; LIST invalidation |
| `addTask`, `clearCompleted` | LIST (and the deleted ids) invalidation |
| comments | injected in `commentsApi.ts`; prefetched on hover |
| logout | `clearUserData()` = `loggedOut()` + `resetApiState()` |
