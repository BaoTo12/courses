# Lecture 17.06 · TS: `RootState`, `AppDispatch`, and Typed `useAppSelector` / `useAppDispatch`

> **Section:** S17 · **Type:** 📖 Theory + 🛠 Build · **Track:** ★ Core · **Time:** ~20 minutes
> 🔗 Official companion reading: the Redux docs page "Usage with TypeScript" (React-Redux section); React-Redux 9's `withTypes`

---

## 1. The problem with the plain hooks

```tsx
const count = useSelector((state) => state.tasks.items.length);
//                         ^^^^^ unknown: the plain hook doesn't know TaskFlow's state shape
```

You could annotate every call (`(state: RootState) => …`), but that's repetitive, and nothing forces anyone to do it. Worse, `useDispatch()` returns a generic `Dispatch`, which won't accept thunks in S18.

## 2. The two app types (both derived, never hand-written)

From `src/app/rootReducer.ts` (16.03) and `src/app/store.ts` (16.11):

```ts
export type RootState = { [K in keyof typeof sliceReducers]: ReturnType<(typeof sliceReducers)[K]> };
export type AppStore = ReturnType<typeof makeStore>;
export type AppDispatch = AppStore['dispatch'];
```

`AppDispatch` is the **real** type of the store's dispatch, including whatever the middleware adds. In S18, the thunk middleware adds "accepts a function", and `AppDispatch` picks that up automatically.

## 3. ✍️ `src/app/hooks.ts`

```ts
import { useDispatch, useSelector } from 'react-redux';
import type { AppDispatch } from './store';
import type { RootState } from './rootReducer';

// Typed versions of the React-Redux hooks (17.06). Use these everywhere instead of the plain ones:
// the state and dispatch types are declared once, here, not in every component.
export const useAppSelector = useSelector.withTypes<RootState>();
export const useAppDispatch = useDispatch.withTypes<AppDispatch>();
```

`.withTypes<…>()` (React-Redux 9.1+) returns the same hook with the type parameter fixed. Older code does the same with explicit signatures:

```ts
// the pre-9.1 way, still common in codebases
export const useAppSelector: TypedUseSelectorHook<RootState> = useSelector;
export const useAppDispatch: () => AppDispatch = useDispatch;
```

Now:

```tsx
const count = useAppSelector((state) => state.tasks.items.length); // state: RootState, count: number
const dispatch = useAppDispatch();                                  // AppDispatch
dispatch(sortChanged('title', 'asc'));                              // ✅
dispatch(sortChanged('createdAt', 'asc'));                          // ❌ compile error (15.13)
```

Team rule (and the official recommendation): **import `useAppSelector`/`useAppDispatch` in components, never the plain hooks.** Enforce it with a lint rule. ✍️ `.oxlintrc.json` (verified with oxlint 1.85):

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "plugins": ["react", "typescript", "oxc"],
  "rules": {
    "react/rules-of-hooks": "error",
    "react/only-export-components": ["warn", { "allowConstantExport": true }],
    "no-restricted-imports": [
      "error",
      {
        "paths": [
          {
            "name": "react-redux",
            "importNames": ["useSelector", "useDispatch"],
            "message": "Use useAppSelector / useAppDispatch from src/app/hooks.ts (17.06)."
          }
        ]
      }
    ]
  },
  "overrides": [
    {
      "files": ["src/app/hooks.ts"],
      "rules": { "no-restricted-imports": "off" }
    }
  ]
}
```

A page importing the plain hook now fails `npm run lint`:

```text
error eslint(no-restricted-imports): 'useSelector' import from 'react-redux' is restricted.
help: Use useAppSelector / useAppDispatch from src/app/hooks.ts (17.06).
```

The `overrides` entry exempts the one file that must import them.

## 4. Why `hooks.ts` is separate from `store.ts`

Components import `hooks.ts`, which imports **types only** from `store.ts` (`import type`, erased at compile time). If components imported the hooks from `store.ts` itself, every component would import the store **module**, including its middleware setup, making tests and circular imports harder. The official template uses the same split.

## 5. Summary

- `RootState` from the reducers; `AppDispatch` from the store.
- `useSelector.withTypes<RootState>()` and `useDispatch.withTypes<AppDispatch>()` in `app/hooks.ts`.
- Components use only the typed hooks.
