# Lecture 17.08 · Global State vs Component State; Form Drafts Stay Local Until Submit

> **Section:** S17 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes
> 🔗 Official companion reading: Fundamentals Part 5 ("Global State, Component State, and Forms"); Style Guide: "Avoid Putting Form State In Redux"

---

## 1. The question to ask

For each piece of state: **does any other part of the app care about this value?**
- **No** → keep it in the component (`useState`/`useReducer`).
- **Yes** → consider Redux (or the URL, 14.03).

Redux doesn't make local state obsolete. A Redux app still has plenty of `useState`.

## 2. TaskFlow after S17

| State | Where | Why |
|---|---|---|
| Tasks, load status, error | Redux `tasks` | Read by the list, details, edit, dashboard and header badge |
| Selection, toasts (S20) | Redux `ui` | Several components, and non-React code |
| Status filter, search text, view mode | URL | Shareable, reload-safe (S12) |
| `TaskForm` values, touched fields, submit lock | **`TaskForm` local state** | Only the form cares, until submit |
| Inline title draft on a card | `TaskCard` local state | Only that card cares |
| `isDeleting` on the details page | Local state | UI detail of one page |
| The fake logged-in user | `AuthProvider` context | Replaced by a Redux `auth` slice in S24 |

## 3. Why form drafts stay local

- **Performance:** each keystroke would dispatch an action, run every reducer, and run every `useSelector` in the app (17.04), for data only one form needs.
- **Nothing else needs a half-typed title.** When the form **submits**, the result becomes an event (`tasks/taskAdded` with the server's task).
- **Cancel is free:** unmount the form and the draft disappears. With a draft in Redux, you'd need a "draft discarded" action and a reset.
- **Validation state** (touched, submit attempted, errors) is pure UI.

Exceptions exist: a multi-step wizard across routes, or "restore my unsaved draft after a reload". Even then, save the draft when leaving a step or on an interval, not on every keystroke.

## 4. Summary

- "Does anyone else care?" decides local vs global.
- Form drafts, dialogs, and one-component UI flags stay local; the **submitted** result becomes an event.
