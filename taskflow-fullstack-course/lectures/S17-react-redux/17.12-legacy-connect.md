# Lecture 17.12 · ＋ Legacy `connect()` and `mapStateToProps`: Reading Older Code

> **Section:** S17 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~30 minutes
> 🔗 Reference: the React-Redux docs, "connect" API pages
> Verified: the example below type-checked against react-redux 9.3.0 and rendered inside TaskFlow's `<Provider>` (results in §3). It's kept **out** of the app's source.

---

## 1. Why learn it

Hooks arrived in React-Redux 7.1 (2019). Codebases older than that, and many written since by habit, use `connect()`: a **higher-order component** (HOC) that wraps your component and injects props from the store. It still works in React-Redux 9. You'll meet it at work, so you need to read it fluently.

## 2. The same badge, written with `connect`

```tsx
// 17.12 (＋): the same "open tasks" badge written the LEGACY way, with connect().
// For reading older code only: new code uses hooks (OpenTasksBadge.tsx).
import { connect } from 'react-redux';
import type { ConnectedProps } from 'react-redux';
import type { RootState } from '../../app/rootReducer';
import { selectionCleared } from '../ui/uiSlice';
import { selectOpenTaskCount } from './tasksSlice';

/** State → props. Runs after every dispatch; the component re-renders if the result is shallowly different. */
const mapStateToProps = (state: RootState) => ({
  openCount: selectOpenTaskCount(state),
  selectedCount: state.ui.selectedTaskIds.length,
});

/** Object shorthand: each action creator is wrapped in dispatch and passed as a prop. */
const mapDispatchToProps = { onClearSelection: selectionCleared };

const connector = connect(mapStateToProps, mapDispatchToProps);

/** The props the connected component receives: inferred from the connector. */
type Props = ConnectedProps<typeof connector>;

function LegacyOpenCountView({ openCount, selectedCount, onClearSelection }: Props) {
  return (
    <span>
      {openCount} open · {selectedCount} selected{' '}
      <button type="button" onClick={onClearSelection}>
        Clear selection
      </button>
    </span>
  );
}

export const LegacyOpenCount = connector(LegacyOpenCountView);
```

| `connect` concept | Hooks equivalent |
|---|---|
| `mapStateToProps(state) → { … }` | one or more `useSelector` calls |
| `mapDispatchToProps` (object shorthand: action creators) | `useDispatch()` + calling `dispatch(creator())` |
| `connect(mapState, mapDispatch)(Component)` | calling the hooks inside the component |
| `ConnectedProps<typeof connector>` | types come from the hooks' return values |
| Re-render when the `mapStateToProps` result is **shallowly** different | re-render when a `useSelector` result is `!==` |

Key differences to remember when reading `connect` code:
- **Shallow equality by default.** `mapStateToProps` returns a new object every time, and `connect` compares it **key by key**. So `{ openCount, selectedCount }` doesn't cause extra renders as long as each value is unchanged. With `useSelector`, returning that same object literal **would** (17.04).
- **Props come from outside the component.** When debugging, look for the `connect(...)` call at the bottom of the file to find where a prop comes from.
- **`mapDispatchToProps` as an object** wraps each action creator: `props.onClearSelection()` dispatches `selectionCleared()`.

## 3. 🔬 Rendered inside TaskFlow's `<Provider>`

| Step | Text |
|---|---|
| Initial | `17 open · 0 selected` |
| Two `ui/taskSelectionToggled` dispatches from the console | `17 open · 2 selected` |
| Click "Clear selection" (the prop from `mapDispatchToProps`) | `17 open · 0 selected`, and the store's `selectedTaskIds` was `[]` |

### A cost the linter showed

oxlint's Fast Refresh rule warned on this file: *"Fast refresh only works when a file only exports components."* The exported `LegacyOpenCount` is the **result of a function call** (`connector(View)`), which static analysis can't recognise as a component. HOCs are harder for tools (and people) to follow, which is one reason the ecosystem moved to hooks.

## 4. Converting `connect` to hooks (a common refactor)

```tsx
export function OpenCount() {
  const openCount = useAppSelector(selectOpenTaskCount);
  const selectedCount = useAppSelector((state) => state.ui.selectedTaskIds.length);
  const dispatch = useAppDispatch();
  return (
    <span>
      {openCount} open · {selectedCount} selected{' '}
      <button type="button" onClick={() => dispatch(selectionCleared())}>Clear selection</button>
    </span>
  );
}
```

Split `mapStateToProps` into one `useSelector` per value (or keep one object and pass `shallowEqual`), replace injected callbacks with `dispatch` calls, and delete the `connect` wrapper. Do it one component at a time. Both styles work side by side under the same `Provider`.

## 5. Summary

- `connect(mapState, mapDispatch)(Component)`: a HOC injecting store data and dispatching callbacks as props.
- It compares `mapStateToProps` results **shallowly**; `useSelector` uses `===`.
- Read it fluently; write hooks.
