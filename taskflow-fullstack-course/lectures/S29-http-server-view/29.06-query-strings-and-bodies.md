# Lecture 29.06 · Query Strings, Form Bodies, URL Encoding, Multipart, JSON

> **Section:** S29 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~35 minutes

## 1. Four ways data travels in a request

| Where | Looks like | Sent by | Servlet API |
|---|---|---|---|
| **Query string** | `GET /tasks?status=TODO&q=report+q3` | links, GET forms, `fetch` | `request.getParameter("status")` |
| **Form body** (urlencoded) | `POST` body `title=Plan+offsite&priority=HIGH` | `<form method="post">` | `request.getParameter("title")`, **the same method** |
| **Multipart** | `POST` body in parts with a boundary | `<form enctype="multipart/form-data">` (file upload) | `request.getPart("file")` (`@MultipartConfig`) |
| **JSON body** | `POST` body `{"title":"Plan offsite"}` | JavaScript (Axios) | `request.getReader()` + Jackson (Part 3). **Not** `getParameter`. |

`getParameter` merges the query string and a **urlencoded** body. It knows nothing about JSON. A classic Part 3 surprise: `getParameter("title")` is `null` for Axios requests.

## 2. URL encoding (percent-encoding)

Some characters have meaning in URLs (`?`, `&`, `=`, `#`, `/`, space), and URLs are ASCII. Everything else is encoded as `%` + hex bytes of its **UTF-8** encoding:

| Text | Encoded |
|---|---|
| `report q3` | `report%20q3`, or `report+q3` in form encoding |
| `a&b=c` | `a%26b%3Dc` |
| `Công` | `C%C3%B4ng` |
| `<script>` | `%3Cscript%3E` |

- The container **decodes** for you: `getParameter("q")` returns `report q3`.
- When you **build** URLs in Java (redirects with parameters, S31), encode each value: `URLEncoder.encode(value, StandardCharsets.UTF_8)`. Otherwise `&` in a value becomes a new parameter: **parameter injection**.

## 3. What a form actually sends

```html
<form method="post" action="/taskflow/tasks/new">
  <input name="title" value="Plan offsite">
  <select name="priority"><option selected>HIGH</option></select>
  <input type="checkbox" name="urgent">              <!-- unchecked → NOT SENT AT ALL -->
  <input type="hidden" name="categoryId" value="2">  <!-- hidden ≠ secure: the user can change it (29.09) -->
</form>
```

```http
POST /taskflow/tasks/new HTTP/1.1
Content-Type: application/x-www-form-urlencoded
Content-Length: 43

title=Plan+offsite&priority=HIGH&categoryId=2
```

- Unchecked checkboxes and disabled fields are **absent**: `getParameter("urgent") == null`.
- Repeated names (`<select multiple>`) → `getParameterValues("tag")` returns an array.
- Everything is a **string**. Converting and validating is your job (S37).

## 4. multipart/form-data, briefly

```http
Content-Type: multipart/form-data; boundary=----X
------X
Content-Disposition: form-data; name="title"

Report
------X
Content-Disposition: form-data; name="file"; filename="q3.pdf"
Content-Type: application/pdf

%PDF-1.7 …binary…
------X--
```

It's only needed for files. The Servlet 3.0+ API parses it (`@MultipartConfig`, `request.getParts()`). TaskFlow has no uploads, but you'll recognise it.

## ✅ Recap

Query string and urlencoded body → `getParameter`. JSON → read the body yourself. Values arrive as decoded strings. Encode when you build URLs, and validate everything you read.
