# Lecture 29.11 · 🎯 Your Turn: Capture and Annotate Five HTTP Exchanges

> **Section:** S29 · **Type:** 🎯 Your Turn · **Track:** ★ Core · **Time:** ~45 minutes
> Solution: [`solutions/S29-http-server-view/29.12-solution.md`](../../solutions/S29-http-server-view/29.12-solution.md)

---

Capture each exchange with `curl -v` or DevTools, paste it into a file `http-notes.md`, and annotate **every line**: what it is, and who set it (browser, curl, your code, the container).

| # | Exchange | How |
|---|---|---|
| 1 | **Page load**: TaskFlow Admin's start page | `curl -v http://localhost:8080/taskflow/` |
| 2 | **Form POST**: a urlencoded body | `curl -v -d 'title=Hello world&priority=HIGH' http://localhost:3001/api/tasks` |
| 3 | **Redirect**: a 30x with `Location` | `curl -v http://localhost:8080/taskflow` (no trailing slash) |
| 4 | **404** | `curl -v http://localhost:8080/taskflow/WEB-INF/web.xml` |
| 5 | **JSON call from TaskFlow Web**: logged in, the tasks list | DevTools → Network → `tasks?…` → Headers + Response |

For each one, answer:

1. Method, path, query, and the HTTP version.
2. Which request headers came from the **client program**, and which from **you**?
3. Status: what does it tell the client to do next?
4. Content-Type and the length of the body. Is there a charset?
5. Any cookies sent or set? With which attributes?
6. (Exchange 5) Where are `X-XSRF-TOKEN` and `X-Request-Id`, and which code added them (24.11, 13.08)?

**Bonus:** exchange 1 again with `ncat` (29.02 §3), typed by hand.
