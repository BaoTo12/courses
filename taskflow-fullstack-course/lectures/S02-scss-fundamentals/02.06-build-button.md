# Lecture 02.06 · 🛠 Build: the Button Component

> **Section:** S02 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~25 minutes
> **Project feature:** `styles/components/_button.scss`: `.btn`, `.btn--primary`, `.btn--secondary`, hover, focus, disabled

---

## 1. Design requirements

| Variant | Background | Text | Border | Hover |
|---|---|---|---|---|
| `.btn--primary` | primary | white | none | darker primary |
| `.btn--secondary` | surface (white) | text | border colour | light grey background |

All buttons:
- Same height/padding, rounded corners, medium font weight.
- A visible **keyboard focus ring** (accessibility: users navigating with Tab must see where they are).
- A clear **disabled** state (reduced opacity, `not-allowed` cursor, no hover change).
- Smooth colour transition.

---

## 2. ✍️ Write `styles/components/_button.scss`

```scss
@use '../abstracts/variables' as *;

.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: $space-2;
  padding: $space-2 $space-4;
  border: 1px solid transparent;
  border-radius: $radius-md;
  font-size: $font-size-sm;
  font-weight: $font-weight-medium;
  line-height: 1.25;
  text-decoration: none;
  cursor: pointer;
  transition: background-color 150ms ease, border-color 150ms ease, color 150ms ease;

  // Keyboard focus only (not on mouse click): :focus-visible
  &:focus-visible {
    outline: 2px solid $color-primary;
    outline-offset: 2px;
  }

  &:disabled,
  &[aria-disabled='true'] {
    opacity: 0.5;
    cursor: not-allowed;
  }

  & + & {
    margin-left: $space-2;
  }

  // ── Variants ────────────────────────────────────────────────
  &--primary {
    background: $color-primary;
    color: #fff;

    &:hover:not(:disabled) {
      background: $color-primary-dark;
    }
  }

  &--secondary {
    background: $color-surface;
    color: $color-text;
    border-color: $color-border;

    &:hover:not(:disabled) {
      background: $color-background;
    }
  }
}
```

### Line-by-line: why it's written this way

- **`@use '../abstracts/variables' as *;`**: every partial that uses tokens must load them itself. (Why? Lecture 02.07. It's the most common Sass module mistake; you'll debug it in 02.12.)
- **`display: inline-flex` + `gap`**: buttons often contain an icon + text; flexbox aligns them and `gap` spaces them.
- **`border: 1px solid transparent`**: primary buttons have no visible border, but reserving 1px keeps primary and secondary buttons exactly the same size.
- **`&:focus-visible`** vs `&:focus`: `:focus-visible` shows the ring for keyboard focus but not for mouse clicks. It's accessible without annoying mouse users. **Never** remove focus outlines without replacing them.
- **`&[aria-disabled='true']`**: links styled as buttons (`<a class="btn">`) can't be `disabled`; `aria-disabled` covers them.
- **`&:hover:not(:disabled)`**: without `:not(:disabled)`, a disabled primary button would still darken on hover and look clickable.
- **Nested hover inside the modifier**: compiles to `.btn--primary:hover:not(:disabled)`, one class plus pseudo-classes. Specificity stays low, (0,3,0).

### Compiled output (excerpt)

```css
.btn--primary {
  background: #4f46e5;
  color: #fff;
}
.btn--primary:hover:not(:disabled) {
  background: #4338ca;
}
```

## 3. Load it in `main.scss`

```scss
@use 'base/reset';
@use 'abstracts/variables' as *;
@use 'components/button';

body {
  font-family: $font-family-base;
  background: $color-background;
  color: $color-text;
}
```

Save, then refresh `ui-kit/index.html`. The **Buttons** section now shows styled buttons. (The `btn--danger` and `btn--sm` buttons are still plain; they're part of the S02 knowledge check.)

---

## 4. Verify with DevTools

1. Inspect the **Save task** button. In **Styles**, you should see `.btn--primary` from `_button.scss` and `.btn` from `_button.scss`.
2. Press **Tab** until the button is focused: the outline appears. Click it with the mouse: no outline (that's `:focus-visible` at work).
3. In the Styles pane, click `:hov` and force `:hover` state to inspect the hover rule without moving the mouse.
4. Inspect the **Disabled** button: hovering it doesn't change the background.

## 6. Summary

- `.btn` base + `&--primary` / `&--secondary` modifiers, all single-class selectors.
- Accessibility built in: `:focus-visible` ring, disabled/`aria-disabled` state, hover only when enabled.
- Every partial `@use`s the tokens it needs.
