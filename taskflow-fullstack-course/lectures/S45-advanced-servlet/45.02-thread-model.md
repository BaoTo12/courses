# Lecture 45.02 · The Thread Model: One Servlet Instance, Many Threads

> **Section:** S45 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S45AdvancedServletTest.anInstanceFieldMixesUpConcurrentRequests`

---

## 1. The model

Tomcat creates **one** instance of each servlet (and filter, and listener). Every request to it runs `service()` → `doGet()` on **its own worker thread**, at the same time as the others:

```text
thread http-nio-8080-exec-3  ─► TaskListServlet.doGet(alice's request)
thread http-nio-8080-exec-7  ─► TaskListServlet.doGet(bob's request)       ← the same object, simultaneously
thread http-nio-8080-exec-9  ─► TaskListServlet.doGet(admin's request)
```

## 2. Shared or not

| Thing | Shared between concurrent requests? | Safe to write per request? |
|---|---|---|
| local variables, parameters of `doGet` | ❌ each thread has its own stack | ✅ |
| the `request` and `response` objects | ❌ one per request | ✅ (don't hand them to other threads, 45.13) |
| request attributes | ❌ | ✅ |
| **servlet / filter / listener fields** | ✅ **one instance for all** | ❌ unless thread-safe |
| session attributes | ✅ between the **same user's** concurrent requests (two tabs, parallel AJAX) | ⚠️ with care (38.03) |
| context attributes, services, caches, static fields | ✅ everyone | ❌ unless thread-safe |

## 3. What TaskFlow keeps in fields

| Field | Why it's fine |
|---|---|
| `private TaskService service;` (set in `init`) | written **once** before any request; never changed; `TaskService` itself has no per-request state |
| `AppStats` counters | `LongAdder`, `AtomicInteger`, `ConcurrentHashMap` (38.07) |
| `CategoryCatalog`, `AccountRegistry` | a `volatile` reference to an **immutable** snapshot, replaced whole (38.06) |
| `LoginThrottle` windows | `ConcurrentHashMap.compute` (41.15) |
| `SessionRegistry` | `ConcurrentHashMap` (45.09) |

## ✅ Recap

Per-request data lives in locals and the request. Fields hold only things set once, or objects built for concurrent use.
