# Lecture 45.11 · Request Dispatching in Depth

> **Section:** S45 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

## 📇 API card: `RequestDispatcher`

| Call | Effect | Response afterwards |
|---|---|---|
| `request.getRequestDispatcher(path)` | a path relative to the context (`/WEB-INF/views/…`) or to the current path | |
| `getServletContext().getNamedDispatcher(name)` | by servlet name (no path attributes set) | |
| `forward(req, res)` | hands the request over: the target produces the **whole** response | the caller must not write anything; buffered output is discarded; committed → `IllegalStateException` |
| `include(req, res)` | runs the target and inserts its output **here** | the caller continues; the target can't set status or headers |

## Dispatcher types and filters

| Type | Started by | Filters run if mapped with |
|---|---|---|
| `REQUEST` | the client | `<dispatcher>REQUEST</dispatcher>` (the default when none is given) |
| `FORWARD` | `forward()` | `FORWARD` |
| `INCLUDE` | `include()`, `<jsp:include>` | `INCLUDE` |
| `ERROR` | the container's error handling (43.03) | `ERROR` |
| `ASYNC` | `AsyncContext.dispatch()` (45.13) | `ASYNC` |

`request.getDispatcherType()` tells a component which one it's in.

## The attributes the container adds

| During | Attribute | Value |
|---|---|---|
| a forward | `javax.servlet.forward.request_uri`, `.context_path`, `.servlet_path`, `.path_info`, `.query_string` | the **original** request's values (the request's own getters now describe the target) |
| an include | `javax.servlet.include.request_uri`, `.context_path`, `.servlet_path`, `.path_info`, `.query_string` | the **included** resource's values (the request's getters still describe the original) |
| an error dispatch | `javax.servlet.error.*` | 43.04 |
| an async dispatch | `javax.servlet.async.*` | the original values |

The asymmetry is the classic surprise. TaskFlow's nav reads `javax.servlet.forward.servlet_path` for exactly this reason (39.08): after the controller forwards to `list.jsp`, `request.getServletPath()` is `/WEB-INF/views/tasks/list.jsp`.

## Parameters

A forward or include to `path?x=1` **adds** `x` to the parameters for the duration of the dispatch (new values first); `/tasks/latest` → `/tasks/view?id=25` used that (31.07).

## ✅ Recap

Forward replaces the response; include inserts into it. Each dispatch has a type that decides which filters run, and path attributes that tell you where the request originally went.
