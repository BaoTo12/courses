# Lecture 45.15 · `@MultipartConfig` File Upload: Concept and 🛡 Risks

> **Section:** S45 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~15 minutes

*Extended track: outline.*

---

- **📇 API card**
  | Piece | Meaning |
  |---|---|
  | `@MultipartConfig(maxFileSize, maxRequestSize, fileSizeThreshold, location)` on the servlet | enables `multipart/form-data` parsing; limits in bytes |
  | `<form method="post" enctype="multipart/form-data">` + `<input type="file" name="attachment">` | the browser side |
  | `request.getPart("attachment")` → `Part` | `getSubmittedFileName()`, `getContentType()`, `getSize()`, `getInputStream()`, `write(fileName)`, `delete()` |
  | `request.getParts()` | all parts (fields and files) |
  | too large | `IllegalStateException` from `getPart` → map it to 413 |
- **🛡 The risks, and the defences**
  | Risk | Defence |
  |---|---|
  | **size**: filling the disk, memory | `maxFileSize`, `maxRequestSize`; Tomcat's `maxPostSize`/`maxSwallowSize` |
  | **path traversal**: a submitted file name `../../webapps/ROOT/shell.jsp` | never use the submitted name as a path; generate a random id; store outside the web app |
  | **type**: an `.html` or `.svg` with script, served back from your origin = stored XSS | allow-list types by **content** (magic bytes), not by extension or `Content-Type` (client-controlled); serve with `Content-Disposition: attachment` and `X-Content-Type-Options: nosniff` (40.10) |
  | **executable content**: a `.jsp` saved under the web app runs as code | never store uploads under the web app's folders |
  | **malware**, zip bombs, image parser bugs | scanning, limits on decompression, re-encoding images |
  | **access control**: guessable download URLs | the same ownership checks as any data (42.05) |
- **CSRF:** a multipart POST is a POST: TaskFlow's `CsrfFilter` checks `_csrf`. Note that `getParameter("_csrf")` works for multipart only once the servlet has `@MultipartConfig` and the parts are parsed.
- TaskFlow has no uploads; an "attachments" feature would follow this list.
