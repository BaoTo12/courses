## 1. Thread safety

| Place | Rule |
|---|---|
| locals, request, request attributes | per request: free to write |
| servlet/filter/listener fields | only set in `init`/constructor; otherwise concurrent or immutable types |
| session attributes | same user, concurrent tabs: immutable values or copy-on-write |
| context attributes, statics | concurrent or immutable (`volatile` snapshot) |
| never | `synchronized doGet`, `SingleThreadModel`, `SimpleDateFormat` fields |

## 2. APIs

`ServletContext` (attributes, `getInitParameter`, `getResourceAsStream`, `getRealPath` may be null, `addServlet/addFilter/addListener` at startup) · `ServletConfig` / `FilterConfig` (`getInitParameter`, names) · listeners (45.07) · `RequestDispatcher` `forward`/`include` + `javax.servlet.forward.*`/`include.*` · `AsyncContext` (`startAsync`, `setTimeout`, `complete`, `dispatch`, `AsyncListener`) · `@MultipartConfig` + `Part`.

| Piece | Job |
|---|---|
| `AppContextListener` | builds everything; `addListener(SessionRegistry)`; export pool; closes all in reverse |
| `SessionRegistry` | session → username (attribute + id listeners); `SESSION_EXPIRED` on timeout; `loginIp` from `LoginServlet` |

| `AuditService.page`, 📦 `AuditDao.find/count`, `AdminAuditServlet`, `admin/audit.jsp` | `/admin/audit?type=&user=&page=` (25/page), logged-in users |
| `TaskExportServlet` | `/tasks/export.csv`, async on a 2-thread pool, CSV-injection safe |
| `web.xml` | every filter `<async-supported>true` |
| 📦 debug | `/debug/race?who=[&mode=safe]`, `/debug/slow?ms=` (loopback) |
