# Lecture 33.14 · Disabling Scripting: `<scripting-invalid>`

> **Section:** S33 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~10 minutes

*Extended track: outline.*

---

```xml
<jsp-config>
  <jsp-property-group>
    <url-pattern>*.jsp</url-pattern>
    <scripting-invalid>true</scripting-invalid>
  </jsp-property-group>
</jsp-config>
```

- Any `<% %>`, `<%= %>` or `<%! %>` in a matching JSP becomes a **translation error**: "Scripting elements are disallowed here". The page doesn't compile.
- It turns a code-review rule ("no Java in views") into something the **build enforces**, the same idea as `noUnusedLocals` in TypeScript or a lint rule.
- Directives (`<%@ page %>`, `<%@ taglib %>`) and JSP comments are still allowed.
- TaskFlow turns it on in S36, once every view uses only EL and JSTL. Doing it earlier would break S33's deliberate scriptlet pages.
- Transition tip: enable it per folder (`/WEB-INF/views/admin/*`), then widen the pattern as pages are converted.
