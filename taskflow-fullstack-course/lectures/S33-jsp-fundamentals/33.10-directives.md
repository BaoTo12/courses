# Lecture 33.10 · Directives: `page`, `include`, `taglib`

> **Section:** S33 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~30 minutes
> Verified: `S33JspFundamentalsTest` (`session="false"` → no `Set-Cookie`; the header fragment inlined with the page's title); the generated code in 33.03

---

Directives are instructions to **Jasper**, at translation time. They produce no output themselves.

## 📇 `<%@ page … %>`

| Attribute | Default | TaskFlow | Meaning |
|---|---|---|---|
| `contentType` | `text/html;charset=ISO-8859-1` | `text/html;charset=UTF-8` | the response header and the output charset |
| `pageEncoding` | from `contentType`, else ISO-8859-1 | `UTF-8` (via `jsp-config`) | the encoding of the **source file** |
| `import` | — | `java.util.List, com.taskflow.model.Task` | Java imports for scriptlets |
| **`session`** | **`true`** | **`false`** | `true` creates a session (and a `JSESSIONID` cookie) for **every** visitor, even anonymous ones. That wastes memory, and a pre-login session id helps session fixation (S41). |
| `errorPage` | — | (S43 uses `web.xml` error pages instead) | forward here on an exception |
| `isErrorPage` | `false` | — | enables the `exception` object |
| `buffer` / `autoFlush` | `8kb` / `true` | defaults | output buffer (commit timing, 30.18) |
| `trimDirectiveWhitespaces` | `false` | `true` (via `jsp-config`) | removes the blank lines left by directives and scriptlets |
| `isELIgnored` | `false` | — | `true` would print `${…}` literally (S34 debug) |

## 📇 `<%@ include file="…" %>`: static, at translation time

- The file's **text** is pasted in before compilation → one servlet, **shared local variables** (`pageTitle`, 33.08).
- A change to the fragment → re-translation of every page that includes it (it's a dependant, 33.04).
- The fragment's encoding comes from `jsp-config` (or its own `pageEncoding`). Otherwise it's ISO-8859-1 (33.19).
- Convention: `.jspf` for fragments. They're never requested or compiled alone.

Its runtime twin, `<jsp:include>`, is in 33.11.

## 📇 `<%@ taglib … %>`

```jsp
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
```

This declares a tag library (JSTL core, S35), or your own tags (a tag file, S35).

## `jsp-config` in `web.xml`: set them once

A `<jsp-property-group>` applies page settings to URL patterns: `page-encoding`, `trim-directive-whitespaces`, `scripting-invalid` (33.14), `include-prelude`/`include-coda` (auto-include a header and footer), `el-ignored`. TaskFlow sets the encoding and trimming there (33.08).
