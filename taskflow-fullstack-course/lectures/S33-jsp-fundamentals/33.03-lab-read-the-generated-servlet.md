## 4. What to take from it

| JSP syntax | Became |
|---|---|
| template text | `out.write("…")` |
| `<%= expr %>` | `out.print( expr )`: **no escaping** (32.11) |
| `<% code %>` | the code itself, inside `_jspService` (a local scope, per request) |
| `<%@ page import %>` | Java imports |
| `<%@ page contentType %>` | `response.setContentType(…)` |
| `<%@ page session="false" %>` | `needsSession = false`: no `session` variable, no session created (33.10) |
| `<%@ include file %>` | the fragment's text **inlined** here, at translation time |
| `<%-- comment --%>` | nothing at all |

Also notice: **JSPs refuse `PUT`/`DELETE`** with 405 (that's a Jasper behaviour), and the page buffer is 8 KB before it autoflushes and commits (30.18).
