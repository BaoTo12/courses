# Lecture 33.06 · Implicit Objects: Where Each Comes From in the Generated Code

> **Section:** S33 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~25 minutes

---

Inside scriptlets and expressions, these variables "just exist". They're **local variables and parameters of `_jspService`** (33.03):

| Object | Type | Generated from | Use |
|---|---|---|---|
| `request` | `HttpServletRequest` | `_jspService`'s parameter | attributes, parameters, context path |
| `response` | `HttpServletResponse` | `_jspService`'s parameter | rarely in views (the controller sets the status and headers) |
| `out` | `JspWriter` | `pageContext.getOut()` | what `<%= %>` and template text write to (buffered, 8 KB) |
| `session` | `HttpSession` | `pageContext.getSession()`, **absent with `session="false"`** | the logged-in user (S38+) |
| `application` | `ServletContext` | `pageContext.getServletContext()` | app-wide attributes and params (30.13) |
| `config` | `ServletConfig` | `pageContext.getServletConfig()` | the JSP's init params (rare) |
| `pageContext` | `PageContext` | `_jspxFactory.getPageContext(…)` | access to all scopes (33.12); EL is built on it |
| `page` | `Object` | `this` | the servlet instance itself (never useful) |
| `exception` | `Throwable` | only in pages with `isErrorPage="true"` | error pages (S43) |

Notes:

- `out` is a **`JspWriter`**, not the response's `PrintWriter`. It has its own buffer on top. `out.print` of a `null` prints the text `"null"`.
- `session` **creates** an `HttpSession` (and a `JSESSIONID` cookie) on first use in pages where `session="true"` (the default). TaskFlow's views set `session="false"`, and `S33JspFundamentalsTest` checks that `/tasks` sends **no** `Set-Cookie` (33.10).
- In EL (S34), these are available through `pageContext` and the implicit EL objects: `${pageContext.request.contextPath}`, `${param.id}`, `${sessionScope.user}`.
