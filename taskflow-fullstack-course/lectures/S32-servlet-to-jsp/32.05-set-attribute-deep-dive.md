# Lecture 32.05 · Deep Dive: `request.setAttribute("tasks", tasks)`

> **Section:** S32 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~25 minutes

---

## 1. What is `request`?

An object Tomcat created for **this one HTTP request**: an instance of `org.apache.catalina.connector.RequestFacade`, which implements `HttpServletRequest`. It lives in the JVM **heap**, referenced by the worker thread's stack while the request is being processed.

## 2. What is an attribute?

A **name → object** entry in a map **inside** that request object (Tomcat's `Request` keeps a `HashMap<String, Object>`).

```java
request.setAttribute("tasks", tasks);   // puts a REFERENCE to the List<Task> in the map: no copy, no serialisation
```

- The value is **any Java object**: the list itself, not a string version of it.
- The JSP receives the **same reference**. Mutating it in the JSP would mutate the servlet's list: don't.

## 3. Who can access it?

Only code that has **this request object**: the servlet, any filter in the chain, components it forwards or includes to, and the JSP. Other users' requests have their own request objects and can't see it. Other threads handling other requests can't either. Nothing is sent to the browser (32.08).

## 4. How long does it live?

```text
request created ──► filters ──► servlet: setAttribute ──► forward ──► JSP reads it ──► response sent ──► request RECYCLED
                                                                                                       (map cleared)
```

**One request**, across forwards and includes, but not across redirects (31.15). Tomcat **recycles** request objects for later requests, so never keep a reference to `request` (or its attributes) in a field or a background thread.

## 5. The other scopes, for comparison (S38 in depth)

| Scope | Object | Lives | Visible to |
|---|---|---|---|
| page | `pageContext` | one JSP execution | that JSP |
| **request** | `HttpServletRequest` | one request (+ forwards) | this request's components |
| session | `HttpSession` | one user's visit | that user's requests |
| application | `ServletContext` | the app's lifetime | everyone |

## ✅ Recap

An attribute is a reference in the request object's map. It's visible to the components handling this request, lives exactly one request, and is never sent to the browser.
