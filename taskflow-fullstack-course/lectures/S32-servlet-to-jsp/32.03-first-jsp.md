# Lecture 32.03 · 🛠 Build: Your First JSP, Static HTML

> **Section:** S32 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. A JSP is an HTML file with a `.jsp` extension

Create `src/main/webapp/hello.jsp` (temporarily at the root, so the browser can request it directly):

```jsp
<%@ page contentType="text/html;charset=UTF-8" pageEncoding="UTF-8" %>
<!doctype html>
<html lang="en">
<head><meta charset="utf-8"><title>First JSP</title></head>
<body>
  <h1>Hello from a JSP</h1>
  <p>The time on the server: <%= java.time.LocalTime.now() %></p>
</body>
</html>
```

Open `http://localhost:8080/taskflow/hello.jsp`. With exploded deployment, no rebuild is needed (28.06).

## 2. What just happened

- The request for `*.jsp` was mapped to Tomcat's **`JspServlet`** (in `conf/web.xml`, 28.03).
- On the **first** request, Jasper **translated** `hello.jsp` into a Java servlet class, **compiled** it, and ran it. S33 opens that generated class.
- The HTML parts were written as-is. `<%= … %>` inserted a Java value. Reload: the time changes, the page doesn't re-translate.

## 3. The page directive: always the first line

```jsp
<%@ page contentType="text/html;charset=UTF-8" pageEncoding="UTF-8" %>
```

| Attribute | Means |
|---|---|
| `contentType` | the response header, including the **charset of the output** (30.17's lesson, done declaratively) |
| `pageEncoding` | the encoding of the **.jsp file itself** on disk, so Vietnamese text in the template is read correctly |

Forget either one, and Vietnamese breaks, in the output or in the template.

## 4. Then delete it

A JSP at the web root is **publicly requestable**. From 32.06 on, JSPs live under `WEB-INF/views/` and are reached only through a controller (32.07). Delete `hello.jsp` once you've seen it work.
