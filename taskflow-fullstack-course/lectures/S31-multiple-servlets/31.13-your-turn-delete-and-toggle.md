## Requirements

1. **`POST /tasks/delete`** with a form field `id`: delete the task, then **redirect** to the list.
2. **`POST /tasks/toggle`** with `id`: switch `DONE` ↔ `TODO`, then redirect to the list.
3. In the list (`TaskListServlet`), each row gets **two small POST forms** (a hidden `id` + a button): "Mark done" / "Reopen", and "Delete".
4. **`GET`** on either URL must **not** change anything, and must answer 405.
5. Missing or invalid `id` → **400**. Unknown id → **404**. No stack traces.
6. The store returns **copies**: make sure your toggle is actually saved.

## Test it

Write a test in the style of `S31TaskServletsTest`:

1. Create a task through `POST /tasks/new` and read its id from the `Location` header.
2. `GET /tasks/delete?id=…` → 405.
3. Toggle → 302 to `/taskflow/tasks`, and the task page shows `DONE`.
4. Delete → 302. The task page is now 404, and deleting again is 404.
