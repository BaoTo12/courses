# Lecture 31.02 · Request Parameters: Everything Is a `String` or `null`

> **Section:** S31 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~30 minutes

---

## 📇 API card

| Method | `?a=1&a=2&b=` | `?b` | nothing |
|---|---|---|---|
| `getParameter("a")` | `"1"` (the **first**) | `null` | `null` |
| `getParameterValues("a")` | `["1", "2"]` | `null` | `null` |
| `getParameter("b")` | `""` (present, empty) | `""` | `null` |
| `getParameterMap()` | `{a=[1, 2], b=[]}` (immutable) | `{b=[]}` | `{}` |
| `getParameterNames()` | `a, b` | `b` | empty |

Sources merged: the **query string** and a **urlencoded POST body** (29.06). Not JSON bodies. Not multipart without `@MultipartConfig`.

## 1. The four cases you must handle for every parameter

| Case | Example | TaskFlow's answer |
|---|---|---|
| **missing** | `/tasks/view` | 400 (a required id) or a default (a filter) |
| **empty** | `?id=` | treat as missing (`Params.positiveId` returns `null`) |
| **malformed** | `?id=abc`, `?dueDate=tomorrow` | 400 + a message; never an uncaught exception (31.16) |
| **valid but not allowed** | `?id=42` belonging to another user; `?priority=URGENT` | 404/403 (S42) / a validation error |

## 2. Converting safely

```java
Long id = Params.positiveId(request.getParameter("id"));            // null for null/""/"abc"/"-1"/overflow
TaskStatus status = TaskStatus.parse(request.getParameter("status")); // null for unknown names
LocalDate due = …  try { LocalDate.parse(raw) } catch (DateTimeParseException e) { error }
```

Rules:
- **Never** `Integer.parseInt(request.getParameter("id"))` bare. `null` → NPE, `"abc"` → `NumberFormatException` → an **HTTP 500** page with a stack trace (31.16).
- **Allow-list** enum-like values (`TaskStatus.parse`), and don't pass raw strings to `Enum.valueOf` (it throws) or to SQL (S36).
- **Trim** text, and check **length** (the DB column is `VARCHAR(120)`, 28.07).

## 3. Encoding

`getParameter` returns **decoded** text (`%C3%B4` → `ô`). For a POST body, the container needs to know the charset **before** the first `getParameter` call: `request.setCharacterEncoding("UTF-8")` (done in `TaskCreateServlet.doPost`, and by a filter from S39). Without it, Tomcat decodes the body as ISO-8859-1: `Công` → `CÃ´ng`. The test `createRedirectsToTheNewTaskAndTheUtf8TitleSurvives` posts `Viết báo cáo quý` and reads it back intact.

(The **query string** decoding is controlled by the connector's `URIEncoding`, UTF-8 by default since Tomcat 8.)

## ✅ Recap

Parameters are strings or `null`. Handle missing, empty, malformed and not-allowed. Convert with helpers that never throw. Set the body charset before reading.
