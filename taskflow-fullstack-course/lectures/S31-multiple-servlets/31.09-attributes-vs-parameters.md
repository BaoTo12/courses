# Lecture 31.09 · Request Attributes vs Parameters

> **Section:** S31 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

| | **Parameters** | **Attributes** |
|---|---|---|
| Come from | the **client** (URL, form body) | **your code** (`setAttribute`) |
| Type | `String` / `String[]` | any `Object` (a `List<Task>`, a `Task`, a `Map` of errors) |
| Can be set by | nobody on the server (read-only) | servlets, filters, JSPs |
| Trust | none: validate (29.09) | yours, but still escape when rendering values that came from users |
| Lifetime | one request | one request (request scope); also session and application scopes (S38) |
| Read in a JSP | `${param.id}` (S34) | `${tasks}`, `${task.title}` (S34) |

## 📇 API card: request attributes

| Method | |
|---|---|
| `request.setAttribute(name, value)` | put (`null` value = remove) |
| `request.getAttribute(name)` | `Object`, or `null` (cast it) |
| `request.removeAttribute(name)` | |
| `request.getAttributeNames()` | an `Enumeration` |

## Typical use: servlet → JSP (from S32/S36)

```java
List<Task> tasks = store.findByStatus(status);                    // loaded by the controller
request.setAttribute("tasks", tasks);                              // handed to the view
request.setAttribute("statusFilter", status);
request.getRequestDispatcher("/WEB-INF/views/tasks/list.jsp").forward(request, response);
```

Parameter or attribute?

| Value | Which | Why |
|---|---|---|
| the task id from the URL | **parameter** | the client sent it |
| the list the servlet loaded | **attribute** | computed on the server |
| a validation message the servlet computed | **attribute** (`errors` map) | computed on the server |
| "the current user" | **session attribute** (S38) | lives across requests |

Don't `setAttribute("id", request.getParameter("id"))` "for the JSP". The JSP can read `${param.id}`. Put **converted, validated** values in attributes (`task`, not the raw id).

## ✅ Recap

Parameters: client strings, read-only, untrusted. Attributes: server objects that pass data between components during one request.
