# Lecture 34.17 · EL 3.0 Extras on Tomcat 9: Static Access, `+=`, Lambdas, Collection Operations

> **Section:** S34 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~15 minutes

*Extended track: outline.*

---

```jsp
<%@ page import="com.taskflow.web.Html" %>
${Html.escape(task.title)}                      <%-- static method of an imported class (TaskFlow uses this) --%>
${Integer.MAX_VALUE} · ${Math.max(a, b)}        <%-- java.lang.* is imported automatically --%>
${'Hello, ' += user.displayName}                <%-- string concatenation --%>
${tasks.stream().filter(t -> t.done).count()}   <%-- lambdas + streams --%>
${[1, 2, 3]} · ${{'a': 1}}                       <%-- List and Map literals --%>
${x = 5; x * 2}                                 <%-- assignment and ; (sets a page attribute "x") --%>
```

- **Static access:** the page's `import`s are given to EL (the generated servlet implements `JspSourceImports`, 34.04). In Tomcat, an **attribute** with the same name wins over the class: `request.setAttribute("Html", …)` would break `${Html.escape}`.
- **`+=`** is the only string concatenation (`+` is arithmetic, 34.11).
- **Lambdas and `.stream()`** make EL a small functional language. `filter`, `map`, `sorted`, `count`, `sum`… on any collection.
- **Clever vs harmful:** `${tasks.stream().filter(t -> t.isOverdue(today)).count()}` works, and it's exactly the business logic 33.13 moved **out** of views. It's untestable in isolation, invisible to the compiler, and runs on every render. Compute it in the controller (`${overdueCount}`).
- **Where they're legitimately useful:** tiny formatting in a view (`${'#' += task.id}`); static constants (`${TaskStatus.DONE}` after importing the enum); prototyping.
- **Assignment** writes attributes from the view. It's a hidden side channel that makes pages order-dependent. Avoid it.
