# Lecture 34.22 · 🐞 Debug: `${requestScope.tasks}` Prints Nothing

> **Section:** S34 · **Type:** 🐞 Debug · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. Symptom

The list page renders with the header, the stats box and an empty table, and no error anywhere. `${requestScope.tasks}` (or `${tasks}`) is simply empty.

EL's "not found → nothing" (34.03) means **every** cause below looks identical in the browser. Work through the chain from the controller to the view.

## 2. The investigation checklist

| # | Question | How to check | Typical cause |
|---|---|---|---|
| 1 | Was this **controller** even called? | a log line in `doGet`; `/debug/request-info` for the servlet path | the URL maps to another servlet, or the JSP was opened directly (it's under `WEB-INF`: 404, 32.08) |
| 2 | Was the attribute **set**? | log `request.getAttribute("tasks")` right before `forward` | an early `return` on some branch; set inside an `if` |
| 3 | Is the **name** identical? | compare the strings: `"tasks"` vs `"taskList"`, `"Tasks"` | a typo. EL names are **case-sensitive** |
| 4 | Is the **scope** the one you read? | `setAttribute` on `request`, `session` or `getServletContext()`? | set in the session, read with `requestScope` (answer to the knowledge-check question: **nothing**) |
| 5 | **Forward** or **redirect**? | Network tab: a 302? | after `sendRedirect` there's a **new request**, and request attributes are gone (31.06) |
| 6 | Same request? | an include/forward chain vs a second page load | the attribute was set in a previous request (e.g. a POST), and the GET after the PRG redirect doesn't have it |
| 7 | Is **this** JSP the one rendered? | put a visible marker in it; check the forward path | forwarding to `/WEB-INF/views/task/list.jsp` (another file), or a stale translation (33.04) |
| 8 | Is EL evaluated at all? | does the page show `${…}` literally? | `isELIgnored` (34.02) |
| 9 | Is it **shadowed** or overwritten? | `${requestScope.tasks}` vs `${pageScope.tasks}` | a `pageContext.setAttribute("tasks", …)` or a later `setAttribute` with `null` |

## 3. Fastest tool

Temporarily add to the page:

```jsp
<pre>${Html.escape(requestScope)}</pre>
```

It prints every request attribute (a `Map`'s `toString`), escaped. If `tasks` isn't in there, the problem is in the controller (1–6). If it is, the problem is in the page (7–9).

## ✅ Takeaway

EL's silence is a feature for optional values and a trap for bugs. Debug from the source: called? set? name? scope? same request? right page?
