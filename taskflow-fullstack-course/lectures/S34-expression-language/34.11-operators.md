## 📇 API card: EL operators

| Kind | Symbols | Word form | Example → result |
|---|---|---|---|
| arithmetic | `+ - * / %` | `div` `mod` | `${7 / 2}` → `3.5` (always decimal division) · `${7 % 2}` → `1` |
| comparison | `== != < > <= >=` | `eq ne lt gt le ge` | `${task.priority == 'HIGH'}` |
| logical | `&& \|\| !` | `and or not` | `${not task.done and task.priority eq 'HIGH'}` |
| emptiness | `empty` | | `${empty tasks}` (34.12) |
| conditional | `a ? b : c` | | `${task.done ? 'Reopen' : 'Mark done'}` |
| grouping | `( )` | | `${(a + b) * 2}` |
| EL 3.0 | `+=` (concat), `=` (assign), `;`, `->` (lambda) | | 34.17 |

Precedence (high → low): `[] .` · `()` · unary `- ! not empty` · `* / div % mod` · `+ -` · `+=` · `< > <= >= lt gt le ge` · `== != eq ne` · `&& and` · `|| or` · `? :` · `->` · `=` · `;`.

**Why word forms exist:** in XML-syntax JSP documents (`.jspx`) and in attributes, `<` and `&&` must be escaped. `lt` and `and` never need escaping. In normal `.jsp` pages, both forms work. Pick one per team.

## 1. Surprises worth knowing

| Expression | Result | Why |
|---|---|---|
| `${7 / 2}` | `3.5` | `/` coerces to `Double` (or `BigDecimal`) |
| `${'a' + 'b'}` | **error**: `'a'` can't be coerced to a number | `+` is **only** arithmetic; concatenation is `+=` (EL 3.0) or just `${a}${b}` |
| `${param.page + 1}` (no `page`) | `1` | `null` → `0` (34.13) |
| `${'5' == 5}` | `true` | the string is coerced to a number |
| `${null == 0}` | `false` | `==` with `null` is only true for `null` |
| `${task.status == 'DONE'}` | `true` for a done task | the string is coerced to the **enum** (34.13) |

## 2. Ternaries in TaskFlow

```jsp
<tr class="${task.isOverdue(today) ? 'task-row--overdue' : ''}">
<a class="${statusFilter == 'DONE' ? 'is-active' : ''}" href="…?status=DONE">DONE</a>
<p class="text-danger"${overdueCount == 0 ? ' hidden' : ''}>${overdueCount} overdue ${overdueCount == 1 ? 'task' : 'tasks'}</p>
```

**When to use** the conditional operator: choosing between two small **values** (a class, a word, an attribute).
**When not to:** choosing between two **blocks of markup**. `${cond ? '<table>…' : ''}` builds HTML in strings, which is unreadable and dangerous. Use `<c:if>`/`<c:choose>` (S35).

**Common mistakes:**
- `${a + ' ' + b}` to concatenate → an exception. Write `${a} ${b}`.
- `${count > 0 && count < 10}` in a `.jspx` → XML error; write `gt`/`and`.
- Deep nested ternaries: move the decision to the controller or model (`${task.statusLabel}`).

## ✅ Recap

EL has the usual operators plus word forms. `+` is arithmetic only, `/` is decimal, and comparisons coerce types. Ternaries pick **values**; tags (S35) pick **blocks**.
