# Lecture 34.10 · `.` vs `[]`: Maps, Lists, Arrays, Dynamic Keys, Keys with Dashes

> **Section:** S34 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S34ElTest` (`${stats['TODO']}` on a `Map<String, Integer>`, `${header['User-Agent']}`, `${paramValues.tag[1]}`)

---

## 1. Two spellings, one operation

`a.b` is shorthand for `a['b']`. The brackets are the general form. They take **any expression**, while the dot only takes a Java-identifier-like name.

| You need | Write | Why not `.`? |
|---|---|---|
| a map key that's a valid name | `${stats.TODO}` or `${stats['TODO']}` | both fine |
| a key with `-`, `.`, space | `${header['User-Agent']}` | `header.User-Agent` = `header.User` **minus** `Agent` |
| a key from a variable | `${stats[task.status]}` | `stats.task…` would look for key `"task"` |
| a list or array element | `${tasks[0]}`, `${paramValues.tag[1]}` | `tasks.0` isn't valid syntax |
| a bean property by computed name | `${task[column]}` with `column = 'title'` | same reason |

## 2. By type of the base value (34.04)

| Base | `a[k]` means | `k` is coerced to | Missing |
|---|---|---|---|
| `Map` | `map.get(k)` | **not** coerced: used as is | `null` |
| `List` | `list.get(k)` | `int` | out of range → `null`, no exception |
| array | `array[k]` | `int` | out of range → `null` |
| bean | the property named `k` | `String` | `PropertyNotFoundException` |

## 3. The map-key trap: EL integers are `Long`

```java
Map<Integer, String> byId = Map.of(1, "alice");
request.setAttribute("byId", byId);
```

```jsp
${byId[1]}    <%-- prints NOTHING --%>
```

The literal `1` is a `java.lang.Long`, and map keys aren't coerced: `byId.get(1L)` isn't `byId.get(1)`. Fix it by using `Map<Long, …>` (TaskFlow's ids are `long`), or `String` keys, as in `stats`.

## 4. TaskFlow's stats box (34.20)

```java
Map<String, Integer> stats = new LinkedHashMap<>();       // TaskListServlet
for (TaskStatus s : TaskStatus.values()) stats.put(s.name(), 0);
for (Task t : all) stats.merge(t.getStatus().name(), 1, Integer::sum);
```

```jsp
<span class="badge">In progress: ${stats['IN_PROGRESS']}</span>
<span class="badge">For this task's status: ${stats[task.status]}</span>   <%-- ⚠ an enum key, not a String: nothing --%>
```

The second line prints nothing: `task.status` is the **enum** `TaskStatus.IN_PROGRESS`, and the map's keys are **strings**. Use `${stats[task.status.name()]}`, or key the map by the enum.

## ✅ Recap

Use dots for simple names, and brackets for dashes, variables and indexes. Map keys are compared **as they are**: match their type.
