## 1. The view model

✍️ `src/main/java/com/taskflow/model/TaskDetails.java`

```java
package com.taskflow.model;

/**
 * S34 (34.09): everything the details page shows, as ONE object for the view.
 * ${details.task.title} · ${details.category.name} · ${details.owner.displayName}.
 * category is null for a task without one, owner is null for an unknown user: EL walks a null chain
 * without an exception and prints nothing (34.08), and the view decides what to show instead with `empty`.
 */
public class TaskDetails {

  private final Task task;
  private final Category category;
  private final User owner;

  public TaskDetails(Task task, Category category, User owner) {
    this.task = task;
    this.category = category;
    this.owner = owner;
  }

  public Task getTask() { return task; }
  public Category getCategory() { return category; }
  public User getOwner() { return owner; }
}
```

No setters and no no-arg constructor: EL only reads (34.07).

## 2. The controller assembles it

✍️ `src/main/java/com/taskflow/web/tasks/TaskViewServlet.java`

```java
package com.taskflow.web.tasks;

import com.taskflow.model.Task;
import com.taskflow.model.TaskDetails;
import com.taskflow.store.InMemoryDirectory;
import com.taskflow.store.InMemoryTaskStore;
import com.taskflow.web.Params;
import java.io.IOException;
import java.util.Optional;
import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

/**
 * GET /tasks/view?id=N. The controller handles every error path (400, 404) BEFORE choosing the view,
 * so view.jsp can simply assume a task exists (32.12).
 * S34 (34.09): it assembles a TaskDetails (the task + its category + its owner) for ${details.…} in the view.
 */
@WebServlet("/tasks/view")
public class TaskViewServlet extends HttpServlet {

  private final InMemoryTaskStore store = InMemoryTaskStore.shared();
  private final InMemoryDirectory directory = InMemoryDirectory.shared();

  @Override
  protected void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
    Long id = Params.positiveId(request.getParameter("id"));
    if (id == null) {
      response.sendError(HttpServletResponse.SC_BAD_REQUEST, "Parameter 'id' must be a positive number");
      return;
    }
    Optional<Task> found = store.findById(id);
    if (found.isEmpty()) {
      response.sendError(HttpServletResponse.SC_NOT_FOUND);
      return;
    }
    Task task = found.get();
    TaskDetails details = new TaskDetails(
        task,
        task.getCategoryId() == null ? null : directory.findCategory(task.getCategoryId()).orElse(null),
        directory.findUser(task.getOwnerId()).orElse(null));

    request.setAttribute("details", details);
    request.setAttribute("pageTitle", task.getTitle()); // header.jspf escapes it
    request.getRequestDispatcher("/WEB-INF/views/tasks/view.jsp").forward(request, response);
  }
}
```

Two new attributes: `details` (the model) and `pageTitle` (for the header). The header used to read a **local variable** `pageTitle` of the including page (33.08). EL can't see Java locals, only attributes, so the controller now provides it. S35's layout tag will take it as a proper tag attribute.

## 3. The header, Java-free

✍️ `src/main/webapp/WEB-INF/views/common/header.jspf`

```jsp
<%--
  The top of every page, pasted in at TRANSLATION time by <%@ include file="…" %> (33.10).
  S34: no Java left. ${pageTitle} is a REQUEST attribute set by the controller (EL can't see local variables),
  and EL does NOT escape (34.18), so the title goes through Html.escape, called as a static method (34.17).
--%>
<%@ page import="com.taskflow.web.Html" %>
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>${Html.escape(pageTitle)} · TaskFlow Admin</title>
  <link rel="stylesheet" href="${pageContext.request.contextPath}/static/css/app.css">
</head>
<body>
<div class="page">
  <header class="page__header">
    <span class="page__brand">TaskFlow Admin</span>
    <nav class="page__nav">
      <a class="page__nav-link" href="${pageContext.request.contextPath}/tasks">Tasks</a>
      <a class="page__nav-link" href="${pageContext.request.contextPath}/tasks/new">New task</a>
    </nav>
  </header>
  <main class="page__main">
```

- `${pageContext.request.contextPath}` replaces `request.getContextPath()` (34.14).
- `${Html.escape(pageTitle)}`: `Html` is imported by the fragment's own page directive, so EL can call its static method (34.17). The escaping is **required**: EL prints raw text (34.18), and the title is user input.

## 4. The details page

✍️ `src/main/webapp/WEB-INF/views/tasks/view.jsp`

```jsp
<%--
  One task. TaskViewServlet handled 400/404 and set "details" (a TaskDetails) and "pageTitle".
  S34 (34.09): EL only. No imports of model classes, no casts, no null checks: ${details.category.name}
  is simply empty when there's no category, and `empty` chooses the fallback text.
--%>
<%@ page contentType="text/html;charset=UTF-8" pageEncoding="UTF-8" session="false" trimDirectiveWhitespaces="true" %>
<%@ page import="com.taskflow.web.Html" %>
<%@ include file="/WEB-INF/views/common/header.jspf" %>
    <nav class="text-muted"><a href="${pageContext.request.contextPath}/tasks">Tasks</a> › ${Html.escape(details.task.title)}</nav>
    <h1 class="page__title">${Html.escape(details.task.title)}</h1>
    <p><span class="badge">${details.task.status}</span> <span class="badge">${details.task.priority}</span></p>
    <p class="${empty details.task.description ? 'text-muted' : 'task__description'}">${empty details.task.description ? 'No description.' : Html.escape(details.task.description)}</p>
    <dl>
      <dt>Category</dt><dd>${empty details.category ? 'No category' : Html.escape(details.category.name)}</dd>
      <dt>Owner</dt><dd>${Html.escape(details.owner.displayName)} (${Html.escape(details.owner.username)})</dd>
      <dt>Due</dt><dd>${empty details.task.dueDate ? 'no due date' : details.task.dueDate}</dd>
    </dl>
    <p><a class="btn btn--secondary btn--sm" href="${pageContext.request.contextPath}/tasks">Back to the list</a></p>
<%@ include file="/WEB-INF/views/common/footer.jspf" %>
```

Read it as a checklist of this section's ideas:

| Expression | Idea |
|---|---|
| `${details.task.status}` | a chain of getters; an enum prints its `name()` (34.07) |
| `${details.owner.displayName}` | a nested bean from another "table" (34.08) |
| `${empty details.category ? 'No category' : …}` | `empty` + the conditional operator choose a fallback (34.11, 34.12) |
| `${empty details.task.dueDate ? 'no due date' : details.task.dueDate}` | a `LocalDate` prints with `toString()`: `2026-10-03` (S44 formats it per locale) |
| `class="${empty … ? 'text-muted' : 'task__description'}"` | EL inside an HTML attribute: it's all template text to JSP (34.02) |

No `import` of model classes, no cast, no null check.
