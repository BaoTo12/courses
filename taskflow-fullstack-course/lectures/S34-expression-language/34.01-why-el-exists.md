# Lecture 34.01 · Why EL Exists: `((Task) request.getAttribute("task")).getTitle()` → `${task.title}`

> **Section:** S34 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes

---

## 1. The same line, twice

S33's `view.jsp`:

```jsp
<%@ page import="com.taskflow.model.Task, com.taskflow.web.Html" %>
<%
  Task task = (Task) request.getAttribute("task");
%>
<h1 class="page__title"><%= Html.escape(task.getTitle()) %></h1>
<p class="text-muted">Due: <%= task.getDueDate() == null ? "no due date" : task.getDueDate() %></p>
```

S34's `view.jsp`:

```jsp
<h1 class="page__title">${Html.escape(details.task.title)}</h1>
<dd>${empty details.task.dueDate ? 'no due date' : details.task.dueDate}</dd>
```

## 2. What disappeared, and why each one mattered

| Gone | Why it hurt in S33 | What EL does instead |
|---|---|---|
| `request.getAttribute("task")` | you had to know the **scope** | searches page → request → session → application (34.03) |
| `(Task)` cast and `import` | a wrong type or name → `ClassCastException`/NPE → **500** | no types at all: it calls whatever getter exists, at runtime (34.07) |
| `task.getTitle()` | Java syntax in HTML | `task.title` → `getTitle()` by the JavaBeans naming rule |
| `== null ? … : …` | every nullable value needed a check, or NPE | a `null` anywhere in `a.b.c` gives `null`, printed as **nothing** (34.08) |
| `<% %>` blocks | braces across HTML (33.18), logic creeping in (33.13) | EL is an **expression** language: no statements, no assignments to Java variables |

EL (Expression Language) was created for JSTL 1.0 (2002), then moved into JSP 2.0 itself (2003). Today's version, **EL 3.0**, ships with Tomcat 9 as `javax.el` (Tomcat's implementation is `org.apache.el`, inside `jasper-el.jar`).

## 3. What EL is *not*

- **Not a programming language.** No `for`, no `if` blocks, no variables you declare. It computes **one value**. Looping and conditional blocks come from tags (JSTL, S35). You'll feel this limit in 34.20: the list page's loop is still one scriptlet.
- **Not an escaper.** `${param.q}` writes the raw text into the HTML. That's an XSS hole (34.18).
- **Not type-checked at build time.** `${task.titel}` compiles fine and fails on the first request (34.23). The tests that render every page (`TomcatTest`) are what catch it.

## 4. Where it runs

Wherever a JSP allows it: template text (`<p>${x}</p>`) and tag attribute values (`<c:out value="${x}"/>`, S35). Jasper translates every `${…}` into a call to the EL engine in the generated servlet (34.04).

## ✅ Recap

EL removes the Java from **reading** values in a view: no scopes to name, no casts, no null checks. It doesn't escape, and it can't loop. Those come next (34.18, S35).
