# Lecture 34.12 · `empty` in Depth

> **Section:** S34 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes
> Verified: `S34ElTest` (`${empty param.missing}` → `true`; `${empty tasks}` hides the table for a search with no results; `${empty details.category}` → "No category")

---

## 📇 API card: `empty x`

| `x` is | `empty x` |
|---|---|
| `null` | `true` |
| `""` (empty `String`) | `true` |
| an empty array | `true` |
| an empty `Collection` (`List`, `Set`) | `true` |
| an empty `Map` | `true` |
| `"  "` (spaces) | **`false`** |
| `0`, `false` | **`false`** |
| anything else | `false` |

`not empty x` (or `!empty x`) is the everyday form: "is there something to show?".

## 1. One operator replaces four checks

```jsp
<%-- S33 --%>  <% if (tasks == null || tasks.isEmpty()) { %> … <% } %>
<%-- S34 --%>  ${empty tasks}
```

It works for whatever type the controller used: a `List`, a `Set`, an array, `null`.

## 2. In TaskFlow

```jsp
<p class="text-muted"${empty tasks ? '' : ' hidden'}>No tasks.</p>
<table${empty tasks ? ' hidden' : ''}> … </table>
<dd>${empty details.category ? 'No category' : Html.escape(details.category.name)}</dd>
```

(The `hidden` attribute is S34's stand-in for "don't render this block": the markup is still sent, just not displayed. S35's `<c:if>` doesn't send it at all.)

## 3. Traps

| Trap | Explanation |
|---|---|
| `${empty param.q}` for `?q=%20` | `false`: a space isn't empty. Trim in the controller if blanks mean "no search" (TaskFlow's `normalise`). |
| `${empty 0}` | `false`. For "no tasks overdue", compare: `${overdueCount == 0}`. |
| `${empty task.done}` | `false` whether done or not: a `boolean` is never empty. |
| `${empty optionalValue}` (a `java.util.Optional`) | `false`, even for `Optional.empty()`. Don't put `Optional`s in the model; unwrap them in the controller. |

## ✅ Recap

`empty` is true for `null`, `""` and empty collections, maps and arrays. It's false for blanks, zeros and `false`.
