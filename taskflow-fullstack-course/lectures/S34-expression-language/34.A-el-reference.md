# 34.A · 📇 Expression Language (EL 3.0): Reference (S34)

## 1. Resolution (34.03, 34.04)

| Step | Rule |
|---|---|
| first identifier | implicit object → `findAttribute`: page → request → session (if any) → application → imported class → `null` |
| `.x` / `['x']` on a value | Map → `get(x)` · List/array → index (out of range → `null`) · bean → `getX()` / `boolean isX()` |
| `null` in a chain | the result is `null`, printed as `""` |
| missing property on a real object | `PropertyNotFoundException` → 500 (34.23) |

## 2. Implicit objects (34.14)

| Object | Type |
|---|---|
| `pageContext` | `PageContext` |
| `pageScope` `requestScope` `sessionScope` `applicationScope` | `Map<String, Object>` (⚠ `sessionScope` throws in `session="false"` pages: 34.25) |
| `param` / `paramValues` | `Map<String, String>` / `Map<String, String[]>` |
| `header` / `headerValues` | `Map<String, String>` / `Map<String, String[]>` |
| `cookie` | `Map<String, Cookie>` (use `.value`) |
| `initParam` | `Map<String, String>` (context params) |

## 3. Operators (34.11–34.13)

| Operator | Notes |
|---|---|
| `+ - * / %` (`div` `mod`) | `/` is decimal; `+` is **not** concatenation; `null` → `0` |
| `== != < > <= >=` (`eq ne lt gt le ge`) | coerce: number > Boolean > enum > String |
| `&& \|\| !` (`and or not`) | |
| `empty` | `null`, `""`, empty collection/map/array → `true`; `" "`, `0`, `false` → `false` |
| `a ? b : c` | for values, not blocks |
| EL 3.0: `+=` `=` `;` `->`, `[…]`, `{…}` | 34.17 (＋) |

## 4. Syntax (34.02)

| Form | Meaning |
|---|---|
| `${expr}` | immediate evaluation (JSP) |
| `#{expr}` | deferred (JSF); an error in JSP template text |
| `\${expr}` | a literal `${expr}` |
| `isELIgnored="true"` | EL printed literally (legacy) |
| `${Cls.method(…)}` | a static method of a page-imported class (34.17) |
| `${obj.method(arg)}` | a method call (EL 2.2+) |

## 5. Security (34.18, 34.19)

EL **never escapes**. Escape per context: HTML body and quoted attributes → entity-encode (`Html.escape` now, `<c:out>` / `fn:escapeXml` in S35); URL parts → URL-encode (`<c:url>`/`<c:param>`); `<script>` → no untrusted data (use `data-` attributes).
