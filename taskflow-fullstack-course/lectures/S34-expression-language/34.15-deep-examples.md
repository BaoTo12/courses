# Lecture 34.15 · Deep Examples: `param`, `header`, `cookie`, `pageContext.request.contextPath`

> **Section:** S34 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S34ElTest` (the debug page's rows, and the search box's escaped `value`)

---

## 1. `${param.q}`: echoing a search

```jsp
<input type="search" name="q" value="${Html.escape(param.q)}">
```

Resolution: `param` → implicit object (a `Map<String, String>` over `request.getParameter`) → `.q` → `MapELResolver` → `"report"` or `null` → `Html.escape` → `""` for `null`.

**Why echo it at all:** after submitting, the box keeps the search text. **Why escape:** 34.18.

## 2. `${header["User-Agent"]}`

```text
header                → ImplicitObjectELResolver → a Map over request.getHeader(name)
["User-Agent"]        → MapELResolver → "Mozilla/5.0 …" (TaskFlow's test sends "TaskFlowTest/1.0")
```

Real uses: small UI hints ("You're on a phone"). Never security. The client writes this header.

## 3. `${cookie.tf_lang.value}`

`tf_lang` is the language cookie the React app writes (S25). The JSP portal will honour it in S44:

```text
cookie               → Map<String, Cookie>
cookie.tf_lang       → the Cookie object (or null: the chain stops, prints nothing)
cookie.tf_lang.value → Cookie.getValue() → "vi"
```

## 4. `${pageContext.request.contextPath}`

The most-typed expression in any JSP application:

```text
pageContext                      → PageContext            (the implicit object)
pageContext.request              → getRequest()           → ServletRequest (an HttpServletRequest at runtime)
pageContext.request.contextPath  → getContextPath()       → "/taskflow"
```

**Why links need it:** the app is deployed under `/taskflow`, and could be `/` or `/admin` somewhere else. `href="/tasks"` breaks, while `href="${pageContext.request.contextPath}/tasks"` works everywhere. It's long, so S35 shortens it once per page with `<c:set var="ctx" …/>`, and `<c:url>` adds it for you.

## 5. Putting it together: a language hint

```jsp
<p class="text-muted">
  Language: ${empty cookie.tf_lang ? 'not chosen (browser default)' : Html.escape(cookie.tf_lang.value)}
  · <a href="${pageContext.request.contextPath}/debug/el">EL debug</a>
</p>
```

## ✅ Recap

`param` and `header` are maps of strings, `cookie` is a map of `Cookie` objects, and `pageContext` is the door to the request itself. Everything from the request is untrusted text: escape it.
