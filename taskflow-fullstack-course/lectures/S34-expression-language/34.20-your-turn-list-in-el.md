## The goal

Convert S33's `list.jsp` (33.08, with your 33.15 overdue feature) to EL, and move every **decision** into `TaskListServlet`.

## Requirements

**Controller (`TaskListServlet`):**
1. Keep the `?status=` filter, and add the `?q=` title search from 34.19 (case-insensitive "contains"; blank means no search).
2. Compute `today` from a `java.time.Clock` field, and give it to the view.
3. Provide `overdueCount` (among the **displayed** tasks), using `Task.isOverdue(today)`.
4. Provide `stats`: a `Map<String, Integer>` with a count for **every** status (`TODO`, `IN_PROGRESS`, `DONE`), over **all** tasks, including statuses with 0.
5. Provide `pageTitle` for the header.

**View (`list.jsp`):**
1. No `import` of model classes, no casts, no `request.getAttribute` **except** the one loop (EL has no statements: see the hint).
2. A stats box: `To do: N`, `In progress: N`, `Done: N`, each in a `<span class="badge">`, read from `stats` with `[]`.
3. `No tasks.` when the list is empty, using `empty`. When there are tasks, don't *display* it.
4. The current status link gets `class="is-active"`, compared with `==` against the enum.
5. Overdue rows: `class="task-row--overdue"` via a ternary, and ⚠ after the date. Keep S33's `N overdue task(s)` sentence.
6. Every piece of user text is escaped (34.19).

**Tests to pass:** S33's overdue test (unchanged), plus: the stats spans exist; `/tasks?status=DONE` marks `DONE` active; a search with no results shows `No tasks.` and hides the table.

## Hints

- The loop, the one allowed scriptlet:

  ```jsp
  <% for (Object task : (java.util.List<?>) request.getAttribute("tasks")) {
       pageContext.setAttribute("task", task); %>
     … ${task.title} …
  <% } %>
  ```

  Why `pageContext.setAttribute`? EL can't see the Java variable `task`, only **attributes** (34.03).
- "Don't display" without tags: the HTML `hidden` attribute, written by a ternary: `<p${empty tasks ? '' : ' hidden'}>`.
- A method with an argument is called as a method: `${task.isOverdue(today)}` (34.07 §2).
