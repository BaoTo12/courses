# Lecture 10.06 · `createGlobalStyle` vs the SCSS Base Layer: Avoiding Two Competing Resets

> **Section:** S10 · **Type:** 📖 Theory + 🛠 Build · **Track:** ★ Core · **Time:** ~20 minutes
> **Project feature:** a tiny `GlobalStyle` for React-only global rules

---

## 1. What `createGlobalStyle` does

```tsx
import { createGlobalStyle } from 'styled-components';

export const GlobalStyle = createGlobalStyle`
  body { margin: 0; }
`;

// render it once, near the root:
<GlobalStyle />
```

It creates a component that, while mounted, injects **unscoped** CSS (no generated class). It has access to the theme and props like any styled component.

## 2. The trap: two resets, two base layers

Many styled-components tutorials start with a full CSS reset and typography in `createGlobalStyle`. TaskFlow **already has** a reset, typography and theme variables in SCSS `base/` (02.03, 03.11, 03.13), which the JSP portal also uses. Adding a second reset in JS leads to:
- Two sets of rules fighting over `body`, headings, `box-sizing`… Which wins depends on **injection order** (10.15), which can change between dev and production.
- The React app and JSP portal slowly looking different.

**Rule:** the SCSS base layer owns global element styles. `GlobalStyle` holds only **React-app-specific** globals.

## 3. ✍️ `src/theme/GlobalStyle.ts`

```ts
import { createGlobalStyle } from 'styled-components';

/**
 * React-app-only global rules. The reset, typography and themes come from the SCSS design system
 * (base/), so this stays deliberately tiny: no second reset (10.06).
 */
export const GlobalStyle = createGlobalStyle`
  #root {
    isolation: isolate; /* toasts and overlays stack above the app without z-index wars */
  }

  :target {
    scroll-margin-top: ${({ theme }) => theme.space(16)};
  }

  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      transition-duration: 0.01ms !important;
    }
  }
`;
```

- **`#root { isolation: isolate }`** creates a stacking context for the app, so a toast viewport rendered inside it stacks predictably.
- **`:target { scroll-margin-top }`** keeps in-page anchors from hiding under a header.
- **Global reduced-motion**: a safety net that shortens every animation and transition for users who ask for less motion. It's one of the rare justified `!important`s, a user preference that must win.

It's a `.ts` file (no JSX), and it exports a *component-like* value, so it doesn't break the Fast Refresh rule for `.tsx` component files. Render `<GlobalStyle />` inside the styled `ThemeProvider` (10.05 §4), since it uses the theme.

## 4. Summary

- `createGlobalStyle` injects unscoped CSS while mounted; it can read the theme.
- Don't duplicate the SCSS reset/typography in JS; keep `GlobalStyle` for React-only globals.
