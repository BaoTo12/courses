# Lecture 10.03 · 🛠 Build: a First Theme (Two Objects) and a Critical Look at It

> **Section:** S10 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~25 minutes
> **Project feature:** a styled-components theme wired into `ThemeProvider`. This first version deliberately has a flaw we'll fix in 10.05.

---

## 1. The "obvious" approach: light and dark theme objects

Many tutorials do this:

```ts
// ⚠️ First attempt: hex values duplicated from the SCSS tokens
export const lightTheme = {
  colors: { primary: '#4f46e5', surface: '#ffffff', text: '#0f172a', danger: '#dc2626', /* … */ },
  space: (n: number) => `${n * 4}px`,
};

export const darkTheme = {
  ...lightTheme,
  colors: { primary: '#818cf8', surface: '#1e293b', text: '#f1f5f9', danger: '#f87171', /* … */ },
};
```

and in the provider, pick one based on the preference:

```tsx
const resolved = preference === 'system' ? (prefersDark ? 'dark' : 'light') : preference;
<StyledThemeProvider theme={resolved === 'dark' ? darkTheme : lightTheme}>
```

(`prefersDark` would come from `window.matchMedia('(prefers-color-scheme: dark)')` plus a change listener: another effect to write and maintain.)

## 2. Try it, then look critically

Wire it up for five minutes and toggle the theme. It works. Now list the problems:

1. **Two sources of truth.** The same colours now live in SCSS (`$themes` map, 03.13) *and* TypeScript. Change the brand colour in one place and the SCSS parts (cards, buttons, forms) and the styled parts (priority bar, ring) disagree. 10.14 is a debug lecture about exactly this bug.
2. **Duplicated "system" logic.** SCSS already follows `prefers-color-scheme` with pure CSS. The JS version needs `matchMedia` and a listener, and can flash the wrong theme before the effect runs.
3. **Every theme switch re-renders every styled component** (10.01 §3) and generates a new set of CSS classes for the new colours.
4. **The JSP portal can't use any of it**, while it *can* use the SCSS tokens.

Don't commit this version. The next lecture explains the better design, and 10.05 implements it.
