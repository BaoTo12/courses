# Lecture 10.09 · Variant Patterns at Scale: Variant Maps, `css` Fragments, Avoiding Prop Explosion

> **Section:** S10 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. The problem: prop explosion

Components grow boolean props over time:

```tsx
<Toast success />  <Toast error />  <Toast warning dismissible large compact outlined />
```

What does `<Toast success error />` mean? Booleans multiply into impossible combinations, the same "boolean soup" as 06.06.

## 2. One prop per axis, a union per prop

```tsx
type ToastTone = 'success' | 'error' | 'info';

<Toast $tone="error" />
```

Each **axis** of variation (tone, size, emphasis) gets **one** prop with a **union** of allowed values. Impossible combinations can't be expressed.

## 3. Variant maps with `css` fragments

```tsx
const toneStyles = {
  success: css`
    border-left-color: ${({ theme }) => theme.colors.success};
  `,
  error: css`
    border-left-color: ${({ theme }) => theme.colors.danger};
  `,
  info: css`
    border-left-color: ${({ theme }) => theme.colors.primary};
  `,
} satisfies Record<ToastTone, ReturnType<typeof css>>;

const Item = styled.div<{ $tone: ToastTone }>`
  /* shared styles… */
  ${({ $tone }) => toneStyles[$tone]}
`;
```

- **`satisfies Record<ToastTone, …>`**: a new tone without styles is a compile error; the map stays typed.
- Each fragment can contain nested rules, hover states and theme lookups.
- Adding an axis = adding another map: `${({ $size }) => sizeStyles[$size]}`.

This is the styled-components equivalent of the SCSS `@each` over a token map (03.07).

## 4. Compound variants (when two axes interact)

Occasionally one combination needs special treatment (e.g. `tone="error"` + `emphasis="solid"` needs white text). Handle it explicitly in one small place:

```tsx
${({ $tone, $emphasis }) =>
  $tone === 'error' && $emphasis === 'solid' &&
  css`color: ${({ theme }) => theme.colors.onPrimary};`}
```

If compound rules multiply, the component is probably doing too much. Split it.

## 5. Summary

- One prop per axis, typed as a union; no boolean soup.
- Variant maps of `css` fragments, typed with `satisfies Record<Union, …>`.
- Handle rare compound variants explicitly; split components when they multiply.
