# Lecture 10.08 · Why styled-components Can Never Style the JSP Admin Portal

> **Section:** S10 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes
> The compile-time vs runtime theme, one more time, applied across the whole architecture.

---

## 1. Follow the code to where it runs

```text
JSP page request:
Browser ── GET /taskflow/admin/tasks ──▶ Tomcat → Servlet → JSP (Java, on the server)
Browser ◀── HTML + <link rel="stylesheet" href="/static/css/app.css"> ──
Browser: parse HTML, apply app.css. NO React, NO styled-components bundle on this page.
```

styled-components needs **all** of these at runtime, in the browser:
1. The **React** runtime, rendering components.
2. The **styled-components** library, executing interpolations.
3. Your **component code** with the templates.

A JSP page has none of them. The JSP runs on the **server** (00.03) and outputs plain HTML text. Even if you copied a styled component's template into a JSP, there's nothing to execute it.

## 2. What *can* cross over

| Asset | Usable in JSP? | Why |
|---|---|---|
| Compiled SCSS (`app.css`) | ✅ | Static CSS: any HTML page can link it |
| CSS custom properties (`--color-primary`) | ✅ | Part of that CSS |
| BEM class names (`btn btn--primary`) | ✅ | Plain HTML attributes |
| CSS Modules class names | ❌ | Hashed names known only to the JS bundle |
| styled-components | ❌ | Runtime JS library |
| The TS theme object | ❌ | JavaScript |

That's the whole reason TaskFlow's design system is **SCSS-first** (10.04 Option A), and why shared components are BEM (07.06).

## 3. The one exception: React islands (S49)

In S49 you'll mount a small **React app inside a JSP page** (a "React island"). Inside that island, styled-components works normally, because React and the bundle are loaded there. The JSP-rendered parts around it still rely only on `app.css`. Same page, two rendering models, which makes this a good test of whether you know where each piece of code runs.

## 4. Summary

- JSP output is server-rendered HTML with static CSS; styled-components requires React + JS in the browser.
- Static assets (compiled SCSS, custom properties, BEM classes) cross over; runtime-generated styles don't.
- React islands (S49) are the exception, and only inside the island.
