# Lecture 10.02 · Typing the Theme: `declare module 'styled-components'` and `DefaultTheme`

> **Section:** S10 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes

---

## 1. The problem

styled-components types `props.theme` as `DefaultTheme`, which the library declares as an **empty interface**. Out of the box, `theme.colors.primary` is a type error, or effectively unchecked depending on setup. Typos like `theme.colours` wouldn't be caught.

## 2. The fix: module augmentation (06.10)

Define the theme as a value, derive its type, and **merge** that type into `DefaultTheme`:

```ts
// src/theme/theme.ts
export const theme = { colors: { … }, space: (n: number) => `${n * 4}px`, … } as const;
export type AppTheme = typeof theme;
```

```ts
// src/styled.d.ts
// Module augmentation (06.10): tell styled-components what our theme looks like.
import 'styled-components';
import type { AppTheme } from './theme/theme';

declare module 'styled-components' {
  // DefaultTheme is an empty interface in the library; we merge our theme's shape into it.
  export interface DefaultTheme extends AppTheme {}
}
```

- **"Values first, type derived"** (06.05): `typeof theme` gives the exact shape, so there's no hand-written interface to keep in sync.
- **`interface DefaultTheme extends AppTheme {}`**: an interface can't be *assigned* a type, but it can *extend* one. Merging this declaration into the library's empty `DefaultTheme` gives every `props.theme` your theme's type.
- **`import 'styled-components'`** at the top makes this file an **augmentation** of the existing module, rather than a declaration of a new one.
- The file must be included by `tsconfig.app.json` (`"include": ["src"]`).

Now:

```tsx
background: ${({ theme }) => theme.colors.surfce};
//                                        ~~~~~~ Property 'surfce' does not exist… Did you mean 'surface'?
```

Autocomplete lists every token. A missing token is a compile error, not a silently transparent background.

## 3. Summary

- `DefaultTheme` is empty until you augment it.
- `export type AppTheme = typeof theme` + `interface DefaultTheme extends AppTheme {}` in a `.d.ts` file.
- Typos and missing tokens become compile errors; autocomplete works everywhere.
