# Lecture 41.17 · 🛡 Defend: Only Relative, Same-Application Paths

> Verified: `S41AuthenticationTest.theReturnUrlCannotLeaveTheApplication` (`https://…`, `//…`, `/\…` → `/taskflow/tasks`), `S39ReusableViewsTest` (the theme switch)

✍️ `src/main/java/com/taskflow/web/Redirects.java`

```java
package com.taskflow.web;

import javax.servlet.http.HttpServletRequest;

/**
 * S41 (41.17): the one place that decides whether a user-supplied redirect target is acceptable (the login's
 * returnUrl, the theme switch's returnTo). Only paths INSIDE this application; anything else → the fallback.
 * An absolute URL (https://evil.example), a protocol-relative one (//evil.example), a backslash trick (/\evil.example)
 * or a header-injection attempt (CR/LF) is refused (24.14, 41.16).
 */
public final class Redirects {

  private Redirects() {}

  public static String safeLocalPath(HttpServletRequest request, String target, String fallback) {
    String appRoot = request.getContextPath() + "/";
    if (target == null || !target.startsWith(appRoot)) return fallback;
    if (target.startsWith("//") || target.contains("\\") || target.contains("\r") || target.contains("\n")) return fallback;
    return target;
  }
}
```

| Rule | Rejects |
|---|---|
| must start with `contextPath + "/"` (`/taskflow/`) | absolute URLs, other apps on the same server, relative paths |
| no `//` at the start | protocol-relative URLs (matters when the context path is empty) |
| no `\` | browsers that treat `/\host` like `//host` |
| no CR/LF | header injection into `Location` |

It's used in **one** place per feature, and nowhere else builds redirects from input:
- `LoginServlet`: `Redirects.safeLocalPath(request, returnUrl, contextPath + "/tasks")`, and the hidden field is re-checked before being written into the form;
- `ThemeServlet` (39.09): the same method (its private copy was removed).

**Stronger alternatives:** store the target server-side (in the session before redirecting to login) instead of a parameter, or map short keys to fixed paths (`?next=tasks`). TaskFlow's allow-list of "our own paths" is the common middle ground.

## ✅ Recap

A redirect target from the request must be a path of this application. One helper decides, and every redirect-from-input uses it.
