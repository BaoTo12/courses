> **Section:** S41 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S41AuthenticationTest.logoutDestroysTheSessionAndPrivatePagesAreNotCached`

✍️ `src/main/java/com/taskflow/web/auth/LogoutServlet.java`

```java
package com.taskflow.web.auth;

import com.taskflow.security.AuthUser;
import com.taskflow.service.AuthService;
import com.taskflow.web.AppContextListener;
import com.taskflow.web.CurrentUser;
import com.taskflow.web.Flash;
import com.taskflow.web.Http;
import java.io.IOException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;

/**
 * S41 (41.08): POST /logout → the whole session is destroyed (not just the user attribute: the CSRF token, the flash,
 * the history go too), then 303 → /login. A POST (with the CSRF token) so another site can't log users out.
 */
@WebServlet("/logout")
public class LogoutServlet extends HttpServlet {

  private AuthService auth;

  @Override
  public void init() {
    auth = AppContextListener.authService(getServletContext());
  }

  @Override
  protected void doPost(HttpServletRequest request, HttpServletResponse response) throws IOException {
    AuthUser user = CurrentUser.get(request);
    HttpSession session = request.getSession(false);
    if (session != null) session.invalidate();
    if (user != null) auth.loggedOut(user.getUsername(), request.getRemoteAddr());
    Flash.put(request, "You have been logged out.");               // a NEW, anonymous session carries the message
    Http.seeOther(response, request.getContextPath() + "/login");
  }
}
```

| Decision | Why |
|---|---|
| **POST**, with the CSRF token | a logout is a state change: as a GET link, any page could log your users out (`<img src="/taskflow/logout">`) |
| `invalidate()`, not `removeAttribute("currentUser")` | everything tied to the login goes: the CSRF token, the history, any flash. Nothing survives into the next person's use of that browser |
| the flash after `invalidate()` | `Flash.put` calls `getSession()`, which creates a **new**, anonymous session to carry "You have been logged out." |
| audit `LOGOUT` | who was logged in, until when |

The nav shows a Log out button (a small form) whenever `currentUser` is set (41.19).

## ✅ Checkpoint

Log out: you land on the login page with the message, and `/taskflow/tasks` redirects to login again.
