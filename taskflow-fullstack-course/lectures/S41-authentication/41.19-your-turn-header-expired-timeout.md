## Requirements

1. **Header:** when someone is logged in, the nav shows `Logged in as <display name>` (escaped) and a **Log out** button (a POST form with the CSRF token). When nobody is, it shows neither.
2. **Session expired:** when a request arrives with a session id the server no longer knows (timeout, restart), the redirect to the login page adds `expired=1`, and the login page shows "Your session has expired. Please log in again." above the form.
3. **Idle timeout:** 15 minutes without a request ends the session.

**Tests:** after login, the task list contains "Logged in as Alice Nguyen"; a request to `/tasks` with `Cookie: JSESSIONID=<made-up value>` is redirected to a login URL ending in `&expired=1`; `/login?expired=1` shows the message.

## Hints

- The views are `session="false"`: read the user from a **request** attribute (`${currentUser}`), set by the authentication filter (34.25).
- `request.getRequestedSessionId()` vs `request.isRequestedSessionIdValid()` (41.02 §4).
- The timeout is configuration, not code (41.04).
- The Log out form needs `${csrfToken}` on **every** page: where can you make sure it's prepared for all logged-in requests?
