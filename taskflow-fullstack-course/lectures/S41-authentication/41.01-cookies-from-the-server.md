# Lecture 41.01 · Cookies from the Server: `new Cookie`, `addCookie`, `getCookies`; Attributes; Deleting

> **Section:** S41 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S39ReusableViewsTest.theThemeSwitchSetsTheCookieAndReturnsToThePage` (`tf_theme`, `Path=/`, `Max-Age`), `S41AuthenticationTest` (`JSESSIONID` with `HttpOnly` and `SameSite=Lax`)

---

The browser side of cookies was S24 (24.01–24.04). This is the server side, in the Servlet API. The full API card is in 39.09; here is the essential.

## 1. Writing

```java
Cookie cookie = new Cookie("tf_theme", "dark");
cookie.setPath("/");                 // which paths it's sent to
cookie.setMaxAge(365 * 24 * 3600);   // seconds; -1 = until the browser closes; 0 = delete
cookie.setHttpOnly(true);            // invisible to JavaScript (not for tf_theme: React reads it)
cookie.setSecure(true);              // HTTPS only
response.addCookie(cookie);          // → Set-Cookie: tf_theme=dark; Max-Age=31536000; Expires=…; Path=/; …
```

## 2. Reading

```java
Cookie[] cookies = request.getCookies();             // null when the request has none!
if (cookies != null) for (Cookie c : cookies) if (c.getName().equals("tf_theme")) …
```

In EL: `${cookie.tf_theme.value}` (34.14). The browser sends back **only** `name=value`: no path, age or flags. A server can't read a cookie's attributes.

## 3. Deleting

There's no "delete" call: send the **same name, path and domain** with `Max-Age=0`. With a different path, the browser keeps the old cookie and adds nothing (the same trap as 24.18 in js-cookie).

## 4. What Tomcat adds

- `JSESSIONID` is written by Tomcat itself (41.02), with `HttpOnly` from `web.xml`'s `<cookie-config>` (28.04).
- `SameSite` has no setter in Servlet 4.0: TaskFlow configures it for all cookies in `META-INF/context.xml` (41.12). The test sees `SameSite=Lax` on `JSESSIONID`.

## ✅ Recap

`new Cookie` + attributes + `addCookie` to write; `getCookies()` (may be `null`) to read names and values only; `Max-Age=0` with the same path to delete.
