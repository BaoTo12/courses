## 1. API

| Type | Members |
|---|---|
| `Cookie` | `new Cookie(name, value)` · `setPath` · `setMaxAge` (s; `-1` browser session, `0` delete) · `setHttpOnly` · `setSecure` · `setDomain` |
| `HttpServletResponse` | `addCookie(cookie)` |
| `HttpServletRequest` | `getCookies()` (may be `null`) · `getSession()` · `getSession(false)` · `changeSessionId()` · `getRequestedSessionId()` · `isRequestedSessionIdValid()` · `getRemoteAddr()` |
| `HttpSession` | `getId` · `get/set/removeAttribute` · `invalidate()` · `setMaxInactiveInterval(s)` · `getCreationTime` · `getLastAccessedTime` · `isNew` |
| config | `web.xml` `<session-config>`: `<session-timeout>` (min), `<cookie-config>` (`http-only`, `secure`), `<tracking-mode>COOKIE`; `context.xml` `<CookieProcessor sameSiteCookies="lax"/>` |

## 2. TaskFlow's authentication pieces

| Class | Job |
|---|---|
| `AuthUser` | serialisable identity in the session: id, username, displayName, role, `isAdmin()` |
| `PasswordHasher` 📦 | BCrypt cost 12: `hash`, `matches`, `burnTime` |
| `LoginThrottle` | 5 failures per account / 20 per IP in 15 min → blocked (even the right password) |
| `AuthService` | `login(username, password, ip)` → `SUCCESS` / `INVALID` / `THROTTLED`; audit `LOGIN_OK` / `LOGIN_FAIL` / `LOGIN_THROTTLED`; `loggedOut` |
| `UserDao.findCredentials` 📦, `AuditDao.record` 📦 | the hash lookup; the append-only audit insert |
| `LoginServlet` | GET form (`expired`, `returnUrl`); POST: `changeSessionId` → session user → `Csrf.reset` → flash → 303 safe return URL; 429 + `Retry-After` when throttled |
| `LogoutServlet` | POST: audit → `invalidate()` → flash → 303 `/login` |
| `AuthenticationFilter` | public paths (`/login`, `/`, `/index.html`, `/favicon.ico`, `/hello`, `/time`, `/static/*`, `/debug/*`); else a user or 303 `/login?returnUrl=…[&expired=1]`; sets request `currentUser`, `Csrf.prepare`, `Cache-Control: no-store` |
| `CurrentUser` | `SESSION_KEY = "currentUser"`; `get(request)` with `getSession(false)` |
| `Redirects.safeLocalPath` | only `contextPath + "/…"`; no `//`, `\`, CR/LF |

## 3. The filter chain now

encoding → logging → security headers (REQUEST, ERROR) → maintenance (admins pass) → **authentication** → CSRF.

## 4. Attacks and defences

| Attack | Defence (lecture) |
|---|---|
| stolen session id via script | `HttpOnly` (41.12) |
| session id over HTTP | `Secure` + HTTPS + HSTS (41.12) |
| cross-site POST with the session | CSRF token (37) + `SameSite=Lax` (41.12) |
| session fixation | `changeSessionId()` at login, `invalidate()` at logout (41.11) |
| user enumeration | one message, one status, `burnTime` (41.14) |
| password guessing / spraying | per-account + per-IP throttle, 429 (41.15) |
| open redirect | `Redirects.safeLocalPath` (41.17) |
| cached private pages after logout | `Cache-Control: no-store` (41.22) |
| database leak → passwords | BCrypt, salted and slow (41.06) |
