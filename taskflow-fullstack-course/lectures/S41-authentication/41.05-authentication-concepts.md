# Lecture 41.05 · Authentication Concepts: Identify, Check, Establish a Session, Log Out

> **Section:** S41 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes

---

| Step | Question | TaskFlow |
|---|---|---|
| **identification** | who do you claim to be? | the username |
| **authentication** | prove it | the password, checked against a slow hash (41.06) |
| **establishing a session** | remember the proof for the next requests | `AuthUser` in the session, under a **new** session id (41.11) |
| **authorisation** | what may you do? | S42 (roles, ownership) |
| **logout** | forget it | `invalidate()` (41.08) |

## The flow

```text
GET  /tasks                          → AuthenticationFilter: no user → 303 /login?returnUrl=/taskflow/tasks
GET  /login                          → the form (+ CSRF token in a pre-login session)
POST /login  username, password     → AuthService.login: throttle? → lookup → BCrypt check → audit
                                       ok: changeSessionId · session.currentUser = AuthUser · 303 → returnUrl (checked)
GET  /tasks                          → the filter finds the user → request.currentUser → the page
POST /logout                         → invalidate → 303 /login
```

## Where each piece lives

| Piece | Layer | Class |
|---|---|---|
| "is this username/password right?" + throttling + audit | service (no HTTP) | `AuthService` (+ `PasswordHasher`, `LoginThrottle`) |
| sessions, redirects, status codes | controller | `LoginServlet`, `LogoutServlet` |
| "is there a user?" for every request | filter | `AuthenticationFilter` |
| who is logged in, for any code | helper | `CurrentUser.get(request)` |

## Alternatives you'll meet at work

Container-managed security (`<login-config>` + `<security-constraint>` in `web.xml`, with Tomcat realms), Spring Security (a filter chain much like S40's, fully featured), single sign-on with OIDC/SAML (an identity provider authenticates; the app receives a token). They all perform the same steps. TaskFlow builds them by hand so you can see each one.

## ✅ Recap

Identify, verify, remember (a session under a fresh id), and forget (logout). Authorisation is a separate question, next section.
