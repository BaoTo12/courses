# 47.A · 📇 API Security for an SPA: Reference (S47)

> One page to look things up.

## 1. Endpoints

| Method | Path | Result |
|---|---|---|
| GET | `/api/auth/csrf` | 204 + `XSRF-TOKEN` cookie (`Path=/`, `SameSite=Lax`, not HttpOnly) |
| POST | `/api/auth/login` `{"username","password"}` + `X-XSRF-TOKEN` | 200 `UserDto` + new `JSESSIONID` + new `XSRF-TOKEN` · 401 `BAD_CREDENTIALS` · 429 `TOO_MANY_REQUESTS` + `Retry-After` · 400 |
| POST | `/api/auth/logout` + `X-XSRF-TOKEN` | 204 |
| GET | `/api/auth/me` | 200 `UserDto` · 401 `UNAUTHENTICATED` |

## 2. Rules for every `/api/*` request

| Rule | Component | Failure |
|---|---|---|
| allowed `Origin` → CORS headers; preflights answered | `CorsFilter` | preflight from another origin → 403, no headers |
| body must be JSON | `ApiExceptionFilter` | 415 |
| unsafe methods: `X-XSRF-TOKEN` == `XSRF-TOKEN` cookie | `CsrfDoubleSubmitFilter` | 403 `CSRF_TOKEN_INVALID` |
| a session user (except `/api/auth/*`) | `AuthenticationFilter` | 401 `UNAUTHENTICATED` (never a redirect) |
| ownership | `TaskService` | 404 `NOT_FOUND` |
| every 401/403 (except anonymous `GET /api/auth/me`) | `ApiExceptionFilter` | audit `ACCESS_DENIED` with `[request <id>]` |

## 3. The filter chain now

encoding → logging → errors → locale → **cors** (`/api/*`) → api (`/api/*`) → security headers → maintenance → **apiCsrf** (`/api/*`) → authentication → authorization → CSRF (pages).

## 4. Configuration

`taskflow.cors.allowedOrigins` (`web.xml`, comma-separated; development: `http://localhost:5173`). `SameSite=Lax` for all cookies (`context.xml`).

## 5. Topologies

Vite proxy (dev, same origin, no CORS) · separate origins (CORS allow-list, credentials) · one WAR (S49, same origin).
