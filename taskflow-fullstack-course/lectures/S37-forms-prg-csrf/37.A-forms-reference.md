# 37.A · 📇 Forms, PRG and CSRF: Reference (S37)

> One page to look things up.

---

## 1. The form-handling recipe

```text
GET  → Csrf.prepare · Flash.consume · attributes (form, errors = {}) → forward to the form
POST → setCharacterEncoding("UTF-8") → Csrf.isValid? (403) → Form.from(request) → validate
         errors → status 400 + forward to the form (form + errors as request attributes)
         ok     → service call (DuplicateKeyException → a form error) → Flash.put → Http.seeOther (303)
```

## 2. Status codes

| Situation | Status |
|---|---|
| invalid input, shown again | 400 |
| missing/wrong CSRF token | 403 |
| the target doesn't exist | 404 |
| GET on a POST-only action | 405 (automatic) |
| success after a POST | 303 See Other + `Location` |

## 4. View patterns (37.06)

| Need | JSP |
|---|---|
| old value in an input | `value="${fn:escapeXml(form.title)}"` |
| old value in a textarea | `<textarea …><c:out value="${form.description}"/></textarea>` |
| error class | `class="form-field${empty errors.title ? '' : ' form-field--error'}"` |
| error text | `<c:if test="${not empty errors.title}">…<c:out value="${errors.title}"/>…</c:if>` |
| selected option (untrusted form value) | compare **strings**: `${p.name() == form.priority ? ' selected' : ''}` |
| CSRF | `<input type="hidden" name="_csrf" value="${csrfToken}">` |
