# Lecture 37.01 · The `<form>` Element: `action`, `method`, `name` → Parameters

> **Section:** S37 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. From fields to a request

```html
<form method="post" action="/taskflow/tasks/new">
  <input name="title" value="Write report">
  <select name="priority"><option>LOW</option><option selected>HIGH</option></select>
  <input type="date" name="dueDate" value="">
  <input type="checkbox" name="urgent" value="yes">          <!-- unchecked: NOT SENT at all -->
  <input name="note" disabled value="x">                      <!-- disabled: NOT SENT -->
  <button type="submit">Create</button>
</form>
```

Submitting sends:

```http
POST /taskflow/tasks/new HTTP/1.1
Content-Type: application/x-www-form-urlencoded

title=Write+report&priority=HIGH&dueDate=
```

## 📇 API card: `<form>` and what becomes a parameter

| Attribute | Default | Meaning |
|---|---|---|
| `action` | the current URL | where the request goes. TaskFlow: `<c:url value='/tasks/new'/>` |
| `method` | `get` | `get` → fields in the **query string**; `post` → fields in the **body** |
| `enctype` | `application/x-www-form-urlencoded` | `multipart/form-data` for file uploads (S45) |
| `novalidate` | off | turns off the browser's own checks (`required`, `maxlength`, `type="date"`) |

| Control | Sent as | Not sent when |
|---|---|---|
| `<input name="x">` | `x=value` (even empty: `x=`) | no `name`, or `disabled` |
| `<select name="x">` | the selected option's `value` (or its text) | — |
| `<input type="checkbox" name="x" value="v">` | `x=v` | **unchecked** |
| several controls with the same `name` | `x=a&x=b` → `getParameterValues("x")` (31.02) | — |
| `<textarea name="x">` | its text | — |
| `<button name="x" value="v">` | `x=v`, only for the clicked button | not clicked |

**Common mistakes:**
- A field without `name`: it's shown, but never sent.
- Expecting an unchecked checkbox to send `false`. It sends nothing, so treat "absent" as false.
- Trusting `disabled`/`readonly`/`hidden` fields: anyone can send any value with DevTools or `curl` (37.04, 37.11).

## 2. How the servlet reads it

`request.getParameter("title")` reads the query string **and** the urlencoded body alike (31.02). For a UTF-8 body, call `request.setCharacterEncoding("UTF-8")` **before** the first `getParameter` (30.17). TaskFlow's POST servlets do it on their first line (S40 moves it into a filter).

## ✅ Recap

A form turns its **named, enabled** controls into `name=value` pairs, in the URL (GET) or the body (POST). Anything the browser can send, an attacker can send too.
