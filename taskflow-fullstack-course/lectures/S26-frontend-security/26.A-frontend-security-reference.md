| Module | API | Lecture |

## 2. What React 19 does and doesn't do (verified)

| Input | React's behaviour |
|---|---|
| text children | escaped |
| attribute values | escaped |
| `href`/`src` = `javascript:…` | replaced with a throwing `javascript:` URL |
| `href` = `data:…`, `https://evil…` | unchanged |
| `dangerouslySetInnerHTML` | unchanged |
| `window.open`, `location`, `innerHTML` | not React's business |

## 3. DOMPurify 3 (26.04)

`DOMPurify.sanitize(dirty, { ALLOWED_TAGS, ALLOWED_ATTR, ADD_ATTR, FORBID_TAGS, FORBID_ATTR, ALLOWED_URI_REGEXP, USE_PROFILES, RETURN_DOM, RETURN_TRUSTED_TYPE })` · `DOMPurify.addHook('afterSanitizeAttributes' | 'uponSanitizeElement' | …, fn)` · `DOMPurify.removeHooks(name)`.

## 4. Sources → sinks (26.07)

**Sources:** `location.*`, `document.referrer`, `window.name`, `postMessage` data, storage, cookies, API data.
**Sinks:** `innerHTML`/`outerHTML`/`insertAdjacentHTML`/`document.write`, `eval`/`Function`/string timers, `location`/`window.open`, `src`/`href` set directly, `dangerouslySetInnerHTML`.

## 5. Headers (server, S40)

| Header | Purpose |
|---|---|
| `Content-Security-Policy` | where scripts, styles, connections and frames may come from; blocks inline script |
| `frame-ancestors 'none'` / `X-Frame-Options: DENY` | clickjacking |
| `X-Content-Type-Options: nosniff` | no MIME sniffing |
| `Referrer-Policy: strict-origin-when-cross-origin` | limits URL leakage |
| `Cache-Control: no-store` (API) | no cached private data |
