## Setup

A "helpful" teammate opened a pull request. Apply their three changes to your project, in a branch `audit/planted`:

**Change 1**, in `src/api/client.ts`: "better debugging"

```ts
api.interceptors.request.use((config) => {
  if (import.meta.env.DEV || new URLSearchParams(location.search).has('debug')) {
    console.log('[api] →', config.method, config.url, config.headers, config.data);
  }
  return config;
});
```

**Change 2**, in `src/pages/TasksPage.tsx`: "the search term highlighted in the empty state"

```tsx
{visibleCount === 0 && q && (
  <p dangerouslySetInnerHTML={{ __html: `No tasks match <mark>${q}</mark>.` }} />
)}
```

**Change 3**, in `src/components/TaskCard.tsx`: "open the task's first link in a popup"

```tsx
const firstLink = parseLinks(task.description).find((s) => s.kind === 'link');
…
{firstLink?.kind === 'link' && (
  <Button size="sm" onClick={() => window.open(firstLink.url, '_blank')}>Open link</Button>
)}
```

## Your job

1. Go through the checklist item by item. For each of the three changes, name **which checklist items** it breaks.
2. For each one, write the **attack**: the exact input and what an attacker gains. Try it locally.
3. Fix each one in the smallest way that keeps the feature. Don't just delete it.
4. Add a test for at least one of the fixes.
