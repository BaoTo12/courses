## 1. Layers (36.01, 36.02)

| Layer | TaskFlow | Rule |
|---|---|---|
| Controller | `web/tasks/*Servlet` | parse → call the service → attributes → forward/redirect/status |
| Service | `service/TaskService` | rules and combining DAOs; no HTTP |
| DAO | 📦 `dao/*` (JPA/Hibernate, provided) | parameters only; the sort from an allow-list |
| View | `WEB-INF/views/**` | EL + JSTL only (`<scripting-invalid>`) |

## 2. `TaskService` (36.03)

`find(TaskFilter)` · `countByStatus()` · `categories()` · `today()` · `details(id)` → `Optional` · `create(task)` · `toggle(id)` · `delete(id)` · `latestId()` · `addComment(taskId, authorId, body)`

`TaskFilter(status, text, categoryId, sort)`: every field optional (`null`), already validated by the controller. `TaskSort.parse(param)`: unknown → `ID`.

## 3. Injection defences (36.08–36.10)

| Variable part | Technique |
|---|---|
| a value | a placeholder + a bound value |
| a `LIKE` search text | bound value + escape `%` `_` and the escape character (`escape '!'`) |
| a sort column/direction | an enum allow-list selected by the input |
| blast radius | least-privilege DB user; hashed passwords; append-only audit |

## 4. Application lifecycle (36.04)

`@WebListener` `ServletContextListener`: `contextInitialized` builds the connection pool, the data layer, the DAOs and the service → `ServletContext` attribute; servlets fetch it in `init()`; `contextDestroyed` closes the data layer and the pool.
