## 2. Endpoint definitions

| Field | Query | Mutation | Meaning |
|---|---|---|---|
| `query(arg)` | ✅ | ✅ | build the base query args |
| `queryFn(arg, api, extraOptions, baseQuery)` | ✅ | ✅ | custom logic instead of `query`; return `{ data } \| { error }` |
| `transformResponse(res, meta, arg)` | ✅ | ✅ | reshape success data |
| `transformErrorResponse(err, meta, arg)` | ✅ | ✅ | reshape the error |
| `providesTags` | ✅ | | tags this entry contains (22.08) |
| `invalidatesTags` | | ✅ | tags this write makes stale (22.08) |
| `keepUnusedDataFor` | ✅ | | seconds kept after the last unsubscribe (22.06) |
| `onQueryStarted(arg, { dispatch, getState, queryFulfilled, … })` | ✅ | ✅ | side effects around the request (optimistic updates: S23) |
| `onCacheEntryAdded(arg, { cacheDataLoaded, cacheEntryRemoved, updateCachedData, … })` | ✅ | | streaming updates for an entry (S23) |
| `serializeQueryArgs`, `merge`, `forceRefetch` | ✅ | | one entry for many args, e.g. infinite scroll (S23) |
| `structuralSharing` | ✅ | ✅ | default `true` (22.06) |
| `extraOptions` | ✅ | ✅ | the third argument of the base query |

## 4. Without hooks: `api.endpoints.X`

| Member | Use |
|---|---|
| `initiate(arg, { subscribe?, forceRefetch?, subscriptionOptions? })` | a thunk. `dispatch` it → a promise with `.unwrap()`, `.refetch()`, `.unsubscribe()`, `.abort()`, `.arg`, `.requestId` (queries). Mutations: `.unwrap()`, `.abort()`, `.reset()`. |
| `select(arg)` | a selector for one cache entry. Create it **once**, at module level (22.09). Its `isLoading` is status-based (22.14). |
| `matchPending`, `matchFulfilled`, `matchRejected` | matchers for `addMatcher`, listeners and middleware (22.09). `action.meta.arg.originalArgs` is the arg. |

## 6. Organising a big API: `injectEndpoints`

```ts
// features/comments/commentsApi.ts
export const commentsApi = apiSlice.injectEndpoints({
  endpoints: (build) => ({ getComments: build.query<Comment[], number>({ /* … */ }) }),
});
export const { useGetCommentsQuery } = commentsApi;
```

- It is the **same** API slice (one reducer, one middleware, one tag space), with endpoints declared in feature files.
- Injecting an endpoint name that already exists is **ignored**, with a console error in development. `overrideExisting: true` replaces it (useful for hot reload), and `'throw'` makes it throw. TaskFlow keeps one file for now; S23 splits it.
