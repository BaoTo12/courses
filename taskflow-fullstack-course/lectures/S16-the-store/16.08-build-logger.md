# Lecture 16.08 · 🛠 Build: `loggerMiddleware`, Then 🛡 Redact `password`/`token` Fields

> **Section:** S16 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~45 minutes

> **Security scope:** sensitive data exposure in logs (OWASP A09 "Security Logging and Monitoring Failures" covers both too little and too much logging)

---

## 1. What a good logger logs

A naive logger prints the action and the **whole** state after every dispatch. Two problems:
- **Noise and cost:** TaskFlow's state includes every task. Printing it on every action is slow and unreadable.
- **Data exposure:** actions and state contain user content (task titles, comments) and, from S24, credentials (`auth/loginRequested` with a password, a CSRF token). Logs get copied into bug reports, screenshots and log-collection services.

TaskFlow's logger prints instead:
- the action **type**;
- the action, with sensitive fields **redacted**;
- **which slices changed**: the keys whose reference changed (14.06's rule, used as a diagnostic);
- how long the reducers took.

## 2. ✍️ `src/app/middleware/redact.ts`

```ts
/** Keys whose values must never reach logs, analytics or crash reports (16.08). */
const SENSITIVE_KEY = /pass(word)?|token|secret|authorization|cookie|session|csrf|xsrf/i;

export const REDACTED = '[REDACTED]';

/**
 * Returns a deep COPY of `value` with sensitive fields replaced. Never mutates the input
 * (it may be an action or state object that Redux still holds).
 */
export function redact(value: unknown, depth = 0): unknown {
  if (depth > 8) return '[…]'; // don't walk huge or cyclic structures
  if (Array.isArray(value)) return value.map((item) => redact(item, depth + 1));
  if (typeof value === 'object' && value !== null) {
    return Object.fromEntries(
      Object.entries(value).map(([key, item]) => [key, SENSITIVE_KEY.test(key) ? REDACTED : redact(item, depth + 1)]),
    );
  }
  return value;
}
```

- **A deep copy**, never mutation. The action object still belongs to Redux, and the reducers may be running with it.
- **Keys matched by pattern**, case-insensitive: `password`, `newPassword`, `csrfToken`, `Authorization`, `sessionId`…
- **A depth limit** protects against huge or cyclic values. Actions should never contain those, but a logger must not crash the app if one does.
- It's a **denylist of key names**, so it can miss a secret stored under an innocent name (`{ code: '123456' }`). That's acceptable for a **development** logger. For data that leaves the browser (analytics, 16.12), use an **allowlist** instead.

## 3. ✍️ `src/app/middleware/logger.ts`

```ts
import { isAction } from 'redux';
import type { Middleware } from 'redux';
import { redact } from './redact';

type Log = (message: string, details: { action: unknown; changed: string[]; ms: number }) => void;

/** Which top-level slices got a NEW reference: the cheap way to see what an action changed (14.06). */
function changedSlices(before: unknown, after: unknown): string[] {
  if (typeof before !== 'object' || before === null || typeof after !== 'object' || after === null) return [];
  const prev = before as Record<string, unknown>;
  const next = after as Record<string, unknown>;
  return Object.keys(next).filter((key) => prev[key] !== next[key]);
}

/**
 * Logs every action (REDACTED) and which slices it changed. Deliberately does NOT log whole states:
 * they can be large and can contain personal data (16.08).
 */
export function createLoggerMiddleware(log: Log = (message, details) => console.debug(message, details)): Middleware {
  return (storeAPI) => (next) => (action) => {
    // Redux 5 types `action` as unknown: thunks (functions) also travel through middleware (S18).
    if (!isAction(action)) return next(action);
    const before = storeAPI.getState();
    const startedAt = performance.now();
    const result = next(action); // everything after this line runs once the reducers are done
    log(`[redux] ${action.type}`, {
      action: redact(action),
      changed: changedSlices(before, storeAPI.getState()),
      ms: Math.round((performance.now() - startedAt) * 100) / 100,
    });
    return result; // ALWAYS return what next() returned (16.15)
  };
}
```

- **A factory** (`createLoggerMiddleware(log)`) instead of a constant: tests inject a fake `log` (`vi.fn()`), and the app uses `console.debug` (hidden unless the console's "Verbose" level is enabled).
- **`isAction` first** (16.07 §4): anything that isn't an action is passed on untouched.
- **`before` is read before `next`**, and `getState()` after: the difference is what this action did.
- **`return result`**: the value `next` returned must travel back up. Forgetting it is 16.15's bug.

## 4. ✍️ Tests (in `src/app/middleware/middleware.test.ts`)

```ts
describe('redact', () => {
  it('replaces sensitive fields at any depth, without mutating the input', () => {
    const input = { type: 'auth/loginRequested', payload: { username: 'alice', password: 'alice123', nested: [{ csrfToken: 'x' }] } };
    const copy = structuredClone(input);
    expect(redact(input)).toEqual({
      type: 'auth/loginRequested',
      payload: { username: 'alice', password: REDACTED, nested: [{ csrfToken: REDACTED }] },
    });
    expect(input).toEqual(copy);
  });
});

describe('logger middleware (16.08)', () => {
  it('logs the redacted action and which slices changed, and returns next()’s result', () => {
    const log = vi.fn();
    const store = createStore(rootReducer, applyMiddleware(createLoggerMiddleware(log)));
    const action = sortChanged('title', 'desc');
    expect(store.dispatch(action)).toBe(action);
    expect(log).toHaveBeenCalledTimes(1);
    const [message, details] = log.mock.calls[0] ?? [];
    expect(message).toBe('[redux] listPrefs/sortChanged');
    expect(details.changed).toEqual(['listPrefs']);
  });

  it('reports no changed slices for an action nobody handles', () => {
    const log = vi.fn();
    const store = createStore(rootReducer, applyMiddleware(createLoggerMiddleware(log)));
    store.dispatch(sortChanged('dueDate', 'asc')); // the current value
    expect(log.mock.calls[0]?.[1].changed).toEqual([]);
  });
});
```

The second test is a nice by-product of 15.12's "same reference when nothing changes": the logger can report **no change**, which helps spot pointless dispatches.

## 5. Summary

- Log the action type, a redacted action, and which slices changed. Not whole states.
- Redact by key pattern with a deep copy; never mutate what Redux owns.
- Always return `next(action)`'s result.
