## B. Code reading

   type A = (typeof PRIORITIES)[number];

8. `props.theme.colours.primary` compiles in a styled component and is `undefined` at runtime. What's missing? [06.10]

## D. Design

9. Should `CreateTaskRequest` include `ownerId`? Explain both the type-level and the security-level answer. [06.04]
10. Should the frontend DTO types mirror the Java classes exactly? Discuss `passwordHash`, dates and enums. [06.04]

## E. Implementation

11. Write `assertNever(x: never): never` from memory and use it to make a `priorityIcon(priority)` function exhaustive. Then write `isCategory(value: unknown): value is Category` with tests.

<details>
<summary><b>Answers</b></summary>

1. A discriminated union makes invalid combinations **unrepresentable**, and narrowing gives safe access to state-specific data. The boolean version allows e.g. `loading: true` + `error`, or `error` + `data` together, forcing defensive code everywhere.

2. It promises the compiler that when the function returns `true`, the value **is** a `T`. **You** are responsible: the runtime check must be correct. A wrong guard is as unsafe as `as`.

3. JavaScript can `throw` any value (strings, plain objects, `undefined`), not just `Error`s. `unknown` forces you to narrow (`instanceof Error`, type guards) before reading properties.

4. The type of the store's `getState` **function** (`() => State`). Wrapping it in another `ReturnType` gives the state shape itself. You'll see `RootState = ReturnType<typeof store.getState>` in S17.

5. `A` = `'LOW' | 'MEDIUM' | 'HIGH'`; `B` = `TaskStatus`; `C` = `'TODO' | 'IN_PROGRESS'`.

6. `Array.prototype.every` has an overload whose callback is a type predicate `(value) => value is S`, returning `this is S[]`. The length comparison is just a number comparison; TS can't connect it to the element types.

7. `e` is `unknown`, so `.message` isn't accessible. Use `setError(toErrorMessage(e))` (06.08), or `e instanceof Error ? e.message : String(e)`.

8. A **module augmentation** of styled-components' `DefaultTheme` (06.10). Without it, TypeScript can't check the theme's shape (and depending on setup it may be `any`-like). With `declare module 'styled-components' { export interface DefaultTheme { colors: … } }`, the typo `colours` is a compile error.

9. **No.** Type level: `Omit<Task, 'id' | 'ownerId' | …>` documents that the client doesn't choose the owner. Security level: the **server** must set the owner from the authenticated session and ignore/reject any `ownerId` in the body (mass assignment, S37/S46). Types are not enforcement.

10. No. DTOs model **what the API sends**: never `passwordHash`; dates as ISO **strings**; Java enums as string literal unions with identical values; nullability as `| null` matching the JSON; separate request and response shapes.

11. Example:
    ```ts
    export function assertNever(value: never): never {
      throw new Error(`Unexpected value: ${JSON.stringify(value)}`);
    }

    export function priorityIcon(p: Priority): string {
      switch (p) {
        case 'LOW': return '▽';
        case 'MEDIUM': return '◇';
        case 'HIGH': return '▲';
        default: return assertNever(p);
      }
    }

    export function isCategory(value: unknown): value is Category {
      return (
        typeof value === 'object' && value !== null &&
        'id' in value && typeof value.id === 'number' &&
        'name' in value && typeof value.name === 'string' &&
        'color' in value && typeof value.color === 'string'
      );
    }
    ```
    Tests: valid object → true; missing `color` → false; `null` → false; `id: '1'` → false.
