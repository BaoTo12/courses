# Lecture 43.01 · Two Kinds of Errors: `sendError(status)` vs an Exception

> **Section:** S43 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes

---

| | `response.sendError(404)` | `throw new IllegalStateException(…)` |
|---|---|---|
| who decides | the code: an **expected** outcome ("no such task") | nobody: something **unexpected** went wrong (a bug, the database is down) |
| status | the one you pass | 500 (unless something maps it) |
| what the container does | marks the response as an error; when the request returns, shows the error page for that **status** | catches it at the top; logs it; shows the error page for that **exception type**, or for 500 |
| the rest of your method | keeps running: `return` right after it! | doesn't run |

## `sendError` vs `setStatus`

| Call | Body | Error page? | TaskFlow uses it for |
|---|---|---|---|
| `setStatus(400)` + your own forward | **your** view | no | a form with validation errors (37.05): the form page, status 400 |
| `sendError(400, message)` | the container's error page | **yes** | "the request makes no sense" (`id=abc`) |
| `setStatus(503)` + forward | your view | no | the maintenance page (40.15) |
| `setStatus(429)` + your view | your view | no | the throttled login (41.15) |

`sendError` also **clears the buffer**: anything already written (but not yet sent) is discarded. After the response is committed, it throws `IllegalStateException` (43.07).

## Where each kind comes from in TaskFlow

```java
throw new NotFoundException();                                  // 43.08: expected, mapped to 404
throw new BadRequestException("Parameter 'id' must be …");      // 43.12: expected, mapped to 400
throw new AccessDeniedException("task 23");                     // 42.05: expected, mapped to 404 + audit
// a Hibernate exception, a NullPointerException                // unexpected → 500 + logged with details
```

From S43 on, controllers **throw** the expected ones and `ErrorHandlingFilter` calls `sendError`: one mapping instead of `sendError` + `return` in every controller.

## ✅ Recap

Expected failures get a chosen status; unexpected ones become 500. `sendError` hands the page to the container's error pages; `setStatus` keeps it yours.
