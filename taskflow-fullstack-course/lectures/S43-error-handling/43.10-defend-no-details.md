# Lecture 43.10 · 🛡 Defend: Custom Pages Everywhere, `ErrorReportValve`, an Error ID, Details Only in Logs

> **Section:** S43 · **Type:** 🛡 Defend · **Track:** ★ Core · **Time:** ~25 minutes
> Verified: `S43ErrorHandlingTest.anUnhandledExceptionShowsOnlyTheRequestId`, `.tomcatsOwnErrorPagesShowNoVersionOrReport`

---

## 1. The layers

| Layer | What it covers | TaskFlow |
|---|---|---|
| the application maps exceptions | everything inside the filter chain | `ErrorHandlingFilter` (43.08) |
| `<error-page>` for every status + `Throwable` + a default | everything inside the web app | `web.xml` (43.02) |
| **`ErrorReportValve`** | what the web app can't handle: other context paths, an error page that fails, requests rejected before any app runs | `tomcat/server.xml` |
| logging | the details, for developers | logback, with the request id |

## 2. ✍️ `ErrorReportValve` (📦 `backend/tomcat/server.xml`)

```xml
<Host name="localhost" appBase="webapps" unpackWARs="true" autoDeploy="true">
  <!-- 🛡 no stack traces, no exception messages, no server version in Tomcat's own error pages -->
  <Valve className="org.apache.catalina.valves.ErrorReportValve" showReport="false" showServerInfo="false"/>
  …
</Host>
```

`docker-compose.yml` mounts it over the image's `conf/server.xml`. With a native install (28.01), edit `conf/server.xml` the same way. The test harness configures the embedded Tomcat identically, and `GET /no-such-application/` proves it: "HTTP Status 404", nothing more.

## 3. The error ID

The 500 page shows the **request id** that `RequestLoggingFilter` created (40.06):

```text
Browser:  If you contact support, quote this reference: c950ed634b09fd0
Response: X-Request-Id: c950ed634b09fd0
```

The log of that test run (captured from `mvn package`):

```text
22:09:09.692 ERROR [c950ed634b09fd0] c.t.w.f.ErrorHandlingFilter - Unhandled exception: GET /taskflow/debug/fail
java.lang.IllegalStateException: Simulated failure in SELECT password_hash FROM users WHERE id = 3 (taskflow_app@mysql:3306)
	at com.taskflow.web.debug.FailServlet.doGet(FailServlet.java:32)
22:09:09.693 INFO  [c950ed634b09fd0] c.t.w.f.RequestLoggingFilter - GET /taskflow/debug/fail 500 1ms
```

One id links the user's report to the full details, which only people with log access can see.

## 4. Logs are sensitive too

Logs hold the details on purpose, so treat them as confidential: restricted access, retention limits, no secrets written into them in the first place (43.11).

## ✅ Recap

Map every error to a page with a status and a fixed text, configure Tomcat's own page to say nothing, and give users a reference that leads to the logged details.
