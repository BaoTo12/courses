# 43.A · 📇 Error Handling: Reference (S43)

> One page to look things up.

---

## 1. API

| Piece | Use |
|---|---|
| `response.sendError(sc)` / `sendError(sc, msg)` | error status → the container's `<error-page>`; clears the buffer; `IllegalStateException` if committed |
| `response.setStatus(sc)` | the status only; your own body |
| `response.isCommitted()`, `resetBuffer()` | before changing course |
| `<error-page>`: `<error-code>`, `<exception-type>`, `<location>` alone (default) | `web.xml` |
| `javax.servlet.error.status_code`, `.message`, `.exception`, `.exception_type`, `.request_uri`, `.servlet_name` | request attributes during the ERROR dispatch |
| `${pageContext.errorData}` → `statusCode`, `requestURI`, `servletName`, `throwable` | in JSPs |
| `<%@ page errorPage=… isErrorPage=… %>` | JSP-level (not used in MVC, 43.05) |
| `ErrorReportValve` `showReport`, `showServerInfo` | `server.xml`: Tomcat's own error pages |

## 2. TaskFlow's mapping (`ErrorHandlingFilter`, after logging)

| Thrown | Status | Page | Extra |
|---|---|---|---|
| `NotFoundException` | 404 | `404.jsp` | |
| `BadRequestException(msg)` | 400 | `400.jsp` shows `msg` | fixed texts only |
| `AccessDeniedException` | 404 | `404.jsp` | audit `ACCESS_DENIED` |
| anything else | 500 | `500.jsp` + reference (`requestId`) | logged with stack trace |
| (filter) non-admin on `/admin/*` | 403 | `403.jsp` | audit `ACCESS_DENIED` |
| other `sendError`s (405, …) | as sent | `error.jsp` | |
| committed response | unchanged | none | logged only |

## 3. The filter chain now

encoding → logging → **errors** → security headers (REQUEST, ERROR) → maintenance → authentication → authorization → CSRF.

## 4. Files

`web/errors/{NotFoundException, BadRequestException}`, `web/filters/ErrorHandlingFilter`, `Params.requiredId`, `views/errors/{400,403,404,500,error}.jsp`, `web/debug/FailServlet` (`/debug/fail[?after=commit]`, loopback), 📦 `backend/tomcat/server.xml` (mounted by `docker-compose.yml`).

## 5. Error page checklist

- [ ] status preserved (not 200)
- [ ] `pageTitle` set in the page; the layout doesn't need a controller
- [ ] no user, session, database or REQUEST-only filter required
- [ ] nothing from exceptions; user input escaped or not shown
- [ ] a reference number on 500
