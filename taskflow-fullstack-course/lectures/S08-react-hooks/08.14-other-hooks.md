# Lecture 08.14 · `useLayoutEffect`, `useId`, `useTransition` and `useDeferredValue`: an Overview

> **Section:** S08 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~20 minutes

---

## 1. `useLayoutEffect`: effects before paint

Same API as `useEffect`, but it runs **after the DOM update and before the browser paints**:

```text
render → commit (DOM updated) → useLayoutEffect → paint → useEffect
```

Use it only when an effect **measures layout and immediately changes something visible**, e.g. positioning a tooltip based on the trigger's size, to avoid a one-frame flicker. It blocks painting, so it's slower. Default to `useEffect`.

## 2. `useId`: unique IDs for accessibility

```tsx
const id = useId();                   // React 19.2 produces e.g. "_r_0_" (older versions used ":r0:"). Never rely on the format
<label htmlFor={id}>Search</label>
<input id={id} />
<p id={`${id}-help`}>…</p>             // derive related IDs from one base
```

- Stable across re-renders; unique per component instance; consistent between server and client rendering.
- For `htmlFor`, `aria-describedby`, `aria-labelledby`. **Not** for list keys (use data IDs, 07.11).

TaskFlow's `SearchBox` uses it (08.12), and form fields will in S11.

## 3. `useTransition`: mark an update as non-urgent

```tsx
const [isPending, startTransition] = useTransition();

function handleFilterChange(status: TaskStatus | null) {
  startTransition(() => {
    setStatusFilter(status);            // may re-render a huge list: can be interrupted
  });
}
```

React keeps urgent updates (typing, clicking) responsive and renders the transition in the background, interrupting it if needed. `isPending` lets you show a subtle indicator.

## 4. `useDeferredValue`: a lagging copy of a value

```tsx
const deferredQuery = useDeferredValue(query);
const visible = useMemo(() => filterTasks(tasks, { q: deferredQuery }), [tasks, deferredQuery]);
```

The input updates immediately with `query`; the expensive list re-renders with `deferredQuery` when React has time. It's similar in spirit to debouncing, but adaptive (no fixed delay) and **no fewer network requests**. For server calls, keep `useDebounce`.

## 5. When to reach for these

| Hook | TaskFlow uses it? |
|---|---|
| `useLayoutEffect` | Not needed (no measure-then-position UI yet) |
| `useId` | ✅ form fields and labels |
| `useTransition` / `useDeferredValue` | Optional: only if profiling shows large list renders blocking input |

## 6. Summary

- `useLayoutEffect`: before paint, for measure-and-adjust; blocks painting.
- `useId`: stable unique IDs for label/ARIA wiring.
- `useTransition` / `useDeferredValue`: keep urgent interactions responsive while heavy renders happen in the background.
