## 2. Shapes

```text
TaskDto     {id, title, description, status, priority, dueDate|null, categoryId|null, ownerId, createdAt, updatedAt}
CommentDto  {id, taskId, authorId, body, createdAt}
CategoryDto {id, name, color}
UserDto     {id, username, displayName, role, locale}
PageDto     {items, page (0-based), size, totalItems, totalPages}
StatsDto    {total, byStatus{TODO,IN_PROGRESS,DONE}, byPriority{LOW,MEDIUM,HIGH}}
ApiError    {status, error, message, fieldErrors?, path, timestamp}
```

Dates: `LocalDate` → `"YYYY-MM-DD"`, `Instant` → `"…Z"`.

## 3. Error codes

`VALIDATION_FAILED` (400, `fieldErrors`) · `MALFORMED_JSON` (400) · `UNSUPPORTED_MEDIA_TYPE` (415) · `NOT_FOUND` (404) · `UNAUTHENTICATED` (401, S47) · `CSRF_TOKEN_INVALID` (403, S47) · `INTERNAL_ERROR` (500).

## 4. Classes

| Class | Job |
|---|---|
| 📦 `web/api/Json` | the one `ObjectMapper`: JavaTimeModule, ISO dates, unknown properties ignored; `readTree`, `read`, `write` |
| `Api` | `path(request)` = servletPath + pathInfo; `isApiRequest` |
| `ApiServlet` | `service()` → `route(method, segments)`; `id(segment)` |
| `TaskApiServlet`, `CategoryApiServlet`, `StatsApiServlet`, `ApiFallbackServlet` | the resources |
| `TaskInput` | request validation, POST/PUT full, PATCH partial; only six fields |
| `dto/Dtos` | response records |
| `ApiError`, `ApiException` | the error body, the thrown outcome |
| `filters/ApiExceptionFilter` (`/api/*`, after `locale`) | 415; exceptions → JSON; `AccessDeniedException` → 404 + audit |
| `CsrfFilter` | skips `/api/*` (JSON-only bodies; S47: double-submit) |

## 5. The filter chain now

encoding → logging → errors → locale → **api (`/api/*`)** → security headers → maintenance → authentication → authorization → CSRF (pages only).
