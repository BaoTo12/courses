# Lecture 46.16 · 🐞 Debug: The API Returns the HTML 404 Page Instead of JSON

> **Section:** S46 · **Type:** 🐞 Debug · **Track:** ★ Core · **Time:** ~15 minutes
> Verified: `S46JsonApiTest.everyApiErrorIsJson`

---

## 1. Symptom

React shows "Unexpected token '<'" or a generic error: Axios got `<!doctype html>…Page not found…` where it expected JSON. The Network tab shows `text/html` with status 404 or 405.

## 2. Where HTML error pages come from, for `/api` URLs

| Cause | Mechanism |
|---|---|
| a path **no servlet maps**: `/api/task` (typo), `/api/categories/1` | the default servlet → `sendError(404)` → `<error-page>` → `404.jsp` |
| a **method** the servlet doesn't override: `DELETE /api/tasks` | `HttpServlet.service` → `sendError(405)` → `error.jsp` |
| `PATCH` on a plain `HttpServlet` | 501 from `HttpServlet.service` |
| `sendError(…)` anywhere in API code | always the page |
| an exception thrown **outside** the API filter's reach (before it in the chain) | `ErrorHandlingFilter` → a page |
| a filter answering with a page: the auth redirect (303 to `/login`, S47), maintenance (503 HTML) | not an error page, but still not JSON |

## 3. TaskFlow's fixes

- `ApiFallbackServlet` on `/api/*`: every unclaimed API path → JSON 404.
- `ApiServlet` overrides `service()`: every method goes through `route`, unknown combinations throw `ApiException.noEndpoint`.
- API code **throws** `ApiException`, never calls `sendError`.
- `ApiExceptionFilter` sits early (right after `locale`).
- S47 makes authentication answer JSON 401 on `/api/*`.

## 4. Check

```bash
curl -i -b "JSESSIONID=…" -X DELETE http://localhost:8080/taskflow/api/tasks
```

→ `404`, `Content-Type: application/json;charset=UTF-8`, `{"status":404,"error":"NOT_FOUND","message":"No endpoint DELETE /api/tasks",…}`.

## ✅ Takeaway

An API must answer in JSON on **every** path, including paths and methods nobody wrote code for.
