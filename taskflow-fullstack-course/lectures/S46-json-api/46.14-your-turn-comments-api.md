## Requirements (the contract)

| Request | Response |
|---|---|
| `GET /api/tasks/{id}/comments` | 200 `[{"id","taskId","authorId","body","createdAt"}, …]`, oldest first |
| `POST /api/tasks/{id}/comments` `{"body": "…"}` | 201 + `Location: …/api/tasks/{id}/comments/{commentId}` + the comment |
| body blank or longer than 1000 characters | 400 `VALIDATION_FAILED`, `fieldErrors.body = "must be 1 to 1000 characters"` |
| a task that doesn't exist, or isn't the caller's | 404 `NOT_FOUND` |

The author is the caller. HTML in the body is stored as typed (escaping is the renderer's job: 35.15, S26).

**Tests:** comments of task 1 have exactly the five fields; `{"body":"   "}` → 400; `{"body":"<b>stored as typed</b>"}` → 201 with that body and the right `Location`; comments of task 23 as alice → 404.
