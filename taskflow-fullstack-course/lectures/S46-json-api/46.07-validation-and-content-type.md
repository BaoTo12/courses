# Lecture 46.07 · Validation → 400 `fieldErrors`; `Content-Type` → 415; Malformed JSON → 400

> **Section:** S46 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S46JsonApiTest.invalidBodiesGetTheRightStatus`

## 1. Three different failures

| Request | Status | `error` | Detected by |
|---|---|---|---|
| `Content-Type: text/plain` (or a form encoding) with a body | **415** | `UNSUPPORTED_MEDIA_TYPE` | `ApiExceptionFilter`, before any servlet |
| `{"title": ` (cut off) | **400** | `MALFORMED_JSON` | `Json.readTree` |
| `{}` or `{"dueDate": "2026-02-30"}` | **400** | `VALIDATION_FAILED` + `fieldErrors` | `TaskInput` |
| a title the user already has | **400** | `VALIDATION_FAILED` + `fieldErrors.title` | the database's unique key |

```json
{"status":400,"error":"VALIDATION_FAILED","message":"Request contains invalid fields",
 "fieldErrors":{"title":"must not be blank","status":"must be one of TODO, IN_PROGRESS, DONE","priority":"must be one of LOW, MEDIUM, HIGH"},
 "path":"/api/tasks","timestamp":"2026-09-26T15:02:11.482Z"}
```

`fieldErrors` keys are the **JSON field names**, so React maps them straight onto its form fields (`EditTaskPage`'s `fieldErrorsOf`).

## 2. 🛡 Why the 415 matters for security

A cross-site HTML form can only send `application/x-www-form-urlencoded`, `multipart/form-data` or `text/plain`. Anything else (`application/json`) requires JavaScript, and a cross-origin script sending it triggers a **CORS preflight**, which TaskFlow doesn't approve (47.08). So "JSON bodies only" means a forged form post can't reach a write endpoint: the API's first line of CSRF defence. S47 adds a double-submit token as the second.

That's also why `CsrfFilter` (the hidden-field check of S37/S40) skips `/api/*`: the API has its own rule set.

## 3. Validation style

- Validate **everything** before changing anything (all errors at once, not one per round trip).
- Report the **field** and a short, fixed message; never echo the value (43.13).
- Type errors are validation errors: `"title": 42` → `must not be blank` (not a 500).
- Rules only the server can check (uniqueness) arrive through the same `fieldErrors` shape.

## ✅ Recap

415 for the wrong format, 400 `MALFORMED_JSON` for broken JSON, 400 `VALIDATION_FAILED` with per-field messages for everything that parsed but isn't acceptable.
