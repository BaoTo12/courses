# Lecture 09.09 · 🛠 Build: `PriorityBar` and `Avatar`

> **Section:** S09 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~35 minutes
> **Project feature:** a 3-segment priority bar on each card; a user avatar in the header
> Verified in the reference app: build and lint clean; the avatar renders "AN"; segment classes look like `sc-hKwBjT lkDdMB`.

---

## 1. ✍️ `src/components/styled/PriorityBar.tsx`

```tsx
import styled from 'styled-components';
import type { Priority } from '../../domain/types';
import { PRIORITY_COLOR } from '../../domain/labels';

const PRIORITY_LEVEL: Record<Priority, number> = { LOW: 1, MEDIUM: 2, HIGH: 3 };

const Track = styled.div`
  display: flex;
  gap: 2px;
  width: 48px;
  height: 6px;
`;

const Segment = styled.span<{ $filled: boolean; $color: string }>`
  flex: 1;
  border-radius: 999px;
  background: ${({ $filled, $color }) => ($filled ? $color : 'var(--color-border)')};
  transition: background-color 150ms ease;
`;

/** Three segments, filled according to priority, in the priority colour. */
export function PriorityBar({ priority }: { priority: Priority }) {
  const level = PRIORITY_LEVEL[priority];
  const color = PRIORITY_COLOR[priority];
  return (
    <Track role="img" aria-label={`Priority: ${priority.toLowerCase()}`}>
      {[1, 2, 3].map((n) => (
        <Segment key={n} $filled={n <= level} $color={color} />
      ))}
    </Track>
  );
}
```

Notes:
- **`PRIORITY_COLOR` from `domain/labels.ts`** (06.13) is the TypeScript copy of the priority colours. The SCSS `$priority-colors` map (03.05) is the other copy. Two sources of truth for the same colours is a smell; S10 fixes it by moving shared values to CSS custom properties.
- **`role="img"` + `aria-label`**: a purely visual bar needs a text alternative for screen readers ("Priority: high").
- **Styled components are defined at module level**, never inside `PriorityBar` (09.11, 09.15).
- Only **two distinct CSS results** exist per colour (filled/empty), so few classes are generated regardless of how many cards render.

Add it to `TaskCard` next to the badges:

```tsx
import { PriorityBar } from './styled/PriorityBar';
// …
<PriorityBadge priority={task.priority} />
<PriorityBar priority={task.priority} />
```

## 2. ✍️ `src/components/styled/Avatar.tsx`

```tsx
import styled from 'styled-components';

type AvatarSize = 'sm' | 'md' | 'lg';
const SIZE_PX: Record<AvatarSize, number> = { sm: 24, md: 32, lg: 48 };

// A fixed palette: colours come from OUR list, never from user input (see 10.10).
const PALETTE = ['#4f46e5', '#0891b2', '#16a34a', '#ca8a04', '#dc2626', '#9333ea'] as const;

function colorFor(name: string): string {
  let hash = 0;
  for (const char of name) hash = (hash * 31 + char.charCodeAt(0)) >>> 0;
  return PALETTE[hash % PALETTE.length] ?? PALETTE[0];
}

function initials(name: string): string {
  return name
    .split(/\s+/)
    .filter(Boolean)
    .slice(0, 2)
    .map((part) => part[0]?.toUpperCase() ?? '')
    .join('');
}

const Circle = styled.span<{ $size: number; $color: string }>`
  display: inline-grid;
  place-items: center;
  width: ${({ $size }) => $size}px;
  height: ${({ $size }) => $size}px;
  border-radius: 50%;
  background: ${({ $color }) => $color};
  color: #fff;
  font-size: ${({ $size }) => Math.round($size * 0.4)}px;
  font-weight: 600;
  user-select: none;
`;

interface AvatarProps {
  name: string;
  size?: AvatarSize;
}

export function Avatar({ name, size = 'md' }: AvatarProps) {
  return (
    <Circle $size={SIZE_PX[size]} $color={colorFor(name)} title={name} aria-label={name} role="img">
      {initials(name)}
    </Circle>
  );
}
```

Walkthrough:
- **Public API vs styled internals** (09.04): consumers write `<Avatar name="An Nguyen" size="sm" />`; the `$size`/`$color` transient props are hidden.
- **`colorFor`** hashes the name into a fixed palette. It's deterministic (same name → same colour), pure (04.06), and **safe**, because the colour always comes from our own list. `>>> 0` keeps the hash an unsigned 32-bit integer. `?? PALETTE[0]` satisfies `noUncheckedIndexedAccess` (the modulo guarantees a valid index, but TypeScript can't prove it).
- **`initials`**: `"An Nguyen"` → `"AN"`. `part[0]?.` handles empty strings.
- `colorFor` and `initials` are **not exported**, so the file still exports only a component (Fast Refresh rule, 07.06).

Put it in the header (`PageLayout.tsx`), inside the `Stack` from 09.03:

```tsx
<Stack $direction="row" $gap={3} $align="center" style={{ marginLeft: 'auto' }}>
  <ThemeToggle />
  <Avatar name="An Nguyen" size="sm" />
</Stack>
```

(The name becomes the logged-in user's `displayName` in S24.)
