# Lecture 09.10 · Pseudo-Classes, Nesting, `&`, and Referring to Other Components

> **Section:** S09 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. SCSS-like nesting

styled-components uses a CSS preprocessor (stylis) that supports nesting and `&`, much like SCSS (02.05):

```tsx
const Item = styled.li`
  padding: 8px;

  &:hover { background: var(--color-surface-muted); }
  &:focus-within { outline: 2px solid var(--color-primary); }
  & + & { border-top: 1px solid var(--color-border); }
  &::before { content: '•'; margin-right: 8px; }

  > a { color: inherit; }                         /* direct child */
  @media (min-width: 768px) { padding: 12px; }    /* nested media query */
`;
```

`&` is replaced by the component's generated class, so `&:hover` becomes `.hash:hover`. The same specificity advice applies: keep nesting shallow.

## 2. Referring to another styled component

Inside a template, interpolating a **styled component** produces its **stable component-ID selector** (the `sc-…` class from 09.02):

```tsx
const Actions = styled.div`
  opacity: 0;
  transition: opacity 150ms ease;
`;

const Row = styled.div`
  &:hover ${Actions},
  &:focus-within ${Actions} {
    opacity: 1;          /* reveal the actions when the row is hovered or focused */
  }
`;
```

And the reverse, "style me differently when inside X":

```tsx
const Title = styled.h3`
  font-size: 1rem;

  ${Row}:hover & {
    color: var(--color-primary);
  }
`;
```

This only works for **styled components** (they have a known selector). For a plain React component, wrap it: `const StyledCard = styled(Card)``;` and refer to `StyledCard`.

(Revealing actions only on hover would hide them from keyboard and touch users. That's why the example includes `:focus-within`. Always pair hover-reveal with a keyboard-accessible state.)

## 3. Global selectors

You can target global classes from inside a styled component:

```tsx
const Toolbar = styled.div`
  .btn + .btn { margin-left: 0; }   /* the design-system BEM class, unchanged by styled-components */
`;
```

Class names written literally are **not** hashed, so this is how styled components and the SCSS design system interact (the CSS Modules equivalent was `:global(.btn)` in 07.07).

## 4. Summary

- Nesting, `&`, pseudo-classes, combinators and media queries work like SCSS.
- `${OtherStyled}` in a template = that component's stable selector: parent-hover and "inside X" patterns.
- Literal class names are global, so they can reach the BEM design system.
