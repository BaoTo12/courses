# Lecture 09.15 · 🐞 Debug: the Input Loses Focus on Every Keystroke

> **Section:** S09 · **Type:** 🐞 Debug · **Track:** ★ Core · **Time:** ~15 minutes

---

## Symptom

A "quick add" field for new task titles:

```tsx
export function QuickAdd({ onAdd }: { onAdd: (title: string) => void }) {
  const [value, setValue] = useState('');

  const Input = styled.input`
    width: 100%;
    padding: 8px 12px;
    border: 1px solid var(--color-border);
    border-radius: 6px;
  `;

  return (
    <Input
      placeholder="Quick add…"
      value={value}
      onChange={(e) => setValue(e.target.value)}
      onKeyDown={(e) => { if (e.key === 'Enter') { onAdd(value); setValue(''); } }}
    />
  );
}
```

Users report: "I type one letter and the field stops accepting input. I have to click it again for every letter."

## Investigation checklist

1. Open the console: is there a styled-components warning?
2. In Elements, watch the `<input>` while typing: does the **same node** stay, or is it replaced (the node flashes)?
3. What does React's reconciliation do when the component **type** at a position changes between renders? (07.04)
4. How many times is `styled.input` called while typing "abc"?

## Explanation

- `const Input = styled.input…` runs on **every render** of `QuickAdd`, creating a **new component type** each time.
- Typing calls `setValue` → re-render → a new `Input` type → React sees a *different type* at the same position → **unmounts** the old input and **mounts** a new one.
- The new DOM input isn't focused. Focus falls back to `<body>`.

Measured in TaskFlow's reference app after one simulated keystroke: `sameElement: false`, `activeTag: "BODY"`, and the console warned: *"The component styled.input with the id of "sc-furwPO" has been created dynamically… only create new StyledComponents outside of any render method and function component."* A new `sc-…` ID appeared for every render.

**Fix:** move the definition to module level:

```tsx
const Input = styled.input`
  width: 100%;
  padding: 8px 12px;
  border: 1px solid var(--color-border);
  border-radius: 6px;
`;

export function QuickAdd({ onAdd }: { onAdd: (title: string) => void }) {
  const [value, setValue] = useState('');
  return <Input … />;
}
```

## The general rule (not just styled-components)

**Never create component types during render.** The same bug happens with:

```tsx
function List() {
  const Row = ({ t }: { t: Task }) => <li>{t.title}</li>;   // ❌ new type every render
  return <ul>{tasks.map((t) => <Row key={t.id} t={t} />)}</ul>;
}
```

Define components at module level; pass data through props.
