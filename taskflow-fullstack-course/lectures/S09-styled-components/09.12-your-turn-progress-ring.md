# Lecture 09.12 · 🎯 Your Turn: a `ProgressRing` for "% of Tasks Done"

> **Section:** S09 · **Type:** 🎯 Your Turn · **Track:** ★ Core · **Time:** ~60 minutes

---

## 1. The task

Build `src/components/styled/ProgressRing.tsx`: a circular progress indicator showing the percentage of tasks that are `DONE`, displayed above the task views.

```text
   ╭───╮
  │ 25% │   tasks done
   ╰───╯
```

## 2. Requirements

1. Props: `done: number`, `total: number`. With `total === 0`, show `0%` (no division by zero).
2. An SVG ring: a grey background circle plus a coloured arc whose length represents the percentage.
3. **Threshold colours**: red below 34%, amber below 67%, green from 67%.
4. Animate the arc **drawing in** on first render (`keyframes`), and transition smoothly when the value changes. Respect `prefers-reduced-motion`.
5. Accessible: the ring has `role="img"` and an `aria-label` like `"25% of tasks done"`. The visible number is hidden from screen readers (it would be read twice).
6. Only **transient props** on styled components; nothing defined inside the component function.
7. The file exports **only** the `ProgressRing` component.
8. Use it in `App` (only when tasks have loaded) next to the text "tasks done", laid out with your `Stack`.

## 3. The SVG math you need

A circle with radius `r` has circumference `C = 2πr`. Draw the arc with a **dash** as long as the circle, then shift it with an **offset**:

```text
stroke-dasharray:  C                    (one dash exactly the circle's length)
stroke-dashoffset: C × (1 − percent/100) (0 = full circle, C = empty)
```

Rotate by −90° so the arc starts at 12 o'clock.

## 4. Hints

<details>
<summary>Hint 1: which parts are dynamic?</summary>

Only the arc's `stroke-dashoffset` and `stroke` colour change. The size, radius and dash length are **module constants**. Should the offset be an interpolation or a `style`? Consider 09.11: how often does the percentage change?
</details>

<details>
<summary>Hint 2: animating from empty</summary>

`` keyframes`from { stroke-dashoffset: ${CIRCUMFERENCE}; }` ``: with only a `from`, the animation ends at the element's current value.
</details>

<details>
<summary>Hint 3: the label</summary>

Wrap the SVG in a `figure` with `position: relative`, and put the percentage in an absolutely positioned `figcaption` with `aria-hidden="true"` (the `figure`'s `aria-label` already says it).
</details>
