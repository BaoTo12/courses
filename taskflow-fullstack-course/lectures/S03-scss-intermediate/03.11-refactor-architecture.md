# Lecture 03.11 · 🛠 Refactor the UI Kit into the 7-1 Architecture

> **Section:** S03 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~30 minutes
> **Project feature:** `abstracts/_index.scss`, `base/_typography.scss`, `utilities/_text.scss`; every component uses one `@use '../abstracts' as *;`

---

## 1. Target structure

```text
styles/
├── abstracts/
│   ├── _variables.scss     (exists)
│   ├── _tokens.scss        (exists: breakpoints, status/priority maps)
│   ├── _functions.scss     (exists: to-rem, space)
│   ├── _mixins.scss        (exists: respond-to, focus-ring, truncate)
│   └── _index.scss         ← NEW
├── base/
│   ├── _reset.scss         (exists)
│   └── _typography.scss    ← NEW (body/link styles moved out of main.scss)
├── layout/
│   ├── _page.scss
│   └── _kit.scss
├── components/
│   ├── _button.scss
│   ├── _badge.scss
│   ├── _card.scss
│   └── _form.scss
├── utilities/
│   └── _text.scss          ← NEW
└── main.scss               ← only @use lines, in cascade order
```

A refactor changes structure **without changing output**. Before starting, save the current compiled CSS so you can compare:

```bash
npm run styles:build
```

```bash
cp ui-kit/css/main.css /tmp/before.css
```

(On PowerShell: `Copy-Item ui-kit\css\main.css $env:TEMP\before.css`.)

---

## 2. ✍️ Step 1: the abstracts index

`styles/abstracts/_index.scss`:

```scss
// Public API of the design system's tools. Emits NO CSS.
@forward 'variables';
@forward 'tokens';
@forward 'functions';
@forward 'mixins';
```

Check the four abstracts files: none of them may contain CSS rules (only variables, maps, functions, mixins, and `@use` lines). Lecture 03.10 explains why.

## 3. ✍️ Step 2: one `@use` per component

In **every** file under `layout/`, `components/`, and the new `base/_typography.scss`, replace the separate abstracts imports:

```scss
// before
@use '../abstracts/variables' as *;
@use '../abstracts/mixins' as *;
@use '../abstracts/functions' as *;
@use '../abstracts/tokens' as *;
```

with:

```scss
// after
@use '../abstracts' as *;
```

Keep `@use 'sass:map';` in files that call `map.get` (badge, card). Built-in modules are loaded where they're used.

While you're in each file, replace `$space-N` with `space(N)` and hard-coded font sizes with `to-rem(…)`. For example in `_page.scss`:

```scss
&__header {
  display: flex;
  align-items: center;
  gap: space(6);
  padding: space(3) space(6);
  background: $color-surface;
  border-bottom: 1px solid $color-border;
}
```

(Colours stay as `$color-*` Sass variables for now; 03.13 converts them to runtime theme tokens.)

## 4. ✍️ Step 3: move global element styles into `base/_typography.scss`

```scss
@use '../abstracts' as *;

body {
  font-family: $font-family-base;
  font-size: to-rem(16px);
  color: $color-text;
  background: $color-background;
}

a {
  color: $color-primary;
}
```

## 5. ✍️ Step 4: utilities

`styles/utilities/_text.scss`:

```scss
@use '../abstracts' as *;

.text-muted {
  color: $color-text-muted;
}

.text-danger {
  color: $color-danger;
}

// Hide visually but keep available to screen readers
.visually-hidden {
  position: absolute !important;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}
```

`.visually-hidden` is one of the few legitimate `!important`s: a utility whose whole purpose is to win. You'll use it for accessible labels (e.g. an icon-only button's text) in React and JSP.

## 6. ✍️ Step 5: `main.scss` is now just a manifest

```scss
// TaskFlow design system: entry point.
// Order = cascade order (generic → specific). Utilities last.
@use 'base/reset';
@use 'base/typography';

@use 'layout/page';
@use 'layout/kit';

@use 'components/button';
@use 'components/badge';
@use 'components/card';
@use 'components/form';

@use 'utilities/text';
```

`main.scss` contains **no rules and no tokens**. Anyone can read it and understand the whole stylesheet's structure and cascade order in five seconds.

## 7. Verify: same output

```bash
npm run styles:build
```

```bash
git diff --no-index /tmp/before.css ui-kit/css/main.css
```

Expected differences: only the ones you intentionally made (e.g. `font-size: 0.875rem` vs `14px`-derived values, the new utility classes, and rule order where you moved body styles). If you see a missing rule, one file probably lost an `@use`. Search the compiled CSS for `space(` or `to-rem(`: if they appear, a function wasn't loaded (03.03's silent-failure trap).

## 8. Commit

```bash
git add styles
```

```bash
git commit -m "refactor(styles): 7-1 architecture with abstracts index"
```

## 9. Summary

- `abstracts/_index.scss` `@forward`s the tools; components need one `@use '../abstracts' as *;`.
- Global element styles live in `base/`; helpers in `utilities/` (loaded last).
- `main.scss` is a manifest in cascade order.
- A refactor is verified by **comparing compiled output**.
