## Not covered in this course (know they exist)

| API | What it's for |
|---|---|
| `combineSlices`, `slice.injectInto`, `reducerPath` | Lazy-loading slices with code splitting |
| `createDynamicMiddleware` | Adding middleware after the store is created |
| `buildCreateSlice`, `asyncThunkCreator` | Defining thunks **inside** `createSlice` via `reducers: (create) => ({ … })` |
| `autoBatchEnhancer`, `prepareAutoBatched` | Batching low-priority notifications (used by RTK Query) |
| `createDraftSafeSelector` | A selector safe to call on Immer drafts inside reducers |
