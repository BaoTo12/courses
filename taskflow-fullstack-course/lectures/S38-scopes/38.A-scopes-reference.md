# 38.A · 📇 Scopes: Reference (S38)

> One page to look things up.

---

## 1. The four scopes

| Scope | Object | Lifetime | Visible to | Thread safety | EL |
|---|---|---|---|---|---|
| page | `PageContext` | one JSP render | that JSP | n/a | `pageScope` |
| request | `HttpServletRequest` | one request (+ forwards/includes) | that request | n/a | `requestScope` |
| session | `HttpSession` | until `invalidate()` / timeout | one browser | needed (parallel requests) | `sessionScope` (⚠ 34.25) |
| application | `ServletContext` | the deployment | everyone | **essential** | `applicationScope` |

## 2. Listeners (38.07)

| Interface | Events |
|---|---|
| `ServletContextListener` | `contextInitialized`, `contextDestroyed` (36.04) |
| `ServletRequestListener` | `requestInitialized`, `requestDestroyed` |
| `HttpSessionListener` | `sessionCreated`, `sessionDestroyed` |

Registered with `@WebListener` or `<listener>` in `web.xml`.

## 3. Thread-safe building blocks

| Need | Use |
|---|---|
| hot counter | `LongAdder` |
| counter up and down | `AtomicInteger` / `AtomicLong` |
| map updated by many threads | `ConcurrentHashMap` + `computeIfAbsent` / `merge` |
| read-mostly shared data | immutable snapshot in a `volatile` field, swapped on change |
| per-user list in the session | copy, change, `setAttribute` the new list |
