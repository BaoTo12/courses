# Lecture 38.05 · Page Scope: Inside One JSP Only

> **Section:** S38 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~10 minutes

---

- **The object:** the `PageContext` of one JSP invocation (33.12). It's created when the JSP starts and discarded when it ends.
- **Who uses it:** JSTL's `var` attributes default to page scope: `<c:forEach var="task">`, `<c:set var="ctx" …/>`, `<c:url var="statusUrl" …>` (35.07, 35.10, 35.11).
- **Not shared with includes:** a `<jsp:include>`d page is a separate servlet with its **own** `PageContext`. A page-scoped `<c:set>` isn't visible there; use request scope (`scope="request"`) or, better, `<jsp:param>` / tag attributes (S39). A static `<%@ include %>` is the same page, so it does see it.
- **Shadowing:** page is searched first (34.03), so a `<c:set var="tasks">` hides the controller's request attribute `tasks` for the rest of the page. Pick loop variable names that don't collide (`task`, not `tasks`).
- **When to use it:** short-lived presentation helpers inside one view. Never data the controller should provide.
