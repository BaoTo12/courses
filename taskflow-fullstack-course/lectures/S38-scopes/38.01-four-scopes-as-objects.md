# Lecture 38.01 · The Four Scopes as Objects: Lifetime, Visibility, Threads

> **Section:** S38 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~25 minutes

---

## 1. A scope is just an object with a map of attributes

| Scope | Object | Created | Destroyed | Visible to | Threads touching it at once |
|---|---|---|---|---|---|
| **page** | `PageContext` | when a JSP starts rendering | when that JSP finishes | that one JSP (not even its `<jsp:include>`s) | one |
| **request** | `HttpServletRequest` | when a request arrives | when its response is done | everything that handles this request: filters, servlet, forwards, includes | usually one |
| **session** | `HttpSession` | on the first `request.getSession()` | `invalidate()`, or 30 min idle (`web.xml`) | every request from **this browser** (the `JSESSIONID` cookie) | **several** (tabs, parallel requests) |
| **application** | `ServletContext` | at deployment | at undeploy | **every** request of **every** user | **many** |

All four have the same API: `setAttribute(name, value)`, `getAttribute(name)`, `removeAttribute(name)`. EL searches them narrowest first (34.03).

## 2. Choosing: two questions

```text
Who must see it?     this page only → page
                     this request (incl. forwards) → request
                     this user, on later requests → session
                     everyone → application
How long?            match the lifetime to the need, no longer
```

Everything else follows from the table: the wider the scope, the more it costs (memory, staleness) and the more it must be thread-safe.

## 3. The costs grow with the scope

| | request | session | application |
|---|---|---|---|
| memory | freed after the response | × active users, for 30 min after their last click | once |
| staleness | none: loaded now | as old as the session | as old as the app, unless refreshed |
| thread safety | not an issue | needed (a user's parallel requests) | **essential** |
| leaks between users | impossible | if the browser is shared | **everything in it is public** |

## ✅ Recap

Four objects, one attribute API, four lifetimes. Pick the narrowest scope that does the job. TaskFlow's choices are in `docs/scopes.md` (38.11).
