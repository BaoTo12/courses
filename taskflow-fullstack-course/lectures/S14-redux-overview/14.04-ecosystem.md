| Package | What it is | In this course |
|---|---|---|
| **`redux`** | The core: a tiny store plus composition helpers. No React, no async, no immutability help. | S14–S19 (by hand first) |
| **`@reduxjs/toolkit`** | The **official, recommended** way to write Redux. Wraps the core, adds `createSlice` (with **Immer**, so "mutating" code is safe), thunks by default, good defaults, and dev-time checks for mutation and non-serialisable values. | S20–S21 |
| **RTK Query** | Part of RTK: a data-fetching and caching layer built on Redux. Replaces most hand-written "fetch → loading → success/failure" logic. | S22–S23 |
| **`react-redux`** | The official React bindings: `Provider` makes the store available; `useSelector`/`useDispatch` read and write it. | S17 onward |
| **`reselect`** | Memoised selectors (`createSelector`). RTK re-exports it. | S21 |
| **Redux DevTools** | A browser extension (Chrome, Firefox, Edge) plus an in-page protocol. | 14.11, 16.11 |
| **`redux-thunk`** | The thunk middleware (async logic). Included in RTK's default middleware. | S18 (you'll write it yourself first) |

## 2. "createStore is deprecated": what that means

Open `redux`'s type definitions (verified in 5.0.1) and you'll find `createStore` marked `@deprecated`, recommending RTK's `configureStore` instead. In VS Code, it's shown ~~struck through~~.

It is **not** removed and **not** broken: it works, logs nothing at runtime (verified), and will keep working. The deprecation is a **nudge** towards RTK for application code. Redux also exports **`legacy_createStore`**: the same function, without the strikethrough. We use `createStore` in S14–S19 precisely *because* we're learning the internals the official Fundamentals tutorial teaches, and we switch to `configureStore` in S20.

## 3. Summary

- `redux` = core; RTK = the recommended way to use it; RTK Query = data fetching on top; `react-redux` = React bindings; DevTools = the time-travel inspector.
- `createStore` is deprecated as a nudge, not a removal. We use it deliberately to learn how Redux works.
