## 2. The proxy (`frontend/vite.config.ts`)

`/api/*` → `<backend>/taskflow/api/*`; `cookiePathRewrite { '/taskflow': '/' }`.

## 3. Cookies and headers

| Name | Kind | Set by | Read by |
|---|---|---|---|
| `JSESSIONID` | cookie, HttpOnly | Tomcat | the server only |
| `XSRF-TOKEN` | cookie, readable, `Path=/` | `/api/auth/csrf`, login | Axios interceptor → `X-XSRF-TOKEN` |
| `tf_lang` | cookie, readable, `Path=/` | i18next / `LanguageServlet` | i18next / `LocaleFilter` |
| `tf_theme` | cookie, readable, `Path=/` | React / `ThemeServlet` | React / `header.jspf` |
| `X-Request-Id` | header, both ways | Axios (a UUID) → adopted by `RequestLoggingFilter` | logs, the 500 page, DevTools |

## 4. Lab tool

`/taskflow/debug/stats` → **Contract drift ON/OFF** (📦 `ContractDriftFilter`, loopback, needs a logged-in portal session): dates, enum casing, `total`, error shape, 204 → 200, string ids.
