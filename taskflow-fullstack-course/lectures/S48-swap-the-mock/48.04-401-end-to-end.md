# Lecture 48.04 · 🛠 401 → `auth/sessionExpired` → Cache Reset → Login, End to End

> **Section:** S48 · **Type:** 🛠 Lab · **Track:** ★ Core · **Time:** ~20 minutes
> Verified by a real run: alice logged in to the React app; an admin disabled her in the Admin Portal (42.07); her next click produced the sequence below

---

## 1. The experiment

1. Log in to TaskFlow Web as alice.
2. In another browser (or a private window), log in to the **Admin Portal** as admin and **Disable** alice (`/taskflow/admin/users`).
3. Back in alice's React tab, click **Reopen** on any task.

## 2. What happens

```text
GET   /api/tasks/21/comments                     → 401   AuthenticationFilter: the account is disabled → session invalidated,
PATCH /api/tasks/21                              → 401     ApiException.unauthenticated() → JSON (47.04)
GET   /api/tasks?size=100                        → 401
GET   /api/tasks?sort=dueDate,asc&page=0&size=20 → 401
→ the app is on /login?returnTo=%2Ftasks with the toast "Your session has expired. Please log in again."
```

Inside the React app (all built in S23–S24):

| Step | Code |
|---|---|
| a request fails with 401 | `axiosBaseQuery` (`src/api/axiosBaseQuery.ts`): `if (payload.status === 401 && !SESSION_ENDPOINTS.has(endpoint)) dispatch(sessionExpired())` |
| the listener reacts | `authListeners.ts`: `clearUserData` (auth state, RTK Query cache via `resetApiState()`, per-user UI state) + the toast |
| the route guard | `RequireAuth` sees no user → `/login?returnTo=/tasks` |
| the optimistic "Reopen" | rolled back with the cache reset (23.05) |

Observed as well: a second toast, "Aborted", from the refetches the cache reset cancelled. The app treats a cancelled request as an error worth showing; filtering `kind: 'cancelled'` out of the toast listener would hide it. That's the kind of polish item integration testing uncovers.

## 3. Why it works across two UIs

The Admin Portal and the API share **one** session model: `AccountRegistry` is checked on **every** request by the same `AuthenticationFilter`, whichever client sent it. Re-enable alice afterwards (**Enable** on the same page).

## ✅ Checkpoint

Your React tab lands on the login page with the expiry toast; after re-enabling and logging in, `returnTo` brings you back to `/tasks`.
