**The click:** alice clicks **Reopen** on task 12 in TaskFlow Web.

| # | Layer | What happens | Built in |
|---|---|---|---|
| 1 | React component | `TaskCard`'s `onToggle` → the `patchTask({ id: 12, changes: { status: 'TODO' } })` mutation (RTK Query) | 17, 22 |
| 2 | RTK Query | `onQueryStarted` patches the cached list **optimistically** (the card flips at once); the request starts | 23.05 |
| 3 | `axiosBaseQuery` | turns `{ url: '/tasks/12', method: 'PATCH', data }` into an Axios call | 22.03 |
| 4 | Axios request interceptors | `X-Request-Id: b0b2e7bd-…` (a new UUID); `X-XSRF-TOKEN` copied from the `XSRF-TOKEN` cookie | 13.12, 24.11 |
| 5 | Browser | `PATCH http://localhost:5173/api/tasks/12`, `Cookie: JSESSIONID=…; XSRF-TOKEN=…; tf_lang=en` (same origin: no preflight) | |
| 6 | Vite proxy | → `http://localhost:8080/taskflow/api/tasks/12` | 48.02 |
| 7 | Tomcat | Connector → a worker thread → the filter chain for `/api/tasks/*` | 45.01 |
| 8 | `CharacterEncodingFilter` | UTF-8 before anything reads the body | 40.05 |
| 9 | `RequestLoggingFilter` | adopts `b0b2e7bd-…` as the request id (MDC, `X-Request-Id`, request attribute) | 40.06, 48.08 |
| 10 | `ErrorHandlingFilter` · `LocaleFilter` | (pages' error mapping) · the language: `tf_lang=en` | 43.08, 44.07 |
| 11 | `CorsFilter` | same origin: nothing to do (`Vary: Origin`) | 47.10 |
| 12 | `ApiExceptionFilter` | body is `application/json` ✅; wraps the rest in the JSON error mapping | 46.08 |
| 13 | `SecurityHeadersFilter` · `MaintenanceModeFilter` | CSP, `nosniff`, … · not in maintenance | 40.10, 40.15 |
| 14 | `CsrfDoubleSubmitFilter` | cookie == header ✅ | 47.06 |
| 15 | `AuthenticationFilter` | session → `AuthUser` alice; `AccountRegistry`: enabled, role USER ✅ | 41.09, 42.07 |
| 16 | `AuthorizationFilter` · `CsrfFilter` | not `/admin` · skips `/api` | 42.03, 46.07 |

| 25 | React | the card re-renders from the fresh cache | |

## If something fails

| Where | You'd see |
|---|---|
| 14 | 403 `CSRF_TOKEN_INVALID` → the optimistic patch is **undone**, an error toast (47.15) |
| 15 | 401 → `sessionExpired` → login page (48.04) |
| 19 | someone else's task → 404 (42.05) |
| 20 | a duplicate title → 400 `fieldErrors.title` (46.07) |
| anywhere, a bug | 500 `INTERNAL_ERROR`; the **same** request id in the Network tab and in the server log's stack trace |
