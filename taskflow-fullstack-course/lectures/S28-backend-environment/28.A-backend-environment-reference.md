# 28.A · 📇 Backend Environment Reference (S28)

---

## 1. Versions

| | Version | Namespace / notes |
|---|---|---|
| JDK | 17 (21 works; `maven.compiler.release=17`) | |
| Tomcat | 9.0.x | Servlet 4.0 · JSP 2.3 · EL 3.0 · `javax.*` |
| MySQL | 8.4 (8.x) | utf8mb4 / `utf8mb4_0900_ai_ci` |
| Maven | 3.9.x | |

## 2. Commands

| Task | Command |
|---|---|
| Build the WAR (+ tests) | `mvn package` → `target/taskflow.war` |
| Dependency conflicts | `mvn dependency:tree` (look for "omitted for conflict") |
| Styles for JSP | `npm run styles:jsp` (in `taskflow/`) |
| Start MySQL + Tomcat (Docker) | `docker compose up -d` · `logs -f tomcat` · `down` · `down -v` (wipe the DB) |
| Tomcat (native) | `bin/startup` · `bin/shutdown` · debug: `catalina jpda run` (port 8000) |
| MySQL as the app | `mysql -h 127.0.0.1 -u taskflow_app -ptaskflow_dev_pw taskflow` |

## 3. URLs and credentials (development only)

| What | Value |
|---|---|
| TaskFlow Admin | `http://localhost:8080/taskflow/` |
| MySQL | `localhost:3306`, database `taskflow` |
| App DB user | `taskflow_app` / `taskflow_dev_pw` (data rights only) |
| MySQL root (Docker) | `root` / `root_dev_only` |
| Demo users | `alice`/`alice123` · `bob`/`bob123` · `admin`/`admin123` (bcrypt in DB) |

## 4. Maven scopes

`compile` (bundled) · `provided` (the container has it: the servlet and JSP APIs) · `runtime` · `test`.

## 5. WAR layout

Root = public · `WEB-INF/web.xml` · `WEB-INF/classes` · `WEB-INF/lib` = private (404 for browsers). Context path = WAR file name (`ROOT.war` → `/`).

## 6. Tomcat directories

`bin` (scripts) · `conf` (`server.xml`, default `web.xml`, `context.xml`) · `lib` (shared jars, the servlet API) · `webapps` (apps) · `work` (compiled JSPs) · `logs` (`catalina`, `localhost` = app exceptions, access log).

## 7. Schema summary

`users` (bcrypt `password_hash`, role, locale, enabled) · `categories` · `tasks` (ENUM status/priority, `UNIQUE(owner_id, title)` with ci collation, FKs cascade / set null) · `comments` (body as typed) · `audit_events` (append-only for the app).
