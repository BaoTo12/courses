# Lecture 28.09 · 🐞 Debug: `ClassNotFoundException: jakarta.servlet.http.HttpServlet` on Tomcat 9

> **Section:** S28 · **Type:** 🐞 Debug · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. The report

> "I followed a tutorial for my first servlet. `mvn package` works, but Tomcat won't start the app. `localhost.<date>.log` shows:"

```text
SEVERE [main] org.apache.catalina.core.StandardContext.startInternal Error during ServletContainerInitializer processing
java.lang.NoClassDefFoundError: jakarta/servlet/http/HttpServlet
  …
Caused by: java.lang.ClassNotFoundException: jakarta.servlet.http.HttpServlet
```

## 2. Investigate

1. **The class name** starts with `jakarta.`. Tomcat 9 only has `javax.servlet.*` in `lib/servlet-api.jar` (28.02).
2. **The code:** `import jakarta.servlet.http.HttpServlet;`. The tutorial targeted Tomcat 10+.
3. **The pom:** `jakarta.servlet:jakarta.servlet-api:6.0.0` with `provided`. It compiles, because Maven has the jar, but the container doesn't.

The build succeeding means nothing about the **runtime** container: `provided` means "trust the container to have this", and it doesn't.

## 3. Fix

Align everything to Tomcat 9:

```xml
<dependency>
  <groupId>javax.servlet</groupId>
  <artifactId>javax.servlet-api</artifactId>
  <version>4.0.1</version>
  <scope>provided</scope>
</dependency>
```

```java
import javax.servlet.http.HttpServlet;   // every import: javax.servlet.*, javax.servlet.http.*, javax.servlet.annotation.*
```

Then `mvn clean package` and redeploy. (Or the opposite: move the whole project to Tomcat 10.1+ and `jakarta` everywhere, 28.02 §4.)

## 4. The mirror-image bug

`javax` code deployed on **Tomcat 10+** doesn't crash. Tomcat simply doesn't recognise your class as a servlet (it isn't a `jakarta.servlet.Servlet`), so every mapped URL answers **404**, with no error at all. Check the Tomcat version first when "everything is 404" (28.10).

## ✅ Takeaway

`jakarta.*` in an error on Tomcat 9 = a namespace mismatch. Check the imports, the `-api` dependency and **every library** (JSTL!) for the same namespace as the container.
