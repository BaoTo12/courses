# Lecture 44.16 · 🎯 Your Turn: Sort Links That Toggle asc/desc and Keep All Other Parameters

## Requirements

1. The **Title**, **Priority** and **Due** column headers of the task list are links that sort by that column.
2. Clicking the column the list is already sorted by (ascending) sorts it **descending** (`&dir=desc`); clicking it again goes back to ascending. Another column always starts ascending.
3. The active column shows ▲ (ascending) or ▼ (descending).
4. The links keep the search, the status and the category; they **drop** the page number.
5. The sort **direction** is as safe as the sort column (36.09): no request value reaches the query text.

**Tests:** `/tasks?sort=title` has a Title header link `href="/taskflow/tasks?sort=title&amp;dir=desc"` with text `Title ▲`, and a Due header `href="/taskflow/tasks?sort=due"`; with `&dir=desc`, the link drops `dir`, shows ▼, and "Write quarterly report" comes before "Update the style guide".

## Hints

- 📦 `TaskSort` now has an ascending and a descending fragment per constant (`orderBy(boolean desc)`); `TaskFilter` has a `descending` component.
- Parse `dir` like `sort`: anything other than exactly `desc` means ascending.
- A tag file with attributes `column`, `current`, `descending`, `keep`, and the label as its body.
- `pageLink.tag` (44.04) shows how to keep a list of parameters.
