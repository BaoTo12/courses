# Lecture 44.10 · Tag Files: Attributes, `<jsp:doBody>`, Fragments

> **Section:** S44 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~25 minutes

---

A **tag file** is a JSP-syntax file in `WEB-INF/tags/` that becomes a custom tag. No Java, no TLD: the container translates it into a tag handler class, as it translates JSPs into servlets.

```jsp
<%@ taglib prefix="t" tagdir="/WEB-INF/tags" %>        <%-- every .tag file in that folder: <t:layout>, <t:statusBadge> … --%>
<t:statusBadge status="${task.status}"/>
```

## 📇 API card: tag file directives and actions

| Piece | Meaning |
|---|---|
| `<%@ tag description="…" pageEncoding="UTF-8" body-content="scriptless\|empty\|tagdependent" trimDirectiveWhitespaces="true" %>` | the tag's settings (like `<%@ page %>`) |
| `<%@ attribute name="x" required="true" type="fully.qualified.Type" rtexprvalue="true" %>` | a declared attribute → a page-scope variable `${x}` inside the tag; default type `String` |
| `<%@ attribute name="x" fragment="true" %>` | a **fragment** attribute: markup passed in `<jsp:attribute name="x">…</jsp:attribute>`, rendered with `<jsp:invoke fragment="x"/>` |
| `<%@ variable name-given="y" scope="NESTED\|AT_BEGIN\|AT_END" %>` | a variable the tag exposes **back** to the caller's body |
| `<jsp:doBody/>` (`var=`, `scope=`) | render the caller's body here (or capture it) |
| `<jsp:invoke fragment="x"/>` | render a fragment attribute here |

## Scopes inside a tag file

| Expression | Resolves |
|---|---|
| `${title}` (an attribute) | the tag's **own** page scope |
| `${pageTitle}` set with `<c:set>` in the tag | the tag's page scope: invisible to the caller |
| `${tasks}`, `${currentUser}` | request scope: shared with the calling page |
| `${param.q}`, `${cookie…}` | implicit objects work as in a JSP |
| the body (`<jsp:doBody/>`) | evaluated in the **caller's** context: `${task}` in the body is the caller's loop variable |

That last row is what makes `<t:layout>` work: the page's own content, with the page's variables, rendered inside the layout.

## Tag file vs the alternatives

| | `<%@ include %>` (39.02) | `<jsp:include>` (39.03) | tag file |
|---|---|---|---|
| parameters | none (shares all variables) | `<jsp:param>` strings | **typed**, declared, `required` checked at translation |
| body content | no | no | yes (`<jsp:doBody/>`), plus fragments |
| scope | the including page's | its own request dispatch | its own page scope |
| cost | none (pasted) | a dispatch per use | a method call |

## ✅ Recap

Tag files are JSP fragments with a declared interface: typed attributes, a body, and their own scope. Use them for layouts and small UI components.
