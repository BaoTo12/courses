# Lecture 44.12 · Custom Tag Handlers: `SimpleTagSupport` + a TLD

> **Section:** S44 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~15 minutes

*Extended track: outline.*

---

- **When a tag file isn't enough:** the tag needs Java logic (date arithmetic, formatting with `java.time`, calling a library), not markup. Tag files can't contain scriptlets under TaskFlow's `scripting-invalid` (36), and shouldn't anyway.
- **📇 API card: `javax.servlet.jsp.tagext.SimpleTagSupport`** (JSP 2.0+)
  | Member | Meaning |
  |---|---|
  | `doTag()` | called once per use; write with `getJspContext().getOut().write(…)` |
  | setters `setX(T x)` | one per attribute; the container calls them before `doTag` (a new instance per use: fields are safe) |
  | `getJspBody()` → `JspFragment` | the body; `getJspBody().invoke(null)` renders it (into the output) or `invoke(writer)` (to capture) |
  | `getJspContext()` | cast to `PageContext` for the request, `Config.find`, `LocaleSupport` |
  | `getParent()`, `findAncestorWithClass(this, C.class)` | cooperating tags (like `<c:param>` inside `<c:url>`) |
  | `throw new SkipPageException()` | stop rendering the rest of the page |
- **The TLD** (`WEB-INF/**/*.tld`, or `META-INF/*.tld` inside a jar): `<uri>` (the name pages import), `<tag>` → `<name>`, `<tag-class>`, `<body-content>` (`empty`, `scriptless`, `tagdependent`), `<attribute>` → `<name>`, `<required>`, `<rtexprvalue>`, `<type>`; `<function>` for EL functions (44.14).
- **Classic tags** (`TagSupport`, `BodyTagSupport`: `doStartTag`/`doEndTag` return codes, pooled instances whose fields must be reset): JSTL itself is written that way; new code uses `SimpleTagSupport`.
- **Escaping:** a tag handler writes raw output. Anything user-controlled must be escaped in the handler (TaskFlow's tags only write JDK-formatted dates and bundle texts).
- TaskFlow's handlers: `DateTag`, `RelativeTimeTag` (44.13), in `taskflow.tld` with `uri="urn:taskflow:tags"`.
