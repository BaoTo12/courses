## 1. `fmt` tags

| Tag | Use |
|---|---|
| `<fmt:message key var bundle>` + `<fmt:param value>` | bundle text; params **not escaped** |
| `<fmt:setLocale value scope>` / `<fmt:setBundle basename var scope>` / `<fmt:bundle basename>` | locale / bundle for a scope or body |
| `<fmt:formatNumber value type pattern …>` / `<fmt:parseNumber>` | numbers in the locale |
| `<fmt:formatDate value type dateStyle timeStyle pattern timeZone>` / `<fmt:parseDate>` | **`java.util.Date` only** |
| `<fmt:timeZone>` / `<fmt:setTimeZone>` | time zone for dates |
| `<fmt:requestEncoding>` | request body encoding |
| context params `javax.servlet.jsp.jstl.fmt.localizationContext`, `…fallbackLocale` | default bundle, fallback locale |
| `Config.set(request, Config.FMT_LOCALE, locale)` / `Config.find(pageContext, name)` | from Java |
| `LocaleSupport.getLocalizedMessage(pageContext, key[, args])` | `fmt:message` from Java |

## 2. Tag files (`WEB-INF/tags/*.tag`, `<%@ taglib prefix="t" tagdir="/WEB-INF/tags" %>`)

`<%@ tag %>`, `<%@ attribute name required type fragment %>`, `<%@ variable %>`, `<jsp:doBody/>`, `<jsp:invoke fragment/>`. Own page scope; the body runs in the caller's context.

## 3. Tag handlers and functions (`WEB-INF/tlds/taskflow.tld`, `uri="urn:taskflow:tags"`)

`SimpleTagSupport.doTag()`, setters per attribute, `getJspBody().invoke(…)`; TLD `<tag>`, `<attribute>`, `<function>`.

## 4. TaskFlow pieces

| Piece | Job |
|---|---|
| `LocaleFilter` (after `errors`) | `tf_lang` (en/vi) → `Accept-Language` (if sent) → en; `Config.FMT_LOCALE`; `lang` attribute |
| `LanguageServlet` `POST /preferences/language` | `tf_lang` cookie, `Path=/`, 1 year, not HttpOnly; 303 to safe `returnTo`; else 400 |
| `i18n/messages.properties`, `messages_vi.properties` | nav, list, rows, statuses, priorities, sorts, pagination, dashboard, due labels |
| `Page<T>` + `TaskService.page(filter, n, caller)`, `PAGE_SIZE = 10` | one page; number clamped; `offset` for row numbers |
| 📦 `TaskDao.find(filter, offset, limit)`, `count(filter)`; `TaskSort.orderBy(desc)`; `TaskFilter.descending` | paged, directed queries |
| `t:layout title` | header + body + footer |
| `t:statusBadge status` | translated badge |
| `t:pagination of path keep` + `t:pageLink path keep number current` | Previous · 1 2 3 · Next, "Page 1 of 3 · 22 tasks" |
| `t:sortHeader column current descending keep` | ▲/▼ header links |
| `tf:date value`, `tf:relativeTime value today`, `tf:truncate(text, max)` | `java.time` dates, due labels, shortening |

## 5. URLs

`<c:url>` + `<c:param>` (URL-encodes) → `fn:escapeXml` (HTML-escapes). Keep an explicit list of parameters; drop `page` when the order or the filter changes.

## 6. The filter chain now

encoding → logging → errors → **locale** → security headers → maintenance → authentication → authorization → CSRF.
