## 1. `Set-Cookie` attributes (24.02)

| Attribute | Default | Meaning |
|---|---|---|
| `Expires=<date>` / `Max-Age=<s>` | none → session cookie | lifetime; `Max-Age` wins; `Max-Age=0` deletes |
| `Path=/p` | the request's directory | sent only under `/p`; part of the cookie's identity |
| `Domain=d` | host-only | also sent to subdomains of `d` |
| `Secure` | off | HTTPS only |
| `HttpOnly` | off | invisible to JavaScript (server-set only) |
| `SameSite=Strict\|Lax\|None` | treated as `Lax` | cross-site sending; `None` requires `Secure` |

## 2. js-cookie 3 (24.04)

| Call | Returns |
|---|---|
| `Cookies.get(name)` / `Cookies.get()` | `string \| undefined` / `Record<string, string>` |
| `Cookies.set(name, value, { expires?, path?, domain?, secure?, sameSite? })` | the cookie string |
| `Cookies.remove(name, { path?, domain? })` | — (**same path/domain as `set`**) |
| `Cookies.withAttributes(defaults)` | a configured instance |
| `Cookies.withConverter({ read?, write? })` | an instance with custom encoding |

`expires` is in **days** (or a `Date`). The default `path` is `'/'`. There's no `httpOnly`.
