# Lecture 40.13 · 🛠 Build: the S37 CSRF Check, Moved into a `CsrfFilter`

> **Section:** S40 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~25 minutes
> **Project feature:** every non-GET request needs the token, whether or not its servlet remembers.
> Verified: `S40FiltersTest.theCsrfFilterGuardsEveryNonGetRequest` (a POST to a GET-only servlet: 403 without a token, 405 with one), and S37's CSRF tests, unchanged

---

## 1. The filter

✍️ `src/main/java/com/taskflow/web/filters/CsrfFilter.java`

```java
package com.taskflow.web.filters;

import com.taskflow.web.Csrf;
import java.io.IOException;
import java.util.Set;
import javax.servlet.Filter;
import javax.servlet.FilterChain;
import javax.servlet.ServletException;
import javax.servlet.ServletRequest;
import javax.servlet.ServletResponse;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

/**
 * S40 (40.13): the S37 CSRF check (37.13), for EVERY state-changing request, in one place.
 * A servlet added tomorrow is protected without anyone remembering to add the three lines.
 * Runs after CharacterEncodingFilter: it reads the _csrf parameter, which fixes the request's encoding (40.19).
 */
public class CsrfFilter implements Filter {

  private static final Set<String> SAFE_METHODS = Set.of("GET", "HEAD", "OPTIONS", "TRACE");

  @Override
  public void doFilter(ServletRequest req, ServletResponse res, FilterChain chain) throws IOException, ServletException {
    HttpServletRequest request = (HttpServletRequest) req;
    if (!SAFE_METHODS.contains(request.getMethod()) && !Csrf.isValid(request)) {
      ((HttpServletResponse) res).sendError(HttpServletResponse.SC_FORBIDDEN, "Invalid or missing CSRF token");
      return;                                   // not calling chain.doFilter = the servlet never runs (40.04)
    }
    chain.doFilter(req, res);
  }
}
```

- **Safe methods** (`GET`, `HEAD`, `OPTIONS`, `TRACE`) don't change anything (29.03, 37.02), so they need no token. Everything else does, including `PUT`/`DELETE` from S46's JSON API (whose token arrives in a header, 24.10).
- `Csrf.prepare` stays in the GET **controllers** that render forms. Preparing a token in the filter for every GET would create a session for every visitor, bot and CSS request.

## 2. Delete the copies

Remove the three-line check from `TaskCreateServlet`, `TaskEditServlet`, `TaskToggleServlet`, `TaskDeleteServlet`, `TaskCommentServlet`, `CategorySaveServlet`, `CategoryDeleteServlet` and `ThemeServlet` (and the now unused `import com.taskflow.web.Csrf`).

## 3. A test that proves "every"

The test posts to `/tasks`, which has **no** `doPost`:
- without a token → **403**: the filter answered before the servlet was called;
- with a token → **405**: the filter let it through, and `HttpServlet` refused the method (30.07).

That's the property that matters: a POST handler added next year is protected on day one. S30's `/hello` test got a token for the same reason.
