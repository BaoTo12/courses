## 1. The filter

✍️ `src/main/java/com/taskflow/web/filters/CharacterEncodingFilter.java`

```java
package com.taskflow.web.filters;

import java.io.IOException;
import javax.servlet.Filter;
import javax.servlet.FilterChain;
import javax.servlet.FilterConfig;
import javax.servlet.ServletException;
import javax.servlet.ServletRequest;
import javax.servlet.ServletResponse;

/**
 * S40 (40.05): request bodies are read as UTF-8, for EVERY request, before anything reads a parameter.
 * Replaces the request.setCharacterEncoding("UTF-8") line S31–S39 repeated in each POST servlet.
 * Must be FIRST in the chain: once a parameter has been read, the encoding can no longer change (40.19).
 */
public class CharacterEncodingFilter implements Filter {

  private String encoding = "UTF-8";

  @Override
  public void init(FilterConfig config) {
    String configured = config.getInitParameter("encoding"); // web.xml <init-param>
    if (configured != null && !configured.isBlank()) encoding = configured;
  }

  @Override
  public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) throws IOException, ServletException {
    if (request.getCharacterEncoding() == null) {   // respect an explicit charset sent by the client
      request.setCharacterEncoding(encoding);
    }
    chain.doFilter(request, response);
  }
}
```

- It only sets the encoding **if the client didn't declare one** (`Content-Type: …; charset=…`). Browsers don't send a charset for form posts, so this almost always applies.
- It doesn't touch the **response** encoding: every JSP declares `contentType="text/html;charset=UTF-8"`.
- The encoding is an `<init-param>`, so it's configurable without recompiling.

## 2. Declaring it

✍️ in `WEB-INF/web.xml` (the full filter section is in 40.07):

```xml
<filter>
  <filter-name>encoding</filter-name>
  <filter-class>com.taskflow.web.filters.CharacterEncodingFilter</filter-class>
  <init-param><param-name>encoding</param-name><param-value>UTF-8</param-value></init-param>
</filter>
<filter-mapping><filter-name>encoding</filter-name><url-pattern>/*</url-pattern></filter-mapping>
```

## 3. Delete the copies

Remove `request.setCharacterEncoding("UTF-8");` from `TaskCreateServlet`, `TaskEditServlet`, `TaskCommentServlet` and `CategorySaveServlet`. The tests that post Vietnamese titles keep passing: the filter did it before the servlet ran.

**Why it must be the first filter:** 40.19.
