# 40.A · 📇 Filters: Reference (S40)

> One page to look things up.

---

## 1. API

| Type | Methods |
|---|---|
| `Filter` | `init(FilterConfig)` (default) · `doFilter(req, res, chain)` · `destroy()` (default) |
| `FilterConfig` | `getFilterName()` · `getInitParameter(name)` · `getServletContext()` |
| `FilterChain` | `doFilter(req, res)`: once, or not at all |
| `HttpFilter` (Servlet 4.0) | `doFilter(HttpServletRequest, HttpServletResponse, FilterChain)` |
| wrappers | `HttpServletRequestWrapper`, `HttpServletResponseWrapper` |

## 2. Declaring and ordering (40.07, 40.08)

`web.xml`: `<filter>` + `<filter-mapping>` (`<url-pattern>` or `<servlet-name>`, `<dispatcher>` REQUEST/FORWARD/INCLUDE/ERROR/ASYNC). Order = the order of the mappings. `@WebFilter` order is unspecified.

## 3. TaskFlow's chain (40.14)

| # | Filter | Dispatchers | Job |
