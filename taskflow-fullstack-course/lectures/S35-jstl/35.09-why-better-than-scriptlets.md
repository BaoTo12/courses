# Lecture 35.09 · Why This Is Better than Scriptlets

> **Section:** S35 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~15 minutes

---

Compare S33's `list.jsp` (33.08) with S35's (35.08), point by point:

| Property | Scriptlets (S33) | EL + JSTL (S35) |
|---|---|---|
| **Readability** | Java and HTML interleaved; `<% } %>` closes something 30 lines up | markup with well-formed tags; the structure is visible |
| **Null-safety** | `task.getCategory().getName()` → NPE → 500 | `${task.category.name}` → nothing; `<c:out default>` for a fallback |
| **Escaping** | opt-in (`Html.escape`), and silent when forgotten | `<c:out>` escapes by default |
| **Errors** | braces break far from the mistake (33.18); runtime casts | a tag mismatch is reported at the tag; no casts |
| **Separation** | anything is possible, so business logic creeps in (33.15) | EL can read and compare; it can't easily *do* things, so the logic stays in the controller |
| **Testability** | logic in the view can only be tested by rendering | logic lives in Java (`Task.isOverdue`, the controller), unit-testable; views are checked by rendering (`TomcatTest`) |
| **Tooling** | IDEs struggle with split Java blocks | IDEs complete tags and attributes from the TLD |
| **Who can edit** | Java developers | anyone who knows HTML + a small tag vocabulary |
| **Enforceable** | — | `<scripting-invalid>true</scripting-invalid>` (33.14, S36) makes Java in views a **build** error |

## What it costs

- Another vocabulary to learn (≈ 10 tags in daily use).
- Slightly more verbose for complex conditions. That's usually a hint that the controller should compute a value.
- Debugging goes through tag handler classes in the generated servlet (35.01), not your own code.

## When scriptlets are still found

Legacy pages (you **will** meet them at work), quick throwaway prototypes, and code generated by old tools. Refactor them the way 34.21 → 35.08 did: first move the decisions into the controller, then replace expressions with EL, then control flow with tags.

## ✅ Recap

Tags + EL are more readable, null-safe, escaped by default, and enforceable. The discipline they impose, views only display, is the real benefit.
