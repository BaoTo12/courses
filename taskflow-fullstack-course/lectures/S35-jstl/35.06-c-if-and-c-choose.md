## 📇 API card: `<c:if>`

```jsp
<c:if test="${overdueCount > 0}" [var="hasOverdue"] [scope="page|request|session|application"]>
  …rendered only when test is true…
</c:if>
```

| Attribute | Type | Required | Meaning |
|---|---|---|---|
| `test` | `boolean` | ✅ | the condition (EL, coerced to `Boolean`: `null` → `false`) |
| `var` | `String` | | also store the result as an attribute |
| `scope` | `String` | | where `var` goes (default `page`) |

**Why no `else`:** `<c:if>` is a single tag whose body is rendered or skipped (`IfTag.doStartTag()` returns `EVAL_BODY_INCLUDE` or `SKIP_BODY`, 35.01). An "else" would need a second tag that knows about the first, and that's `<c:choose>`.

## 📇 API card: `<c:choose>`

```jsp
<c:choose>
  <c:when test="${empty tasks}"> <p class="text-muted">No tasks.</p> </c:when>
  <c:when test="${…}"> … </c:when>                       <%-- as many as needed --%>
  <c:otherwise> <table>…</table> </c:otherwise>          <%-- optional, last --%>
</c:choose>
```

- The **first** `<c:when>` whose `test` is true is rendered, and the rest are skipped: an if / else-if / else chain.
- Only `<c:when>`, `<c:otherwise>` and whitespace are allowed directly inside `<c:choose>`. Text there is a translation error.
- `<c:otherwise>` must come last.

**When to use which:**

| Situation | Tag |
|---|---|
| show or skip one block | `<c:if>` |
| two alternatives (empty state vs table) | `<c:choose>` + `<c:when>` + `<c:otherwise>` |
| several cases (status labels) | `<c:choose>` with several `<c:when>` |
| choose a **value** (a class, a word) | an EL ternary (34.11). A `<c:choose>` in an attribute is unreadable |

**Common mistakes:**
- Two `<c:if>`s for if/else: `<c:if test="${empty x}">…</c:if><c:if test="${not empty x}">…</c:if>` works, but the conditions drift apart over time. Use `<c:choose>`.
- `test="${task.status == DONE}"`: `DONE` without quotes is an **identifier** → an attribute named `DONE` → `null` → never equal. Write `'DONE'` (the knowledge check).
- `test="task.done"` without `${}` → the **string** `"task.done"` → coerced to `false`.

## 1. In TaskFlow

```jsp
<c:if test="${overdueCount > 0}">
  <p class="text-danger">${overdueCount} overdue ${overdueCount == 1 ? 'task' : 'tasks'}</p>
</c:if>

<c:choose>
  <c:when test="${task.status == 'DONE'}"><span class="badge badge--done">Done</span></c:when>
  <c:when test="${task.status == 'IN_PROGRESS'}"><span class="badge badge--progress">In progress</span></c:when>
  <c:otherwise><span class="badge">To do</span></c:otherwise>
</c:choose>
```

Unlike S34's `hidden`, the empty-state paragraph and the table are **not sent** when they don't apply: `S35JstlTest` checks that an empty search has no `<table` at all.

## ✅ Recap

`<c:if>` renders or skips one body. `<c:choose>` renders the first matching `<c:when>`, else `<c:otherwise>`. Quote your string literals in `test`.
