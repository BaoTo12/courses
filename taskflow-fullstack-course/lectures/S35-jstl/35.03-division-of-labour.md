# Lecture 35.03 · Division of Labour: EL Reads Values, JSTL Controls Flow and Output

> **Section:** S35 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~10 minutes

---

## 1. Who does what

| Need | S33 (scriptlets) | EL | JSTL |
|---|---|---|---|
| read a value | `<%= ((Task) request.getAttribute("task")).getTitle() %>` | `${task.title}` | |
| print it **safely** | `<%= Html.escape(…) %>` | ❌ | `<c:out value="${task.title}"/>` |
| a condition | `<% if (…) { %> … <% } %>` | `${a ? b : c}` (values only) | `<c:if>`, `<c:choose>` |
| a loop | `<% for (…) { %> … <% } %>` | ❌ | `<c:forEach>` |
| a link | `<%= request.getContextPath() %>/tasks?q=<%= URLEncoder… %>` | `${pageContext.request.contextPath}/tasks` | `<c:url>` + `<c:param>` |
| a page variable | `<% String x = …; %>` | ❌ (EL 3.0 `=`: avoid, 34.17) | `<c:set>` |

Tag attributes **take** EL: `<c:forEach items="${tasks}" var="task">`. EL computes the value, and the tag decides what to do with it.

## 2. The mental model

```text
controller (Java)  → decides WHAT to show, puts it in attributes
JSTL tags          → decide HOW MUCH of the page to render (loops, choices), and HOW to print (escaping, URLs)
EL                 → READS the values the tags and the text need
```

S35 ends with `S35JstlTest.noViewContainsJavaAnymore`: no `<% %>` in any view or fragment. S36 makes the container **enforce** it (`<scripting-invalid>`, 33.14).

## ✅ Recap

EL answers "what's the value?" JSTL answers "render this, how many times, and how to print it". Together, they replace every kind of scriptlet.
