# Lecture 35.05 · 🛡 Defend: the S32/S34 Escaping, Done with `<c:out>` / `fn:escapeXml`

> **Section:** S35 · **Type:** 🛡 Defend · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S34ElTest` (titles escaped in `<title>`, `<h1>` and the list; the search `value`), `S31TaskServletsTest` (the malicious seed-style title)

---

## 1. What changes

| Where | S34 | S35 |
|---|---|---|
| `header.jspf` `<title>` | `${Html.escape(pageTitle)}` | `<c:out value="${pageTitle}"/>` |
| `view.jsp` title, description, names | `${Html.escape(details.task.title)}` | `<c:out value="${details.task.title}"/>` |
| `view.jsp` fallbacks | `${empty details.category ? 'No category' : Html.escape(…)}` | `<c:out value="${details.category.name}" default="No category"/>` |
| `list.jsp` search box (an attribute) | `value="${Html.escape(param.q)}"` | `value="${fn:escapeXml(param.q)}"` |
| `debug/el.jsp` | `${Html.escape(header['User-Agent'])}` | `${fn:escapeXml(header['User-Agent'])}` |
| every page | `<%@ page import="com.taskflow.web.Html" %>` | `<%@ taglib … %>` |

`Html` stays in the codebase for the one remaining `println` servlet (`TaskCreateServlet`, until S37 moves its form to a JSP).

## 2. Why switch, if `Html.escape` worked?

- **Standard:** every JSP developer knows `<c:out>`. A custom static call in EL is surprising (34.17).
- **Safe by default:** `<c:out>` escapes unless you opt out. With `${Html.escape(x)}`, forgetting the call is silent.
- **Reviewable:** a grep for `\${[^}]*}` outside `<c:out>`/`fn:escapeXml` finds every unescaped print. S51's security review does exactly that.

## 3. Check the result

The same attacks as before, now against the JSTL pages:

```text
/taskflow/tasks?q=%22%3E%3Cscript%3Ealert(1)%3C%2Fscript%3E
→ <input type="search" name="q" value="&#034;&gt;&lt;script&gt;alert(1)&lt;/script&gt;" …>
```

A task titled `<img src=x onerror=alert(1)>` → the list, the title bar and the details page all show the text.

## ✅ Takeaway

The fix didn't change **what** is escaped. It changed **who is responsible**: the tag library, by default, instead of every developer remembering a helper.
