## 1. Declarations (35.02)

```jsp
<%@ taglib prefix="c"  uri="http://java.sun.com/jsp/jstl/core" %>
<%@ taglib prefix="fn" uri="http://java.sun.com/jsp/jstl/functions" %>
```

Jar: `javax.servlet:jstl:1.2`, **compile** scope (Tomcat doesn't ship JSTL). JSTL 1.0 URI (`/jstl/core`) → "does not accept any expressions". Jakarta (Tomcat 10.1+) → `jakarta.tags.core`.

## 4. Output encoding by context (34.19, 35.15–35.17)

| Context | Use |
|---|---|
| HTML text | `<c:out value="${x}"/>` |
| quoted attribute | `attr="${fn:escapeXml(x)}"` (always quote) |
| URL parameter | `<c:url>` + `<c:param>`, then `fn:escapeXml` in `href` |
| JavaScript | none: `data-*` attributes + a static script; or `<script type="application/json">` with an HTML-safe JSON encoder |
| HTML you mean to render | an allow-list sanitiser (OWASP Java HTML Sanitizer), never `escapeXml="false"` on user input |
