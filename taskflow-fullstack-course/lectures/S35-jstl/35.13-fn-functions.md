# Lecture 35.13 · The `fn:` Functions Library

> **Section:** S35 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Verified: `S35JstlTest` (`${fn:length(details.comments)}` → `Comments (2)` / `Comments (0)`; `fn:escapeXml` in the search box, the delete form and the debug page)

---

```jsp
<%@ taglib prefix="fn" uri="http://java.sun.com/jsp/jstl/functions" %>
<h2>Comments (${fn:length(details.comments)})</h2>
```

These are **EL functions**: static Java methods declared in a TLD (`<function>` elements) and called **inside** `${…}`. They aren't tags.

## 📇 API card: `fn:` (JSTL 1.2)

| Function | Signature (EL) | Example → result |
|---|---|---|
| `fn:length` | `(Object) → int`: `Collection`, `Map`, array, `String`, iterator; **`null` → 0** | `${fn:length(tasks)}` → `4` |
| `fn:escapeXml` | `(String) → String` | `${fn:escapeXml('<b>')}` → `&lt;b&gt;` |
| `fn:contains` / `fn:containsIgnoreCase` | `(String, String) → boolean` | `${fn:containsIgnoreCase(task.title, 'report')}` |
| `fn:startsWith` / `fn:endsWith` | `(String, String) → boolean` | `${fn:endsWith(file, '.pdf')}` |
| `fn:indexOf` | `(String, String) → int` (−1) | |
| `fn:substring` | `(String, int begin, int end) → String` (out-of-range tolerated) | `${fn:substring(task.title, 0, 20)}` |
| `fn:substringBefore` / `fn:substringAfter` | `(String, String) → String` | `${fn:substringAfter(email, '@')}` |
| `fn:replace` | `(String, String, String) → String` | `${fn:replace(text, '-', ' ')}` |
| `fn:split` | `(String, String delims) → String[]` | `${fn:split('a,b', ',')}` |
| `fn:join` | `(String[], String) → String` (**arrays only**) | `${fn:join(tagsArray, ', ')}` |
| `fn:toLowerCase` / `fn:toUpperCase` / `fn:trim` | `(String) → String` | |

`null` string arguments are treated as `""`.

**When to use:** small **presentation** transformations: a count, truncating a long title, escaping inside an attribute.
**When not to:** anything that's really data preparation (filtering a list, building a label from several fields, business rules): do that in Java, where it can be tested.

**Common mistakes:**
- `${fn:join(task.tags, ', ')}` with a `List<String>` → an error: `fn:join` takes a `String[]`. Convert in the controller, or loop with `<c:forEach>` and `varStatus.last`.
- `${fn:substring(title, 0, 20)}…` always adding `…`, even for short titles → `${fn:length(title) > 20 ? fn:substring(title, 0, 20) += '…' : title}` is getting clever: give the view a `shortTitle`.
- Forgetting that `fn:substring` output still needs escaping: `<c:out value="${fn:substring(…)}"/>`.

## ✅ Recap

`fn:` gives EL string and collection helpers. `fn:length` (null-safe) and `fn:escapeXml` are the everyday two, and the rest are for small display tweaks.
