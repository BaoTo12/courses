# Lecture 09.07 · The `css` Helper, Shared Style Fragments, and `keyframes` Animations

> **Section:** S09 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. `css`: reusable fragments

`` css`…` `` creates a **style fragment**: a piece of CSS (with interpolations, nesting and `&`) that can be inserted into styled components. It's the styled-components equivalent of a Sass **mixin** (03.01).

```tsx
import styled, { css } from 'styled-components';

const truncate = css`
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
`;

const focusRing = css`
  &:focus-visible {
    outline: 2px solid var(--color-primary);
    outline-offset: 2px;
  }
`;

const Title = styled.h3`
  ${truncate}
`;

const Link = styled.a`
  ${focusRing}
`;
```

### Why not a plain string?

A plain template string (`` const truncate = `overflow: hidden;` ``) works only for static text. **Fragments with interpolation functions** must use `css`, otherwise the functions are converted to text instead of being called with props:

```tsx
const sized = css<{ $size: number }>`
  width: ${({ $size }) => $size}px;
`;
```

Rule: **always wrap reusable style fragments in `css`.**

### Conditional fragments

```tsx
const Row = styled.div<{ $selected: boolean }>`
  padding: 8px;
  ${({ $selected }) =>
    $selected &&
    css`
      background: var(--color-surface-muted);
      font-weight: 600;
    `}
`;
```

(`false` renders nothing, like in JSX.)

## 2. `keyframes`: scoped animations

```tsx
import { keyframes } from 'styled-components';

const appear = keyframes`
  from { stroke-dashoffset: ${CIRCUMFERENCE}; }
`;

const Arc = styled.circle`
  animation: ${appear} 600ms ease-out;

  @media (prefers-reduced-motion: reduce) {
    animation: none;
  }
`;
```

`keyframes` generates a **uniquely named** `@keyframes` rule (no global name collisions) and returns a reference you interpolate into `animation`. The rule is injected lazily, only when used.

> ♿ **Respect `prefers-reduced-motion`.** Some users get dizzy or nauseous from motion. Disabling non-essential animations for them is an accessibility requirement, and it's a one-liner.

## 3. Summary

- `css` = reusable fragments (like Sass mixins); required whenever a fragment contains interpolation functions.
- Conditional fragments: `${(p) => p.$x && css`…`}`.
- `keyframes` = collision-free animations; always handle `prefers-reduced-motion`.
