# Lecture 09.08 · `.attrs()`, the Polymorphic `as` Prop, and `shouldForwardProp`

> **Section:** S09 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes

---

## 1. `.attrs()`: default or computed attributes

```tsx
const StyledButton = styled.button.attrs({ type: 'button' })`…`;
const SearchInput = styled.input.attrs({ type: 'search', autoComplete: 'off' })`…`;

// computed from props
const ExternalLink = styled.a.attrs<{ $external?: boolean }>(({ $external }) =>
  $external ? { target: '_blank', rel: 'noopener noreferrer' } : {},
)`…`;
```

`.attrs` attaches attributes to every rendered element, either static or computed from props. Explicit props passed by the caller override static attrs.

> 🛡 `rel="noopener noreferrer"` on `target="_blank"` links prevents the opened page from getting a reference to your window (`window.opener`) and leaking the referrer. Encoding it in a component means nobody forgets it.

## 2. The `as` prop: polymorphism

Every styled component accepts `as` to render a **different element or component** with the same styles:

```tsx
<Stack as="ul" $gap={2}>…</Stack>          // a flex <ul> for a semantic list
<Stack as="section" aria-labelledby="h1">…</Stack>
<StyledButton as="a" href="/tasks">View tasks</StyledButton>   // looks like a button, is a link
```

Great for **semantics and accessibility**: you choose the right element (`ul`, `nav`, `a`) without duplicating styles.

⚠️ With `as="a"`, `.attrs({ type: 'button' })` would still add `type="button"` to the link (harmless but invalid). Keep that in mind for polymorphic components.

## 3. `shouldForwardProp`: fine-grained control

When you can't use `$` props (e.g. wrapping a third-party component whose props you don't control), decide per prop what reaches the element:

```tsx
const Panel = styled('div').withConfig({
  shouldForwardProp: (prop) => !['elevation', 'tone'].includes(prop),
})<{ elevation: number; tone: 'info' | 'warning' }>`
  box-shadow: 0 ${(p) => p.elevation}px ${(p) => p.elevation * 3}px rgba(0, 0, 0, 0.15);
`;
```

App-wide, `<StyleSheetManager shouldForwardProp={…}>` can filter with a list of valid HTML attributes (e.g. `@emotion/is-prop-valid`), which is what the 09.04 warning suggests. For our own components, **transient `$` props are simpler**.

## 4. Summary

- `.attrs()` sets default/computed attributes (`type`, `rel`, `autoComplete`).
- `as` renders another element with the same styles; use it for semantics.
- `shouldForwardProp` (or `StyleSheetManager`) controls forwarding when `$` props aren't an option.
