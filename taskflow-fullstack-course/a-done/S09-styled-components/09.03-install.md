# Lecture 09.03 · 🛠 Install styled-components, VS Code Support, and Your First Styled Component

> **Section:** S09 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~20 minutes
> **Project feature:** styled-components installed; a `Stack` layout primitive

## 1. Install

**Stop the dev server first** (Ctrl+C), then:

```bash
cd /c/dev/taskflow/frontend
```

```bash
npm install styled-components
```

At the time of writing this installs **styled-components 6.5.x**, which ships its own TypeScript types (no separate `@types/…` package needed in v6).

> ⚠️ **Why stop the dev server?** In testing for this course, installing a package **while** `npm run dev` was running produced confusing errors in the open browser tab: *"Invalid hook call"*, *"Cannot read properties of null (reading 'useState')"* and *"several instances of 'styled-components' initialized"*. Vite re-optimises its pre-bundled dependencies when a new package appears, and a tab that loaded the old bundle can end up with **two copies** of React or styled-components. A full reload fixed it. General rule: **after installing dependencies, restart the dev server and hard-reload the page** before debugging anything.

Install the VS Code extension **vscode-styled-components** (01.01) for CSS syntax highlighting and autocomplete inside the template literals.

## 2. ✍️ Your first styled component: `src/components/styled/Stack.tsx`

A **layout primitive**: a flex container whose direction, gap and alignment are props. Doing this with SCSS classes would mean a modifier per direction × gap × alignment combination.

```tsx
import styled from 'styled-components';

interface StackProps {
  $direction?: 'row' | 'column';
  $gap?: number; // spacing scale step: 4px × n (same scale as SCSS space(), 03.04)
  $align?: 'start' | 'center' | 'end' | 'stretch';
  $justify?: 'start' | 'center' | 'end' | 'space-between';
  $wrap?: boolean;
}

/** Layout primitive: flexbox with spacing-scale gaps. Polymorphic via `as` (09.08). */
export const Stack = styled.div<StackProps>`
  display: flex;
  flex-direction: ${({ $direction = 'column' }) => $direction};
  gap: ${({ $gap = 2 }) => $gap * 4}px;
  align-items: ${({ $align = 'stretch' }) => $align};
  justify-content: ${({ $justify = 'start' }) => $justify};
  flex-wrap: ${({ $wrap = false }) => ($wrap ? 'wrap' : 'nowrap')};
`;
```

- `styled.div<StackProps>` is a **generic** (06.01) that types the props your interpolations receive.
- Each `${({ … }) => …}` is an **interpolation function**, called with the props on render (09.02). Destructuring defaults give prop defaults.
- The `$` prefix makes these **transient props**: used for styling, **not** passed to the DOM (09.04).
- `$gap * 4` mirrors SCSS's `space(n)` (4px scale), so the two styling systems share **one spacing scale**.

## 3. Use it

In `PageLayout.tsx`, group the header's right-hand items:

```tsx
import { Stack } from './styled/Stack';
// …
<Stack $direction="row" $gap={3} $align="center" style={{ marginLeft: 'auto' }}>
  <ThemeToggle />
</Stack>
```

(`style` still works: styled components forward normal props, including `style` and `className`, to the element.)

Run `npm run dev`, then inspect the element: you'll see `class="sc-… …"` (09.02).
