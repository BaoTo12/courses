# Lecture 07.15 · 🎯 Your Turn: a Status Board (TODO / IN PROGRESS / DONE)

> **Section:** S07 · **Type:** 🎯 Your Turn · **Track:** ★ Core · **Time:** ~60 minutes

---

## 1. The task

Add a **board view** next to the list view:

```text
[ List ] [ Board ]
──────────────────────────────────────────────────────
 TO DO            3 │ IN PROGRESS      1 │ DONE      1
 ┌──────────────┐   │ ┌──────────────┐   │ ┌──────────┐
 │ Fix login…   │   │ │ Write report │   │ │ Plan…    │
 └──────────────┘   │ └──────────────┘   │ └──────────┘
 ┌──────────────┐   │                    │
 │ Review…      │   │                    │
 └──────────────┘   │                    │
```

## 2. Requirements

1. A `List` / `Board` toggle (two `Button`s) above the content. The list view keeps its filter bar; the board shows **all** tasks.
2. A `Board` component with **three columns**, one per status, in `TASK_STATUSES` order. Each column shows its label and a **count**.
3. Use `groupByStatus` from your domain code; don't filter three times by hand.
4. Toggling a task on the board **moves** it to the right column (state lives in `App`; the board only calls `onToggle`).
5. An empty column shows "Nothing here." instead of an empty box.
6. Columns side by side from the `md` breakpoint; stacked on small screens. Use a CSS Module with `@use '@styles/abstracts' as *;` and `respond-to`.
7. Accessibility: each column is a `<section>` labelled by its heading (`aria-labelledby`).
8. `npm run build` and `npm run lint` pass with no warnings.

## 3. Think before coding

- Where does the `view` state live, and why?
- Should `Board` be one component, or `Board` + `BoardColumn`? What props would `BoardColumn` need?
- What `key` does each column get? Each card?

## 4. Hints

<details>
<summary>Hint 1: shape of the components</summary>

`Board({ tasks, onToggle })` computes `groupByStatus(tasks)` and maps over `TASK_STATUSES` to render `BoardColumn({ status, tasks, onToggle })`. `BoardColumn` can live in the same file if it isn't exported (Fast Refresh only cares about **exports**).
</details>

<details>
<summary>Hint 2: accessible sections</summary>

`<section aria-labelledby={headingId}><h2 id={headingId}>…</h2>…</section>` with `headingId = \`column-${status}\``.
</details>

<details>
<summary>Hint 3: the view toggle</summary>

`type View = 'list' | 'board'; const [view, setView] = useState<View>('list');` then a ternary around the two views.
</details>
