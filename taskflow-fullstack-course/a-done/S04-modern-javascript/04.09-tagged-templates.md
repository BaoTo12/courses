# Lecture 04.09 · Tagged Template Literals: How `` styled.div`…` `` Actually Works

> **Section:** S04 · **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> Preview of S09 (styled-components). After this lecture, the styled-components syntax won't look like magic.

---

## 1. Template literals (the untagged kind)

```js
const name = 'An';
const count = 3;
const msg = `Hello ${name}, you have ${count} tasks`;   // interpolation
const multi = `line 1
line 2`;                                                   // multi-line strings
```

`${expression}` evaluates any JavaScript expression and converts the result to a string.

## 2. Tagged templates: calling a function with a template

Put a function name directly before the backtick, and JavaScript **calls that function** with the template's pieces instead of building a string:

```js
function tag(strings, ...values) {
  console.log(strings);   // the literal text parts
  console.log(values);    // the evaluated ${…} values
  return 'whatever the tag returns';
}

const priority = 'HIGH';
const result = tag`Task is ${priority} and due ${'Oct 3'}!`;
```

Output:

```text
[ 'Task is ', ' and due ', '!' ]
[ 'HIGH', 'Oct 3' ]
```

- `strings` always has **one more element** than `values` (text before, between and after each `${}`).
- The tag can return **anything**: a string, an object, a function, a React component.
- The values are passed **as values**, not converted to strings. So a `${}` can contain a **function**, and the tag decides what to do with it.

## 3. Rebuilding a mini "styled" in 15 lines

This is the core trick behind styled-components:

```js
function css(strings, ...values) {
  // Return a FUNCTION that produces CSS text for given props
  return (props) =>
    strings.reduce((out, str, i) => {
      let value = values[i];
      if (typeof value === 'function') value = value(props); // interpolation functions!
      return out + str + (value ?? '');
    }, '');
}

const buttonStyles = css`
  padding: 8px 16px;
  background: ${(p) => (p.variant === 'primary' ? '#4f46e5' : '#fff')};
  color: ${(p) => (p.variant === 'primary' ? '#fff' : '#0f172a')};
`;

console.log(buttonStyles({ variant: 'primary' }));
```

```text
  padding: 8px 16px;
  background: #4f46e5;
  color: #fff;
```

The real library goes further. Internally, `` styled.button`…` ``:
1. Stores the `strings` and `values` (including your `(p) => …` functions).
2. Returns a **React component**.
3. On each render, calls your interpolation functions with the component's **props** (and theme) to produce CSS text.
4. Hashes that CSS into a class name (e.g. `.sc-a1b2c3`), injects a `<style>` rule into the page if it's new, and renders a `<button class="sc-a1b2c3 …">`.

You'll see exactly this in DevTools in S09.

## 4. Other tagged templates you might meet

| Tag | Library | Purpose |
|---|---|---|
| `` styled.div`…` ``, `` css`…` ``, `` keyframes`…` `` | styled-components | CSS-in-JS |
| `` gql`…` `` | GraphQL clients | Parse queries at build time |
| `` html`…` `` | lit | Safe HTML templates |
| `` String.raw`C:\new` `` | Built-in | Raw strings (backslashes not processed) |
| `` sql`…` `` | Some DB libraries | **Safe parameterised SQL**: values are passed separately, never concatenated |

That last one is interesting for security (S36): because a tag receives text parts and values **separately**, a library can send the values as **parameters**, which is exactly how prepared statements prevent SQL injection. A plain template literal would concatenate the values into the query text, and that's exactly how injection happens.

## 5. Summary

- `` tag`text ${a} more ${b}` `` calls `tag(['text ', ' more ', ''], a, b)`.
- Values are passed as values, so they can be **functions**, which the tag can call later (with props).
- styled-components = a tag that returns a component, calls your interpolation functions with props, hashes the CSS, and injects a class.
- Tags that keep text and values separate enable safety (e.g. parameterised SQL).

## 6. Check yourself

What does this log?

```js
const t = (s, ...v) => `${s.length}:${v.length}`;
console.log(t`a${1}b${2}c`, t`no values`);
```
