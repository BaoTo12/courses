# Lecture 18.12 · 🎯 Your Turn: `deleteTask(id)` and `toggleTaskOnServer(id)` Thunks with Toasts

> **Section:** S18 · **Type:** 🎯 Your Turn · **Track:** ★ Core · **Time:** ~2 hours

---

## 1. The task

Finish moving TaskFlow's async logic into thunks, and let thunks talk to the user.

### A. Toasts move into the store

1. The toast **list** now lives in the `ui` slice (`ui.toasts`, built in 15.12). Rewrite `ToastProvider` so that:
   - it renders `useAppSelector((state) => state.ui.toasts)`;
   - `show(input)` dispatches `toastShown(input)` and `dismiss(id)` dispatches `toastDismissed(id)`;
   - `useToast()` keeps exactly the same API, so no page changes;
   - each toast still disappears after 4 s. (Hint: give each toast its own small component with its own effect.)
2. `ToastProvider` must be **inside** `<Provider>` in `main.tsx` (it already is: 17.03).

### B. Thunks that report to the user

3. `toggleTaskOnServer(id): AppThunk<Promise<boolean>>`: reads the task with `getState()`, PATCHes the opposite status, dispatches `taskUpdated`, and dispatches a success toast ("Completed: …") when a task becomes DONE. On failure: an **error toast**, and it resolves to `false` (it doesn't reject).
4. `deleteTask(id): AppThunk<Promise<boolean>>`: DELETE, `taskDeleted(id)`, a success toast "Deleted: <title>"; on failure an error toast and `false`.
5. Move 17.13's `clearCompleted` into a thunk too (no arguments: it finds the DONE tasks with `getState()`), with its toast.

### C. Pages

6. `TasksPage`: the toggle dispatches `toggleTaskOnServer`; "Clear completed" dispatches `clearCompleted()` after confirmation.
7. `TaskDetailsPage`: Delete dispatches `deleteTask`, then navigates back only if it resolved to `true`. Keep 13.13's `isDeleting` guard.
8. No page imports `useTaskOperations` any more (the file is gone).

### D. Tests (with a fake API through `makeStore(state, { api })`)

9. `toggleTaskOnServer`: success (status DONE + success toast); failure (resolves `false`, status unchanged, error toast).
10. `deleteTask` removes the task **and** clears it from the selection (15.10).
11. `clearCompleted` with one failing DELETE: the failed task stays, and the toast says how many failed.

<details>
<summary>Hint 3: the auto-dismiss timer</summary>

```tsx
function ToastItem({ toast, onDismiss }: { toast: Toast; onDismiss: (id: number) => void }) {
  useEffect(() => {
    const timer = window.setTimeout(() => onDismiss(toast.id), AUTO_DISMISS_MS);
    return () => window.clearTimeout(timer);
  }, [toast.id, onDismiss]);
  // …render
}
```

If the user dismisses early, the component unmounts and the cleanup cancels the timer.
</details>
