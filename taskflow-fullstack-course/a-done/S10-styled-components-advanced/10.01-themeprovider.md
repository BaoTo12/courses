# Lecture 10.01 · `ThemeProvider`: How a Theme Reaches Every Styled Component

> **Section:** S10 · styled-components Advanced: Theming, Global Styles, and Living with SCSS
> **Type:** 📖 Theory · **Track:** ★ Core · **Time:** ~20 minutes
> 🔗 Official reading: styled-components.com/docs/advanced#theming

---

## 1. The problem after S09

S09's styled components use colours three different ways:

```tsx
background: var(--color-surface);           // a raw CSS custom property string
stroke: ${({ $color }) => $color};           // a colour passed in as a prop
if (percent < 67) return '#f59e0b';          // a hard-coded hex value
```

That means inconsistent access, typos go unnoticed (`var(--color-surfce)` silently fails), and some colours ignore dark mode entirely. We need **one typed source** of design values inside styled components.

## 2. `ThemeProvider`

styled-components ships a `ThemeProvider` that puts a **theme object** into React context (08.09). Every styled component below it receives that object as `props.theme` in its interpolations:

```tsx
import { ThemeProvider } from 'styled-components';

<ThemeProvider theme={theme}>
  <App />
</ThemeProvider>

const Card = styled.article`
  background: ${({ theme }) => theme.colors.surface};
  border-radius: ${({ theme }) => theme.radii.lg};
  padding: ${({ theme }) => theme.space(4)};
`;
```

Internals: the provider is a context provider. When a styled component renders, it reads the context and passes `theme` along with your props to each interpolation function (09.02). Non-styled components can read it with the `useTheme()` hook from styled-components.

## 3. The consequence you must know

Because it's context: **when the `theme` object changes (a new reference), every styled component re-renders and recomputes its CSS.** A light/dark switch that swaps two theme objects re-renders the whole styled UI and generates new CSS classes for the new colours.

Keep that in mind. 10.04 shows a design where the theme object **never changes**, even when the user switches themes.

## 4. Summary

- `ThemeProvider` passes a theme object via context; interpolations receive it as `props.theme`.
- A new theme object re-renders all styled components.
- It provides one typed place for design values (typing it is 10.02).
