Notes:

- **Two URL patterns** in one annotation: the exact `/debug/request-info` (path info `null`) and `/debug/request-info/*` (path info = the rest). Try `/debug/request-info/tasks/42`.
- **Everything is escaped**, including header names and parameter names. A request-info page is an XSS playground otherwise: `/debug/request-info?<img src=x onerror=alert(1)>=1`.
- **Loopback only** (`127.0.0.1`, `::1`): the page shows the `Cookie` header, the session id included. On a real server, a debug page like this must not exist at all. S43 removes it from production builds with a context parameter. It answers **404**, not 403, so it doesn't confirm it exists.
- **`request.getContextPath()`** builds the stylesheet URL, so it works at any context path (28.10).

Use it now:

| Try | Look at |
