## 2. Showing the form, from both places

✍️ `src/main/java/com/taskflow/web/tasks/TaskFormPage.java`

{{file:@reference/taskflow/backend/src/main/java/com/taskflow/web/tasks/TaskFormPage.java:java}}

The GET and the failed POST show the page the same way, so the code lives in one place. The only difference is what's in `form` (empty vs as typed) and `errors` (empty vs filled).

## 3. The service gains three small methods

`TaskService.categoryIds()` (for the form's category check), `task(id)` and `update(task)` (for edit). `create` now reports a duplicate title with a `DuplicateKeyException` (📦 provided), which the controller turns into a form error instead of a 500.

`Layout.java` (S31's `println` page frame) had no users left, so it's deleted.

## ✅ Checkpoint

`mvn package` → green. Open `/taskflow/tasks/new`, submit it empty: 400, the errors are next to the fields. Fill it in: you land on the new task with "Task created.", and Reload doesn't create a second one.
