Walk through it against S34's version (34.21):

| S34 | S35 | Lecture |
|---|---|---|
| `<% for (Object task : (List<?>) request.getAttribute("tasks")) { pageContext.setAttribute("task", task); %>` | `<c:forEach items="${tasks}" var="task" varStatus="row">` | 35.07 |
| — | `<td class="row-number">${row.count}</td>` | 35.07 |
| `<p …${empty tasks ? '' : ' hidden'}>` + `<table${… ' hidden'}>` | `<c:choose>`: the table **or** the paragraph is rendered | 35.06 |
| `<p class="text-danger"${overdueCount == 0 ? ' hidden' : ''}>` | `<c:if test="${overdueCount > 0}">` | 35.06 |
| `${task.status}` (`IN_PROGRESS`) | `<c:choose>` → "In progress" with a badge class | 35.06 |
| three hand-written links | `<c:forEach items="${statuses}">` + `<c:url>`/`<c:param>`, keeping the current search | 35.11 |
| `${Html.escape(…)}` | `<c:out>` / `fn:escapeXml` | 35.04 |
| — | `data-confirm-title` on the delete form | 35.17 |

Two details to notice:
- `statusFilter == status` compares two **enums** (no coercion needed).
- `href="${fn:escapeXml(statusUrl)}"`: `<c:url>` URL-encodes the **parameters** but doesn't HTML-escape the **URL**, whose `&` must be `&amp;` inside an attribute. The test checks `href="/taskflow/tasks?status=DONE&amp;q=a%26b%22"` for the search `a&b"`.

## 4. Two S34 assertions change, on purpose

- `<table hidden>` / `<p class="text-muted" hidden>` no longer exist: the table isn't rendered at all. `S34ElTest` now asserts `assertFalse(none.contains("<table"))`.
- The search box's `"` is written `&#034;` by `fn:escapeXml` (S34's `Html.escape` wrote `&quot;`: 35.04 §1).

When behaviour changes intentionally, update the old test **and** say why in a comment. Deleting it would lose the regression coverage.
