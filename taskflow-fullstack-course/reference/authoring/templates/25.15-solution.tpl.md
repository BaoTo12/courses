## 2. The widgets

✍️ `src/features/dashboard/DashboardWidgets.tsx`

{{file:features/dashboard/DashboardWidgets.tsx:tsx}}

- Each widget calls `useTranslation` **itself**, which keeps the 21.17 design: a widget re-renders for its own data, and now also on language changes.
- `t('completion.summary', { count: total, rate })`: `count` chooses the form, `rate` is plain interpolation.
- `formatDue(task.dueDate, today, i18n.language)` gives "Sep 20, 2026 (6 days ago)" in English and the Vietnamese equivalent. `i18n.language` (not `resolvedLanguage`) keeps a region such as `en-GB` for date order (25.06 §3).
- The `{task.dueDate && …}` guard: overdue tasks always have a due date, but the type says `IsoDate | null`, and the guard keeps the code honest without a `!`.

`DashboardPage` translates its title and loading text with `useTranslation(['dashboard', 'common'])`.

## 3. Why it's lazy for free

`useTranslation('dashboard')` asks i18next for a namespace that isn't loaded. The HTTP backend fetches `/locales/<lng>/dashboard.json`, and the component suspends meanwhile. The dashboard route's `<Suspense>` (12.09) shows "Loading dashboard…" for both the JS chunk and the translations.

## 4. Common wrong answers

| Attempt | Problem |
|---|---|
| `` `${count} overdue task${count === 1 ? '' : 's'}` `` | English-only grammar in code; not translatable |
| `new Date(task.dueDate).toLocaleDateString()` | the browser's locale, not the app's, and a possible off-by-one day in the Americas (25.10) |
| copying `status.*` into `dashboard.json` | two places to fix every label |
| `useTranslation()` without `'dashboard'` | the keys resolve against `common` and show raw |
