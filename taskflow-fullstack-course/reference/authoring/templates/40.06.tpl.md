## 📇 API card: SLF4J `MDC` (Mapped Diagnostic Context)

| Call | Meaning |
|---|---|
| `MDC.put(key, value)` | attach a value to **this thread**; every log line printed on it can show it (`%X{key}`) |
| `MDC.get(key)` / `MDC.remove(key)` / `MDC.clear()` | |
| in the Logback pattern | `%X{requestId}`, or `%X{requestId:-default}` |

**Always remove it in `finally`:** Tomcat reuses threads. A leftover id would label the **next** request's lines, which is worse than no id.

## 2. Details that matter

| Detail | Why |
|---|---|
| `response.getStatus()` **after** the chain | Servlet 3.0+ returns what the servlet set, `sendError` included. Before the chain, it's always 200 (40.17) |
| `status = 500` unless the chain returns | an exception escaping the chain becomes a 500 **after** the filter has finished |
| `System.nanoTime()` | a monotonic clock for durations (`currentTimeMillis` can jump with clock adjustments) |
| the id in a header | a user or the React app can report "request 3f9a1c…" and you find all its lines |
| the query string is logged | useful, but it's also where secrets end up if someone puts them in URLs: never put tokens or passwords in GET parameters |
