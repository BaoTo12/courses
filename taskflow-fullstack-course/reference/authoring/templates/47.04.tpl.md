Three changes:

1. `PUBLIC_PATHS` gains `/api/auth/csrf`, `/login`, `/logout`, `/me`, compared with `Api.path(request)` (the servlet is `/api/auth/*`, so `getServletPath()` alone is `/api/auth`).
2. An anonymous `/api/*` request **throws** `ApiException.unauthenticated()`. The filter doesn't write JSON itself: `ApiExceptionFilter`, earlier in the chain, catches it and writes the standard error (with CORS headers, 47.10).
3. A disabled account's session (42.07) ends with a 401 for API calls instead of a redirect.
