## 3. Decisions

| Choice | Why |
|---|---|
| 400 and 404 decided in the servlet, **before** forwarding | the view renders one thing; errors use the container's error pages (S43 makes them nice) |
| `request.setAttribute("task", …)`, then forward | the same request reaches the JSP (32.05) |
| the title escaped in **three** places (`<title>`, breadcrumb, `<h1>`) | each is output of user data. `Html.escape` must not be forgotten once, and that's why S35's `<c:out>` is better |
| status and priority printed raw | enums from our model: no user text |
| `if (task.getDescription().isEmpty())` in the view | a **presentation** decision ("what to show when empty"), fine in a view. Loading or checking permissions would not be. |

## 4. Duplication you should dislike

`list.jsp` and `view.jsp` repeat the whole page frame (head, header, nav, footer). S33 introduces `<%@ include %>` / `<jsp:include>`, and S35 a layout tag file, to fix it.
