# Lecture 44.14 · EL Functions: Static Java Methods in a TLD

> **Section:** S44 · **Type:** 📖 Theory · **Track:** ＋ Extended · **Time:** ~10 minutes
> Verified: `S44AdvancedJspTest.theTruncateFunctionCutsBeforeEscaping`

*Extended track: outline.*

---

- An EL function is a **public static** method declared in a TLD: `<function>` → `<name>`, `<function-class>`, `<function-signature>` (fully qualified types). JSTL's `fn:` library is exactly that.
- TaskFlow's:

{{file:@reference/taskflow/backend/src/main/java/com/taskflow/web/tags/Functions.java:java}}

  ```xml
  <function>
    <name>truncate</name>
    <function-class>com.taskflow.web.tags.Functions</function-class>
    <function-signature>java.lang.String truncate(java.lang.String, int)</function-signature>
  </function>
  ```

  ```jsp
  <c:out value="${tf:truncate(recent.title, 40)}"/>      <%-- "Recently viewed" links --%>
  ```
- **Order matters:** truncate **then** escape. Escaping first could cut an entity in half (`&am…`); the test shows `…&gt; o…` intact.
- **Function vs tag vs EL method call:** a function returns a value to use inside expressions (`${fn:length(x) > 0}`); a tag writes output and can use the page context; EL 2.2+ can also call instance methods directly (`${task.isOverdue(today)}`), and EL 3.0 can call static methods of imported classes (34.16). Functions remain the portable, declared way.
