## 1. Start the backend

With Docker Compose (28.01): `docker compose up -d` → Tomcat on `http://localhost:8080/taskflow`.

Without a Tomcat install or image, 📦 `DevServer` starts MySQL in a container (as the tests do) and an embedded Tomcat:

{{file:@reference/taskflow/backend/src/test/java/com/taskflow/DevServer.java:java}}

```bash
cd reference/taskflow/backend
```

```bash
mvn -q test-compile dependency:build-classpath -Dmdep.outputFile=target/cp.txt
```

Then `java -cp "target/classes;target/test-classes;<the contents of target/cp.txt>" com.taskflow.DevServer` (`:` instead of `;` on macOS/Linux). Add `-Dport=8081` if something else already listens on 8080: on the machine these lectures were verified on, an Apache httpd did.

## 2. The proxy

✍️ `frontend/vite.config.ts`

{{file:@reference/taskflow/frontend/vite.config.ts:ts}}

| Option | Why |
|---|---|
| `target` | Tomcat's origin (`TASKFLOW_BACKEND` overrides it) |
| `rewrite: /api/… → /taskflow/api/…` | the browser calls `/api/tasks`; Tomcat serves the web app under its **context path** |
| `cookiePathRewrite: { '/taskflow': '/' }` | Tomcat's `Set-Cookie: JSESSIONID=…; Path=/taskflow`. The browser only ever requests `/api/…` on the Vite origin, so a `/taskflow` cookie would be **stored but never sent back**: login "succeeds", and the very next call is a 401 |
| `TASKFLOW_API=mock` | the Part 1 mock is still one variable away, for UI work without Java |

`XSRF-TOKEN` already says `Path=/` (47.06), so it needs no rewrite.

## 3. Run it

```bash
cd reference/taskflow/frontend
```

```bash
npm run dev
```

(With the backend on another port: `TASKFLOW_BACKEND=http://localhost:8081 npm run dev`; in PowerShell set `$env:TASKFLOW_BACKEND` first.) json-server isn't started any more.

## 4. Same origin, no CORS

The browser sees only `http://localhost:5173`: pages **and** `/api`. No preflights, no CORS headers needed (47.11), and the session cookie is a same-site cookie.

Open the React app, log in as `alice` / `alice123`: the task list shows alice's 22 tasks, from MySQL.
