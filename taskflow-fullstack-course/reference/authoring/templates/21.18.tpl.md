## 1. ✍️ `src/features/dashboard/dashboardSelectors.ts`

{{file:features/dashboard/dashboardSelectors.ts:ts}}

- The three object/array selectors depend **only** on `selectTasks`. `selectTasks` (the adapter's `selectAll`) keeps its reference until a task changes, so a toast, a sort change or a quick-find keystroke returns the **same** results.
- `selectCompletionRate` returns a number and reuses the memoized counts.
- `selectOverdueTasks` takes `today` as an argument. The string comparison `task.dueDate < today` works because both are `YYYY-MM-DD`, which sorts like a date (that's also why `isOverdue` in `task-utils.ts` can use `<`).

## 2. ✍️ `src/hooks/useToday.ts`

{{file:hooks/useToday.ts:ts}}

- `toISOString()` converts to **UTC**: in Vietnam (UTC+7), between 00:00 and 07:00 local time it returns **yesterday's** date. `toLocalIsoDate` uses the local getters.
- The interval moves a dashboard left open overnight to the new day. `setToday` with the same string lets React bail out, so the minute tick doesn't re-render the widgets.

## 3. ✍️ `src/features/dashboard/DashboardWidgets.tsx`

{{file:features/dashboard/DashboardWidgets.tsx:tsx}}

Each widget selects **only** what it shows. No `memo` is needed here: the widgets have no props (or one primitive, `today`), and `DashboardPage` itself rarely re-renders (§4).

## 4. ✍️ `src/pages/DashboardPage.tsx`

{{file:pages/DashboardPage.tsx:tsx}}

The page selects two **primitives** (`selectTaskCount`, `selectTasksStatus`) to decide "loading or not". Selecting `selectTasks` here, as the S20 version did, would re-render the page, and all four widgets under it, on every task change.

const { store } = await import('/src/app/store.ts');

## 8. Common wrong approaches

| Approach | Problem |
|---|---|
| `selectOverdueTasks = createSelector([selectTasks], (tasks) => tasks.filter((t) => isOverdue(t, todayIso())))` | reads the clock inside a selector: the result depends on **when** it's called, and the cache would keep yesterday's list forever |
| `new Date().toISOString().slice(0, 10)` for "today" | the UTC date, a day off near midnight in UTC+7 |
| `DashboardPage` selects `selectTasks` and passes counts down as props | every task change re-renders the page and all four widgets, even a widget whose numbers didn't change |
| One `selectDashboard` returning `{ statusCounts, priorityCounts, rate, overdue }` | one new object whenever **any** part changes: every widget re-renders for every change |
| Storing the counts in a slice, updated by reducers | derived data in state (15.01): every task action must remember to update them |
