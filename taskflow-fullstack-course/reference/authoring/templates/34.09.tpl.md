## 2. The controller assembles it

✍️ `src/main/java/com/taskflow/web/tasks/TaskViewServlet.java`

{{file:@reference/taskflow/backend/src/main/java/com/taskflow/web/tasks/TaskViewServlet.java:java}}

Two new attributes: `details` (the model) and `pageTitle` (for the header). The header used to read a **local variable** `pageTitle` of the including page (33.08). EL can't see Java locals, only attributes, so the controller now provides it. S35's layout tag will take it as a proper tag attribute.

## 3. The header, Java-free

✍️ `src/main/webapp/WEB-INF/views/common/header.jspf`

{{file:@reference/taskflow/backend/src/main/webapp/WEB-INF/views/common/header.jspf:jsp}}

- `${pageContext.request.contextPath}` replaces `request.getContextPath()` (34.14).
- `${Html.escape(pageTitle)}`: `Html` is imported by the fragment's own page directive, so EL can call its static method (34.17). The escaping is **required**: EL prints raw text (34.18), and the title is user input.

## 4. The details page

✍️ `src/main/webapp/WEB-INF/views/tasks/view.jsp`

{{file:@reference/taskflow/backend/src/main/webapp/WEB-INF/views/tasks/view.jsp:jsp}}

Read it as a checklist of this section's ideas:

| Expression | Idea |
|---|---|
| `${details.task.status}` | a chain of getters; an enum prints its `name()` (34.07) |
| `${details.owner.displayName}` | a nested bean from another "table" (34.08) |
| `${empty details.category ? 'No category' : …}` | `empty` + the conditional operator choose a fallback (34.11, 34.12) |
| `${empty details.task.dueDate ? 'no due date' : details.task.dueDate}` | a `LocalDate` prints with `toString()`: `2026-10-03` (S44 formats it per locale) |
| `class="${empty … ? 'text-muted' : 'task__description'}"` | EL inside an HTML attribute: it's all template text to JSP (34.02) |

No `import` of model classes, no cast, no null check.
