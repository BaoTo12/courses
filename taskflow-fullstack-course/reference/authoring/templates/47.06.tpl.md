| Decision | Why |
|---|---|
| `MessageDigest.isEqual` | constant-time: no timing clue about how many characters matched |
| before `authentication` (`apiCsrf` in `web.xml`) | the login POST is protected too; the order matches the Part 1 mock |
| after `api` | its `ApiException` becomes the standard 403 JSON |
| `/api/*` only | pages keep the session-bound hidden-field token (`CsrfFilter`, which skips `/api/*` since S46) |

## 3. The test harness

S46's API tests now send the header: `TomcatTest.xsrfToken(browser)` calls `/api/auth/csrf` and returns the cookie's value.

## ✅ Checkpoint

A `POST /api/tasks` from curl without `X-XSRF-TOKEN` → 403 `CSRF_TOKEN_INVALID`, even with a valid session.
