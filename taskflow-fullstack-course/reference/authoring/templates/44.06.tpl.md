## 📇 API card: the i18n tags

| Tag / setting | Meaning |
|---|---|
| `<fmt:message key="k"/>` | the text for `k` in the current bundle and locale; unknown key → `???k???` |
| `<fmt:message key="k"><fmt:param value="…"/></fmt:message>` | `{0}`, `{1}` … filled in (`java.text.MessageFormat`) |
| `<fmt:message key="k" var="x"/>` | store the text instead of printing it |
| `<fmt:message key="k" bundle="${b}"/>` | a bundle other than the default |
| `<fmt:setLocale value="vi" scope="…"/>` | set the locale for a scope (TaskFlow does it in a filter instead, 44.07) |
| `<fmt:setBundle basename="i18n.messages" var="b"/>` / `<fmt:bundle basename="…">` | choose a bundle for a scope / a body |
| context param `javax.servlet.jsp.jstl.fmt.localizationContext` | the **default** bundle basename for every page |
| context param `javax.servlet.jsp.jstl.fmt.fallbackLocale` | the locale to try when none of the preferred ones has a bundle |
| `<fmt:requestEncoding value="UTF-8"/>` | sets the request encoding before parameters are read (TaskFlow's encoding filter does it for all requests, 40.05) |

Lookup for locale `vi`: `messages_vi` → then the base `messages` for any missing key. Keys are grouped by page (`nav.`, `tasks.`, `dashboard.`) and by concept (`status.`, `priority.`), so a status is translated the same everywhere.

## 2. ✍️ `web.xml`

```xml
<context-param>
  <param-name>javax.servlet.jsp.jstl.fmt.localizationContext</param-name>
  <param-value>i18n.messages</param-value>
</context-param>
<context-param>
  <param-name>javax.servlet.jsp.jstl.fmt.fallbackLocale</param-name>
  <param-value>en</param-value>
</context-param>
```

## 3. In the views

```jsp
<fmt:message key="tasks.col.title"/>
<fmt:message key="status.${task.status}"/>                          <%-- a computed key --%>
<fmt:message key="tasks.stats.${status}"><fmt:param value="${stats[status.name()]}"/></fmt:message>
<fmt:message key="tasks.title" var="listTitle"/>                    <%-- used twice: title + h1 --%>
```

**MessageFormat features:** `{0,choice,1#{0} overdue task|1<{0} overdue tasks}` handles singular/plural; numbers in `{0}` are formatted for the locale.

## 4. 🛡 `fmt:message` does not escape

The bundle text is ours, but `<fmt:param>` values are inserted **as is**:

```jsp
<fmt:message key="nav.loggedInAs"><fmt:param value="${currentUser.displayName}"/></fmt:message>              <%-- ❌ XSS --%>
<fmt:message key="nav.loggedInAs"><fmt:param value="${fn:escapeXml(currentUser.displayName)}"/></fmt:message> <%-- ✅ --%>
```

A display name like `<img src=x onerror=…>` would otherwise run on every page (35.14).

## 5. What's translated

The layout (nav, language switch), the task list, the rows, pagination and the dashboard. The forms, the task details, categories, admin and error pages follow the same pattern (Part 4's finishing work).

## ✅ Recap

One bundle per language, keys in the views, parameters through `<fmt:param>` (escaped), the base bundle as the fallback.
