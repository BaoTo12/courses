## 📇 API card: Jackson's `ObjectMapper` (the parts TaskFlow uses)

| Member | Use |
|---|---|
| `new ObjectMapper()` | expensive to create, **thread-safe** once configured: one `static final` per application |
| `registerModule(new JavaTimeModule())` | `java.time` support (`jackson-datatype-jsr310`) |
| `disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS)` | ISO strings instead of numbers/arrays (46.17) |
| `disable(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES)` | ignore fields a DTO doesn't have (46.11 discusses the trade-off) |
| `readTree(InputStream)` → `JsonNode` | a tree: `has("dueDate")`, `get("title").isTextual()`, `isNull()` |
| `treeToValue(node, Type.class)` / `readValue(in, Type.class)` | bind to a class or record |
| `writeValue(writer, object)` | serialise (records: their components; classes: their getters) |
| `@JsonInclude(NON_NULL)` | leave out null fields (`ApiError.fieldErrors`) |
| `JsonProcessingException` | malformed JSON, or a type mismatch while binding |

## Why a tree for task bodies

`PATCH {"dueDate": null}` means "clear the due date"; `PATCH {}` means "don't touch it". A Java object with `LocalDate dueDate` can't tell them apart (both null). `JsonNode.has("dueDate")` can (46.05).

## Writing

`Json.write(response, 201, dto)` sets the status, `application/json;charset=UTF-8`, and writes. Everything a client receives from `/api/*` goes through it, success or error.
