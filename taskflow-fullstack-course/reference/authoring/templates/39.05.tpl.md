## 3. The error summary, with a parameter

✍️ `src/main/webapp/WEB-INF/views/common/form-errors.jsp`

{{file:@reference/taskflow/backend/src/main/webapp/WEB-INF/views/common/form-errors.jsp:jsp}}

Used by `categories/list.jsp` instead of its own copy:

```jsp
<jsp:include page="/WEB-INF/views/common/form-errors.jsp">
  <jsp:param name="title" value="The category was not saved:"/>
</jsp:include>
```

`errors` arrives as a **request attribute** (a `Map`: attributes carry objects), and `title` as a **parameter** (a string for this one include). 39.06 compares the two.
