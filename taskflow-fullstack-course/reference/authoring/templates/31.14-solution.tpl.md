## 4. Decisions

| Choice | Why |
|---|---|
| `doPost` only | GET is safe by contract (29.03); 405 comes free (30.07) |
| a form per button, not a link | only forms can POST without JavaScript |
| `Params.positiveId` → 400 | malformed input is the client's error; never a `NumberFormatException` 500 (31.16) |
| 404 when there's nothing to delete | the resource doesn't exist; a second delete gives the same **state** (idempotent), a different response |
| redirect to `/tasks` | PRG: Reload doesn't resubmit (31.04) |
| `id` is a number we render, not user text | no escaping needed for a `long`. Escape anything that's text. |

## 5. What's still missing (on purpose)

Anyone can delete anything: no login (S41), no ownership check (S42), and no CSRF token. Any website can auto-submit a form to `/tasks/delete` in your browser: that's S37's lab. The 31.12 table lists them.
