# Lecture 42.03 · 🛠 Build: `AuthorizationFilter` for `/admin/*` → a 403 Page for Non-Admins

> **Section:** S42 · **Type:** 🛠 Build · **Track:** ★ Core · **Time:** ~35 minutes
> **Project feature:** everything under `/admin` is for admins only, for every HTTP method.
> Verified: `S42AuthorizationTest.nonAdminsAreDeniedEveryAdminPathAndMethod` (GET and POST → 403, audited as `ACCESS_DENIED`)

## 1. The filter

✍️ `src/main/java/com/taskflow/web/filters/AuthorizationFilter.java`

{{file:@reference/taskflow/backend/src/main/java/com/taskflow/web/filters/AuthorizationFilter.java:java}}

This lecture builds the **URL rule** (the `if` at the top). The `try`/`catch` around `chain.doFilter` is the second half, built in 42.05.

| Decision | Why |
|---|---|
| mapped to `/*`, checks the prefix in code | the same filter also handles 42.05's exceptions for every path; and `path.startsWith("/admin/")` can't miss a method or a sub-path (42.11) |
| `equals("/admin") \|\| startsWith("/admin/")` | `/administrator-notes` doesn't start with `/admin/`; `/admin` alone is covered |
| after `AuthenticationFilter` | a request here has a user (or is public): 403 means "logged in, not allowed" |
| before `CsrfFilter` | a USER's POST to `/admin/…` is refused as **403 Access denied**, whether or not the token is valid |
| a **forward** to the 403 view with `setStatus(403)` | the page uses the normal layout. S43 replaces this with `sendError(403)` + an `<error-page>` |
| audit every denial | a USER probing `/admin` URLs is exactly what an administrator wants to know (43.11) |

## 2. Its place in the chain

✍️ `web.xml`: declared between authentication and CSRF:

```xml
<filter>
  <filter-name>authorization</filter-name>
  <filter-class>com.taskflow.web.filters.AuthorizationFilter</filter-class>
</filter>
…
<filter-mapping><filter-name>authentication</filter-name><url-pattern>/*</url-pattern></filter-mapping>
<filter-mapping><filter-name>authorization</filter-name><url-pattern>/*</url-pattern></filter-mapping>
<filter-mapping><filter-name>csrf</filter-name><url-pattern>/*</url-pattern></filter-mapping>
```

## 4. The audit service

`AuditService.record(type, username, ip, details)` wraps the provided `AuditDao`: filters and controllers call services, not DAOs (36.02). `AppContextListener` creates it and exposes `auditService(context)`; the filter fetches it in `init`, like servlets fetch their services.
