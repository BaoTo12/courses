# 💡 Lecture 11.11 · Solution Walkthrough: Edit Mode, Dirty Indicator, Reset

> Solution for [11.10 · Your Turn](../../lectures/S11-react-forms/11.10-your-turn-edit-mode.md).
> Verified in the reference app (build + lint clean). Browser test results:
> - **Edit** on a new task opened the form prefilled (`title "Write release notes"`, `status IN_PROGRESS`, `due 2099-12-31`), not dirty, **Reset disabled**.
> - Typing made it dirty ("Unsaved changes" shown, Reset enabled); **Reset** restored the original title and cleared the dirty state.
> - Three synchronous clicks on submit created exactly **one** task (ref lock from 11.06).

## 1. Key decisions

### `isDirty` is derived

```ts
const isDirty = (Object.keys(values) as (keyof TaskFormValues)[]).some(
  (key) => values[key] !== initialValues[key],
);
```

Every field is a primitive (strings and string unions), so `!==` compares correctly. No state and no effect: it can never be out of sync with the values. `Object.keys` returns `string[]` in TypeScript (objects may have extra keys at runtime), so we assert `keyof TaskFormValues` for this form object we fully control.

### No carry-over: the `key` trick

```tsx
<TaskForm
  // A new key resets the form's internal state when switching tasks (07.11)
  key={panel.mode === 'edit' ? `edit-${panel.task.id}` : 'create'}
  …
/>
```

`useState(initialValues)` reads `initialValues` only when the component instance is **created** (08.01). A different `key` tells React "this is a different form", so React unmounts the old one (discarding its state) and mounts a fresh one. This is the recommended alternative to an effect that copies props into state (08.05, anti-pattern 3).

### The panel is a discriminated union

```ts
type FormPanel = { mode: 'closed' } | { mode: 'create' } | { mode: 'edit'; task: Task };
```

`panel.task` exists **only** in edit mode, so the compiler forces `panel.mode === 'edit'` before reading it. With two booleans (`isCreating`, `editingTask`) you could represent "creating and editing at once".

### The server-controlled fields are preserved on update

`toCreateRequest(values, panel.task.categoryId)` sends only editable fields; `fakeUpdateTask` (like a real `PUT`) keeps `id`, `ownerId`, `createdAt` and sets `updatedAt`. The reducer's `taskUpdated` then **replaces** the task by id, returning the **same** references for all other tasks (structural sharing, 04.05).

### Inline title editing vs the full form

The card's **Edit** button now calls `onEdit(task.id)`; inline title editing (08.16) remains on **double-click**. `onEdit` travels through `TaskList` and `Board → BoardColumn` to `TaskCard`, the same drilling as `onToggle` and `onEditTitle`. Count the props passed through `BoardColumn` now: that's the concrete motivation for Redux (S17).

## 2. The reducer additions (`src/hooks/tasks-reducer.ts`, complete file)

```ts
import type { Task } from '../domain/types';
import type { RequestState } from '../domain/api-types';
import { toggleTask, updateTaskField } from '../domain/task-utils';
import { assertNever } from '../domain/guards';

export type TasksState = RequestState<Task[]>;

// Actions describe EVENTS that happened (past tense), not "set X" commands.
export type TasksAction =
  | { type: 'fetchStarted' }
  | { type: 'fetchSucceeded'; tasks: Task[] }
  | { type: 'fetchFailed'; error: string }
  | { type: 'taskToggled'; id: number }
  | { type: 'titleEdited'; id: number; title: string }
  | { type: 'taskAdded'; task: Task }
  | { type: 'taskUpdated'; task: Task };

export const initialTasksState: TasksState = { status: 'idle' };

/** Pure: (state, action) → new state. No fetching, no mutation, no randomness. */
export function tasksReducer(state: TasksState, action: TasksAction): TasksState {
  switch (action.type) {
    case 'fetchStarted':
      return { status: 'loading' };
    case 'fetchSucceeded':
      return { status: 'succeeded', data: action.tasks };
    case 'fetchFailed':
      return { status: 'failed', error: action.error };
    case 'taskToggled':
      if (state.status !== 'succeeded') return state;
      return { status: 'succeeded', data: toggleTask(state.data, action.id) };
    case 'titleEdited': {
      if (state.status !== 'succeeded') return state;
      const title = action.title.trim();
      if (title === '') return state;
      return { status: 'succeeded', data: updateTaskField(state.data, action.id, 'title', title) };
    }
    case 'taskAdded':
      if (state.status !== 'succeeded') return state;
      return { status: 'succeeded', data: [...state.data, action.task] };
    case 'taskUpdated':
      if (state.status !== 'succeeded') return state;
      return {
        status: 'succeeded',
        data: state.data.map((t) => (t.id === action.task.id ? action.task : t)),
      };
    default:
      return assertNever(action);
  }
}
```

`useTasks` exposes `addTask(task)` and `replaceTask(task)` via `useCallback` (as in 08.08).

## 3. `src/components/TaskForm.tsx` (complete, final)

```tsx
import { useRef, useState } from 'react';
import type { FormEvent } from 'react';
import { PRIORITIES, TASK_STATUSES } from '../domain/types';
import { isPriority, isTaskStatus } from '../domain/guards';
import { statusLabel } from '../domain/labels';
import {
  DESCRIPTION_MAX,
  TITLE_MAX,
  hasErrors,
  localToday,
  validateTaskForm,
} from '../domain/task-form';
import type { TaskFormValues } from '../domain/task-form';
import { FormField } from './forms/FormField';
import { Button } from './Button';

interface TaskFormProps {
  initialValues: TaskFormValues;
  mode: 'create' | 'edit';
  onSubmit: (values: TaskFormValues) => Promise<void>;
  onCancel: () => void;
}

const PRIORITY_TEXT = { LOW: 'Low', MEDIUM: 'Medium', HIGH: 'High' } as const;

export function TaskForm({ initialValues, mode, onSubmit, onCancel }: TaskFormProps) {
  const [values, setValues] = useState<TaskFormValues>(initialValues);
  const [touched, setTouched] = useState<Partial<Record<keyof TaskFormValues, boolean>>>({});
  const [submitAttempted, setSubmitAttempted] = useState(false);
  const [isSubmitting, setIsSubmitting] = useState(false); // for rendering (disabled button, label)
  const submittingRef = useRef(false); // synchronous guard: state updates are not visible until the next render

  // Derived, not state (08.05): errors are recomputed from the values on every render.
  const errors = validateTaskForm(values, localToday(), mode === 'create');
  const isDirty = (Object.keys(values) as (keyof TaskFormValues)[]).some(
    (key) => values[key] !== initialValues[key],
  );

  /** Type-safe single-field update: the value type follows the key (06.02). */
  function setField<K extends keyof TaskFormValues>(field: K, value: TaskFormValues[K]) {
    setValues((current) => ({ ...current, [field]: value }));
  }

  const markTouched = (field: keyof TaskFormValues) =>
    setTouched((current) => ({ ...current, [field]: true }));

  /** Show an error once the user has left the field, or after a submit attempt. */
  const visibleError = (field: keyof TaskFormValues) =>
    touched[field] || submitAttempted ? errors[field] : undefined;

  async function handleSubmit(e: FormEvent<HTMLFormElement>) {
    e.preventDefault(); // stop the browser's full-page form submission
    if (submittingRef.current) return; // a second click in the same frame sees the ref, not stale state
    setSubmitAttempted(true);
    if (hasErrors(errors)) return;

    submittingRef.current = true;
    setIsSubmitting(true);
    try {
      await onSubmit(values);
    } finally {
      submittingRef.current = false;
      setIsSubmitting(false);
    }
  }

  function handleReset() {
    setValues(initialValues);
    setTouched({});
    setSubmitAttempted(false);
  }

  return (
    <form className="form" noValidate onSubmit={handleSubmit} aria-label={mode === 'create' ? 'New task' : 'Edit task'}>
      <FormField
        label="Title"
        error={visibleError('title')}
        help={`${values.title.trim().length}/${TITLE_MAX}`}
      >
        {(control) => (
          <input
            {...control}
            className="form-field__input"
            value={values.title}
            onChange={(e) => setField('title', e.target.value)}
            onBlur={() => markTouched('title')}
            maxLength={TITLE_MAX + 20}
            autoComplete="off"
          />
        )}
      </FormField>

      <FormField label="Description" error={visibleError('description')}>
        {(control) => (
          <textarea
            {...control}
            className="form-field__input"
            rows={3}
            value={values.description}
            onChange={(e) => setField('description', e.target.value)}
            onBlur={() => markTouched('description')}
            maxLength={DESCRIPTION_MAX}
          />
        )}
      </FormField>

      <FormField label="Status">
        {(control) => (
          <select
            {...control}
            className="form-field__input"
            value={values.status}
            onChange={(e) => {
              if (isTaskStatus(e.target.value)) setField('status', e.target.value);
            }}
          >
            {TASK_STATUSES.map((s) => (
              <option key={s} value={s}>
                {statusLabel(s)}
              </option>
            ))}
          </select>
        )}
      </FormField>

      <FormField label="Priority">
        {(control) => (
          <select
            {...control}
            className="form-field__input"
            value={values.priority}
            onChange={(e) => {
              if (isPriority(e.target.value)) setField('priority', e.target.value);
            }}
          >
            {PRIORITIES.map((p) => (
              <option key={p} value={p}>
                {PRIORITY_TEXT[p]}
              </option>
            ))}
          </select>
        )}
      </FormField>

      <FormField label="Due date" error={visibleError('dueDate')} help="Optional">
        {(control) => (
          <input
            {...control}
            className="form-field__input"
            type="date"
            value={values.dueDate}
            onChange={(e) => setField('dueDate', e.target.value)}
            onBlur={() => markTouched('dueDate')}
          />
        )}
      </FormField>

      <div className="form__actions">
        <Button type="submit" variant="primary" disabled={isSubmitting}>
          {isSubmitting ? 'Saving…' : mode === 'create' ? 'Create task' : 'Save changes'}
        </Button>
        <Button onClick={handleReset} disabled={!isDirty || isSubmitting}>
          Reset
        </Button>
        <Button onClick={onCancel} disabled={isSubmitting}>
          Cancel
        </Button>
        {isDirty && <span className="text-muted" aria-live="polite">Unsaved changes</span>}
      </div>
    </form>
  );
}
```

## 4. `src/App.tsx` (complete, final for S11)

```tsx
import { useState } from 'react';
import type { Task, TaskStatus } from './domain/types';
import { filterTasks } from './domain/task-utils';
import { assertNever, toErrorMessage } from './domain/guards';
import { EMPTY_TASK_FORM, toCreateRequest, toFormValues } from './domain/task-form';
import type { TaskFormValues } from './domain/task-form';
import { fakeCreateTask, fakeUpdateTask } from './data/fake-save';
import { useTasks } from './hooks/useTasks';
import { useDebounce } from './hooks/useDebounce';
import { PageLayout } from './components/PageLayout';
import { FilterBar } from './components/FilterBar';
import { SearchBox } from './components/SearchBox';
import { TaskList } from './components/TaskList';
import { Board } from './components/Board';
import { Button } from './components/Button';
import { TaskForm } from './components/TaskForm';
import { ProgressRing } from './components/styled/ProgressRing';
import { Stack } from './components/styled/Stack';
import { useToast } from './toast/toast-context';

type View = 'list' | 'board';
/** What the form panel is doing: a discriminated union (06.06), not two booleans. */
type FormPanel = { mode: 'closed' } | { mode: 'create' } | { mode: 'edit'; task: Task };

export function App() {
  const { state, toggle, editTitle, reload, addTask, replaceTask } = useTasks();
  const [statusFilter, setStatusFilter] = useState<TaskStatus | null>(null);
  const [view, setView] = useState<View>('list');
  const [query, setQuery] = useState('');
  const [panel, setPanel] = useState<FormPanel>({ mode: 'closed' });
  const debouncedQuery = useDebounce(query, 300);
  const { show } = useToast();

  function handleToggle(id: number) {
    if (state.status !== 'succeeded') return;
    const task = state.data.find((t) => t.id === id);
    toggle(id);
    if (task && task.status !== 'DONE') {
      show({ tone: 'success', message: `Completed: ${task.title}` });
    }
  }

  function handleEdit(id: number) {
    if (state.status !== 'succeeded') return;
    const task = state.data.find((t) => t.id === id);
    if (task) setPanel({ mode: 'edit', task });
  }

  async function handleSubmit(values: TaskFormValues) {
    try {
      if (panel.mode === 'edit') {
        const saved = await fakeUpdateTask(panel.task, toCreateRequest(values, panel.task.categoryId));
        replaceTask(saved);
        show({ tone: 'success', message: `Saved: ${saved.title}` });
      } else {
        const created = await fakeCreateTask(toCreateRequest(values));
        addTask(created);
        show({ tone: 'success', message: `Created: ${created.title}` });
      }
      setPanel({ mode: 'closed' });
    } catch (error) {
      show({ tone: 'error', message: toErrorMessage(error) });
    }
  }

  let content;
  switch (state.status) {
    case 'idle':
    case 'loading':
      content = <p className="text-muted">Loading tasks…</p>;
      break;
    case 'failed':
      content = (
        <div role="alert">
          <p className="text-danger">{state.error}</p>
          <Button onClick={reload}>Try again</Button>
        </div>
      );
      break;
    case 'succeeded': {
      const visible = filterTasks(state.data, {
        status: statusFilter ?? undefined,
        q: debouncedQuery,
      });
      content =
        view === 'list' ? (
          <>
            <FilterBar value={statusFilter} onChange={setStatusFilter} />
            <TaskList tasks={visible} onToggle={handleToggle} onEditTitle={editTitle} onEdit={handleEdit} />
          </>
        ) : (
          <Board tasks={state.data} onToggle={handleToggle} onEditTitle={editTitle} onEdit={handleEdit} />
        );
      break;
    }
    default:
      content = assertNever(state);
  }

  const subtitle = state.status === 'succeeded' ? `(${state.data.length})` : undefined;

  return (
    <PageLayout title="Tasks" subtitle={subtitle}>
      {state.status === 'succeeded' && (
        <Stack $direction="row" $gap={4} $align="center">
          <ProgressRing done={state.data.filter((t) => t.status === 'DONE').length} total={state.data.length} />
          <span className="text-muted">tasks done</span>
        </Stack>
      )}
      <Stack $direction="row" $gap={2} $align="center" $wrap>
        <div role="group" aria-label="View">
          <Button size="sm" variant={view === 'list' ? 'primary' : 'secondary'} onClick={() => setView('list')}>
            List
          </Button>
          <Button size="sm" variant={view === 'board' ? 'primary' : 'secondary'} onClick={() => setView('board')}>
            Board
          </Button>
        </div>
        <Button size="sm" variant="primary" onClick={() => setPanel({ mode: 'create' })}>
          + New task
        </Button>
      </Stack>

      {panel.mode !== 'closed' && (
        <section aria-label={panel.mode === 'create' ? 'New task' : 'Edit task'}>
          <h2 className="kit-section__title">{panel.mode === 'create' ? 'New task' : 'Edit task'}</h2>
          <TaskForm
            // A new key resets the form's internal state when switching tasks (07.11)
            key={panel.mode === 'edit' ? `edit-${panel.task.id}` : 'create'}
            mode={panel.mode}
            initialValues={panel.mode === 'edit' ? toFormValues(panel.task) : EMPTY_TASK_FORM}
            onSubmit={handleSubmit}
            onCancel={() => setPanel({ mode: 'closed' })}
          />
        </section>
      )}

      {view === 'list' && <SearchBox value={query} onChange={setQuery} />}
      <hr />
      {content}
    </PageLayout>
  );
}
```

## 5. Stretch: focus the first invalid field after a failed submit

```tsx
const formRef = useRef<HTMLFormElement>(null);
const [focusRequest, setFocusRequest] = useState(0);

useEffect(() => {
  if (focusRequest === 0) return;
  formRef.current?.querySelector<HTMLElement>('[aria-invalid="true"]')?.focus();
}, [focusRequest]);

// in handleSubmit, when validation fails:
if (hasErrors(errors)) {
  setFocusRequest((n) => n + 1);   // runs after the render that shows the errors
  return;
}

// <form ref={formRef} …>
```

The effect runs **after** the render that sets `aria-invalid`, so the query finds the field.

## 6. Common wrong approaches

| Attempt | Problem |
|---|---|
| `useEffect(() => setValues(initialValues), [initialValues])` | Extra render + flicker; wipes the user's typing whenever the parent re-renders with a new object |
| `isDirty` as state set in `onChange` | Stays `true` after the user types a change and then types it back; derived is always correct |
| `JSON.stringify(values) !== JSON.stringify(initialValues)` | Works, but depends on key order and is slower; field-wise comparison is explicit |
| Two booleans for the panel | Impossible states ("creating while editing") |
| Replacing the whole task list after an update (re-fetch) | Works later with a server, but loses structural sharing and is slower; replace by id |
