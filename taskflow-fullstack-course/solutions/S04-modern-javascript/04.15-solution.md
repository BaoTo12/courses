# 💡 Lecture 04.15 · Solution Walkthrough: `updateTaskField` and `groupByStatus`

> Solution for [04.14 · Your Turn](../../lectures/S04-modern-javascript/04.14-your-turn.md). Tested: `Tests 8 passed (8)` with Vitest 5.

## 1. Reference solution

```js
/** Return a new array where one field of one task is replaced. */
export function updateTaskField(tasks, id, field, value) {
  return tasks.map((task) => (task.id === id ? { ...task, [field]: value } : task));
}

/** Group tasks into { TODO: [...], IN_PROGRESS: [...], DONE: [...] }. */
export function groupByStatus(tasks) {
  const groups = { TODO: [], IN_PROGRESS: [], DONE: [] };
  for (const task of tasks) {
    groups[task.status].push(task); // mutating OUR new object is fine; the input is untouched
  }
  return groups;
}
```

## 2. Reasoning

### `updateTaskField`

- `map` → new array (the outer reference changes, so React/Redux see a change).
- Matching task → `{ ...task, [field]: value }`: a **new object** with one property replaced. `[field]` is a computed key, so `'title'` becomes the `title` property.
- Non-matching tasks → returned **as-is** (`: task`), so their references are preserved. That's what `expect(next[1]).toBe(tasks[1])` checks, and it's what lets a memoised `TaskCard` for task 2 skip re-rendering later (S21).

### `groupByStatus`

- The object literal fixes **key order** (`TODO`, `IN_PROGRESS`, `DONE`). JavaScript preserves insertion order for string keys, so `Object.entries(groups)` renders columns in the right order every time.
- Pre-creating all three arrays guarantees **empty columns still exist**; `Object.groupBy` would omit them and the UI would have to handle `undefined`.
- `push` mutates the arrays, but they were **created inside this call**. Nobody else holds a reference to them yet, so the function is still pure from the outside. The frozen input tasks are only *read*.

## 3. The unknown-status question (Hint 3)

With the solution above, a task with `status: 'BLOCKED'` crashes:

```text
TypeError: Cannot read properties of undefined (reading 'push')
```

Three reasonable designs:

| Option | Code | Trade-off |
|---|---|---|
| **Fail loudly with a clear message** | `if (!groups[task.status]) throw new Error(\`Unknown status: ${task.status}\`);` | Surfaces backend/frontend contract drift immediately |
| **Ignore unknown** | `groups[task.status]?.push(task);` | UI keeps working, but tasks silently disappear. Dangerous. |
| **Collect separately** | `(groups[task.status] ?? (groups.OTHER ??= [])).push(task);` | Nothing lost; UI must handle an `OTHER` column |

In TaskFlow the status list is a fixed contract with the backend enum, so **failing loudly** is defensible in development. In S06, TypeScript's discriminated unions and exhaustiveness checks will catch this at **compile time**, which is even better.

## 4. Common wrong approaches

| Attempt | Why it fails |
|---|---|
| `tasks.find(t => t.id === id)[field] = value; return tasks;` | Mutates a frozen object → throws. And returns the same array, so React wouldn't re-render. |
| `const copy = [...tasks]; copy[i][field] = value;` | Shallow copy: the task object inside is still shared and frozen → throws (04.04). |
| `structuredClone(tasks)` then modify | Works, but **every** task gets a new reference, so `toBe(tasks[1])` fails. That breaks structural sharing (04.05). |
| `Object.groupBy(tasks, t => t.status)` | Missing keys for empty statuses (`groupByStatus([])` returns `{}`), and key order follows the data. (Its result also has a `null` prototype. `toEqual` ignores that, but `toStrictEqual` would fail on it.) |
| `tasks.reduce((acc, t) => ({ ...acc, [t.status]: [...(acc[t.status] ?? []), t] }), {})` | Pure, but empty groups are missing and key order depends on data order. |

## 5. Stretch: three columns in `main.js`

```js
import { filterTasks, toggleTask, groupByStatus } from './task-utils.js';

function renderColumns() {
  const groups = groupByStatus(tasks);
  const columns = Object.entries(groups).map(([status, list]) => {
    const column = document.createElement('section');
    const heading = document.createElement('h2');
    heading.className = 'kit-section__title';
    heading.textContent = `${STATUS_LABEL[status]} (${list.length})`;
    const grid = document.createElement('div');
    grid.className = 'task-grid';
    grid.style.gridTemplateColumns = '1fr';
    grid.append(...list.map(createCard));
    column.append(heading, grid);
    return column;
  });
  listEl.replaceChildren(...columns);
}
```
