# 💡 Lecture 09.13 · Solution Walkthrough: `ProgressRing`

> Solution for [09.12 · Your Turn](../../lectures/S09-styled-components/09.12-your-turn-progress-ring.md).
> Verified in the reference app: build and lint clean; with 2 of 8 tasks done, the ring's accessible label reads "25% of tasks done".

---

## 1. `src/components/styled/ProgressRing.tsx`

```tsx
import styled, { keyframes } from 'styled-components';

const SIZE = 72;
const STROKE = 8;
const RADIUS = (SIZE - STROKE) / 2;
const CIRCUMFERENCE = 2 * Math.PI * RADIUS;

/** Threshold colours: red below 34%, amber below 67%, green otherwise. */
function ringColor(percent: number): string {
  if (percent < 34) return 'var(--color-danger)';
  if (percent < 67) return '#f59e0b';
  return '#16a34a';
}

const appear = keyframes`
  from { stroke-dashoffset: ${CIRCUMFERENCE}; }
`;

const Wrapper = styled.figure`
  position: relative;
  width: ${SIZE}px;
  height: ${SIZE}px;
  margin: 0;
`;

const Arc = styled.circle<{ $offset: number; $color: string }>`
  fill: none;
  stroke: ${({ $color }) => $color};
  stroke-width: ${STROKE};
  stroke-linecap: round;
  stroke-dasharray: ${CIRCUMFERENCE};
  stroke-dashoffset: ${({ $offset }) => $offset};
  transform: rotate(-90deg);
  transform-origin: 50% 50%;
  transition: stroke-dashoffset 300ms ease, stroke 300ms ease;
  animation: ${appear} 600ms ease-out;

  @media (prefers-reduced-motion: reduce) {
    animation: none;
    transition: none;
  }
`;

const Label = styled.figcaption`
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
  font-size: 0.875rem;
  font-weight: 600;
`;

interface ProgressRingProps {
  done: number;
  total: number;
}

export function ProgressRing({ done, total }: ProgressRingProps) {
  const percent = total === 0 ? 0 : Math.round((done / total) * 100);
  const offset = CIRCUMFERENCE * (1 - percent / 100);

  return (
    <Wrapper aria-label={`${percent}% of tasks done`} role="img">
      <svg width={SIZE} height={SIZE} aria-hidden="true">
        <circle
          cx={SIZE / 2}
          cy={SIZE / 2}
          r={RADIUS}
          fill="none"
          stroke="var(--color-border)"
          strokeWidth={STROKE}
        />
        <Arc cx={SIZE / 2} cy={SIZE / 2} r={RADIUS} $offset={offset} $color={ringColor(percent)} />
      </svg>
      <Label aria-hidden="true">{percent}%</Label>
    </Wrapper>
  );
}
```

And in `App.tsx`:

```tsx
{state.status === 'succeeded' && (
  <Stack $direction="row" $gap={4} $align="center">
    <ProgressRing
      done={state.data.filter((t) => t.status === 'DONE').length}
      total={state.data.length}
    />
    <span className="text-muted">tasks done</span>
  </Stack>
)}
```

## 2. Reasoning

- **Constants at module level**: `SIZE`, `RADIUS`, `CIRCUMFERENCE` are computed once. Interpolating a **constant** (`${CIRCUMFERENCE}`) bakes it into the static CSS; it's not a function, so it isn't re-evaluated per render.
- **Interpolation vs `style` for the offset**: the percentage has at most 101 values (0–100) and changes only when a task is toggled, so it's a **finite, low-frequency** value and interpolation is fine (09.11). If the ring animated continuously (e.g. a live upload), `style={{ strokeDashoffset }}` would be better.
- **`ringColor` is private.** Exporting it from a component file would trigger the Fast Refresh lint rule (07.06). If another module needs it, move it to `domain/`.
- **`total === 0` guard**: `0 / 0` is `NaN`, and `Math.round(NaN)` is `NaN`, which would render "NaN%" (07.10: numbers, including NaN, render).
- **SVG attributes in JSX are camelCase** (`strokeWidth`), and the SVG's `stroke` for the background uses `var(--color-border)`, so the ring themes automatically (08.10).
- **Accessibility**: the `figure` has `role="img"` + a full-sentence label; the SVG and the visible number are `aria-hidden` so screen readers hear the sentence once.
- **Reduced motion**: both the keyframe animation and the transition are disabled for users who ask for it.

## 3. Known imperfection (on purpose)

`'#f59e0b'` and `'#16a34a'` are hard-coded here, while the danger colour comes from a theme token. That's inconsistent: in dark mode the danger colour adapts, but the others don't. **S10 fixes this** by giving styled-components a typed theme built from the same tokens as SCSS.

## 4. Common wrong approaches

| Attempt | Problem |
|---|---|
| Computing `CIRCUMFERENCE` inside the component and interpolating functions for everything | Works, but re-evaluates constants per render and generates more classes |
| `stroke-dashoffset` via a CSS `transition` only, without `keyframes` | Nothing animates on first render (there's no previous value to transition from) |
| Percentage text readable by screen readers **and** an `aria-label` | Announced twice |
| `export function ringColor` in the same file | Lint warning: Fast Refresh only works when a file only exports components |
| Forgetting `total === 0` | "NaN%" on an empty task list |
